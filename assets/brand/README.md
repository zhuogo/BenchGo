# BenchGo

应用与插件名称均为 **BenchGo**。**BenchGo** 同时是统一 Logo 与吉祥物；PC、Android、网页工作台和初始化使用同一形象。

2026-10-26 定稿母版在仓库 `icon/logo.svg`（600×380，透明底）。本目录是运行与构建的唯一品牌来源。

- `benchgo-mark.svg`：母版原样拷贝，用于与名称组合的横版标识。
- `benchgo-logo.svg` / `benchgo-logo.png`：母版居中放入 1024 透明方画布，宽度约占 76%。用于桌面窗口、托盘、安装器、启动页、网页入口和 Android 图标。PNG 为 1024px。
- `favicon.svg` / `favicon.ico`：与母版同一造型。ICO 来自 `icon/favicon.ico`。

品牌色：奶白 `#F1E8DB`、深墨 `#222321`、身份橙 `#EE5A33`。不改身体、切角、眼睛或纹章比例，不拉伸。Android 自适应图标使用同一方标，背景仍为墨黑 `#222222`。
