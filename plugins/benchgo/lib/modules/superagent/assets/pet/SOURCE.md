# Pet assets

Derived from the user-authorized local VI project at commit 21c317a302c9f850be24ee7e96c7a11ace3ef564 and its working tree. Source files are recorded per layer. Original usage restrictions are preserved in BRAND-USAGE.md. No additional redistribution license is granted.

Face and decoration paths are retained; historical colors map to BenchGo formal colors. The formal BenchGo mark supplies body geometry, editor strip and framing. Palette values come from the VI BenchGo palette marks. Regenerate explicitly with: node scripts/import-pet-assets.mjs <VI-checkout>.
