# 品牌资产使用说明

本仓库包含小角、DraftGo、RouterGo、SelfGo、BenchGo 的品牌图标与 VI 资产。

- 可下载或公开访问，不等于获得开放源代码许可、商标许可或自由再分发许可。
- 项目内获授权的使用者可按 VI 规范接入；外部使用、修改、再分发与商业用途应先取得资产所有者授权。
- 不得将这些标识用于冒充产品官方、暗示未获授权的合作关系，或使用户混淆来源。
- 不在本说明中新增或推定 MIT、Apache、CC0 等授权；具体授权范围由资产所有者决定。
- 历史探索不等于当前正式标识。优先使用 `vi-manifest.json` 指向的当前资产；固定版本发布请使用经确认的 tag 或 commit。
- 字体文件不随资产分发，字体许可需单独核对。SVG 保留可编辑文字；无相应字体时使用 PNG 固化版本，或在合法字体环境中转曲。
- 交付为 RGB 数字资产。印刷前需另行进行色彩管理、尺寸与出血校验。
