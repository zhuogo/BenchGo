# 统一技能管理

## 已实现范围（2026-11-03）

当前实现：工具 → 技能统一展示官方注册表中实际生效的用户安装、项目、内置和插件技能，并整合 SuperAgent 的自建技能及待确认候选。候选仍需人工批准后生效，界面保留“批准启用/拒绝候选”；官方技能提供方只暴露 active/stale 项。复用官方 `ctx.skills.list/get`，不新增磁盘扫描器，不修改官方引擎。

2026-11-04 产品目标（待实施）：按直管制，自建技能沉淀自动生效、无需逐条批准；候选只作为系统内待流转状态，管理覆盖查看、编辑、固定、归档、历史与恢复。当前服务和界面尚未切换到该策略，统一页也尚无正文编辑及手动归档入口，不能将目标当作已实现能力。

页面回答“当前范围有哪些技能可用，来自哪里，如何查看或管理”。布局遵循《前端视觉规范》（docs/02-工作台与Agent/前端视觉规范.md）：24px 标题，技能域、来源筛选与搜索同一行；列表和详情为两个切换视图，点击技能进入详情，返回保留筛选。删除空详情占位说明及“默认 Agent”“所有项目共享的技能”等辅助文案。默认工作区显示为“最近”，不改变实际路径与标识。延续 BenchGo 字体、主题与品牌色；品牌色只标记真实可用性，选中项使用中性底色。窄屏工具栏自适应换行，保留加载、空、失败、重试和键盘焦点状态。

## 范围与状态

- 默认全局范围；可选择已有项目，由服务端从 workspaceRegistry 解析项目路径，明确显示查询范围。项目目录遵循官方最近 .git 根规则。
- 使用默认 Agent 预设的 standing scope 查询目录：官方文件系统提供方属于预设作用域，只查询宿主全局层会遗漏已安装技能。查询不创建 Agent，不启动会话；页面不是某个活动会话的专属技能目录。
- 官方注册表返回同名最终生效项，不声称列出被覆盖的全部安装副本；页面说明同名优先级。
- 自建技能与官方目录按 provider 与名称关联，避免重复；候选、待整理、归档与未生效状态明确区分。
- SuperAgent 未启用时仍可浏览已安装技能；官方技能服务不可用与空目录必须区分。
- 文件/内置技能支持查看正文与复制实际路径；本次不新增删除、禁用或任意路径文件读取。自建技能保留批准、拒绝、固定、历史与恢复操作。

## 服务契约

基础层提供 owner-only `POST /api/benchgo/skills`，沿用同源校验、JSON 请求和 no-store 响应。

- `list { projectId? }` → `{ available, skills, projects, scope: { projectId?, title, cwd? } }`。
- `get { projectId?, name, provider }` → `{ skill }`，只加载所选范围注册表中的实际生效项，provider 不一致时返回冲突，避免同名切换后预览错误技能。
- skill 字段：`name, description, source, provider, path?, invocation, content?`；列表不加载正文。
- 项目 ID 必须来自官方 workspaceRegistry，不接受任意 cwd/path。未启用服务时 list 返回 `available:false`，get 明确失败。
- 自建管理继续使用既有 `/api/commander/assistant` 操作，不复制持久化实现。

OpenAPI 同步描述上述只读接口。本次不增加模型工具或 MCP 操作，现有技能加载工具和自建管理协议不变。

## 验证与边界

2026-11-03 实施验证覆盖全局/项目查询、provider 冲突、服务缺失、跨源拒绝、正文读取与自建管理回归，并验证客户端构建和 `npm run reload:plus`。当次按用户要求未启动图形应用或做截图视觉校验；这是历史验证边界，后续前端变更仍须遵循[前端视觉规范](../02-工作台与Agent/前端视觉规范.md)自查四态实际渲染。全部安装副本枚举、第三方 CLI 私有技能目录导入与文件技能编辑/卸载不在该次范围。

本次验证结果：官方引擎 `571902028a` 的真实 scoped registry + filesystem provider 可发现安装技能，列表/正文/冲突/取消后均释放预设租约；客户端验证独立浏览、调用策略、去重、筛选、项目与正文请求竞态、审核/拒绝/固定及快照恢复。定向测试通过，`reload:plus` 完成模块、预览、Link 网页与统一客户端重建。设计静态检查无失败，路径和技能源文保留等宽字体。

组合模块生命周期测试在可选模块启动阶段超时；移除本次新增挂载和断言的基线仍在同一阶段失败，未扩大范围修改既有模块启动逻辑。视觉与真实浏览器交互由用户验收。
