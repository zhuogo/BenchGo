# 媒体生成

在设置「媒体 → 媒体生成」中分别启用图片、视频和音频生成。每类最多配置三个顺位，按供应商 ID 和原始模型 ID 保存。语音转文本、回复朗读和实时通话在「媒体 → 语音」中配置，详见[实时语音](../03-实时语音/设计.md)。

本机主人的 SuperAgent 对话可通过 `assistant_settings` 的 `benchgo-media-generation` 命名空间修改三类生成开关、模型顺位和音频音色。顺位数组从首选到备用排序，调整顺序时按供应商与原始模型 ID 保留同一模型的参数和凭据引用。页面与对话共用生成设置和版本校验，提交后从服务读回核验，下一次生成读取已保存的配置。实时语音继续使用 `benchgo-voice` 命名空间。

## 路由与交付

- 用户从聊天提出生成或编辑要求。工具只在当前用户原文明确指定时使用模型覆盖，否则按顺位选择满足当前操作的模型。指定模型时按原始 ID 或唯一显示名在该类别的顺位中查找，同 ID 或同名重复时还需指定供应商 ID。显式指定的模型不可用时返回原因。
- 能力与参数根据[模型与供应商](模型与供应商.md#模型能力标签)确定。RouterGo 首先使用账号目录的 `capabilities` 和 `media_constraints`，公开目录按精确 ID 补充资料。
- 音频生成的每个模型顺位可手填多个供应商音色名称、听感说明，并选一个默认音色。旧单音色自动成为默认。生成时优先使用用户在当前对话明确指定的音色。用户给出偏好或把选择交给助手时，助手可读取配置并从中选择。只询问建议时使用只读工具。未指定或未表达偏好时使用所选顺位的默认音色，未配置时取供应商目录列出的首个音色。全无可用音色则提示填写。目录或供应商明确指出音色无效时提示核对，停止自动换音色或重新提交。提交结果不明时保留原请求记录。
- 供应商明确拒绝且未接受请求时允许顺位降级。取消、超时、断网或响应无法解析时保留提交记录。视频一旦拿到供应商任务 ID，后续只查询或下载原任务。
- 生成文件保存在发起请求的 BenchGo 主机，通过已有 owner 连接访问。供应商用外部 HTTPS 图片链接交付时，原链接保存于任务回执并可以预览或打开，图片仍由供应商托管。视频和音频提供文件并支持浏览器可解码的预览。文件引用只读取该会话已有的附件或本地生成文件回执。

## OpenAI 兼容操作

| 类型 | 请求与参数 |
| --- | --- |
| 图片 | `/images/generations` 文生图。 `/images/edits` 带一张或多张参考图，可传 PNG 遮罩。局部修改要求模型明确声明遮罩能力或在模型选项标注 `image-mask`。尺寸、质量和输出格式随模型能力。 |
| 视频 | `/videos` 提交，`/videos/{id}` 查询，`/videos/{id}/content` 下载。支持文本和一张参考图，时长、尺寸按模型校验。视频和音频参考素材及其他扩展参数待逐个接入。 |
| 音频 | `/audio/speech` 将文字生成独立文件，默认为 MP3。支持供应商声明的其他输出格式和音色。 |

## 实现边界与验收

媒体生成由 `plugins/media/` 持有，复用基础层供应商和凭据，随现有 Cordis 入口装配。普通会话注册通用工具，SuperAgent 复用相同工具并延续自己的任务与交付机制。SuperAgent 既有单模型图片配置迁移到第一顺位，历史产物继续可读。旧视频配置迁入时保持禁用。

生成工具将产物地址写入会话展示数据，模型收到交付状态和后续操作所需的凭据。普通会话和 SuperAgent 按原回合合并产物并去重，复用同一图片画廊和音视频播放卡，交互见[文件与图片交付](../06-superagent/对话交互.md#文件与图片交付)。

外部 Harness 通过现有会话私有桥注册媒体工具。原生会话可以按文件名引用同一会话先前生成的图片，现有原生输入仅支持文本。已连接的原生客户端可能缓存工具清单，设置变更后重连即可刷新。

定向验收覆盖设置四态、显式选择、顺位降级、原模型 ID 请求、参考图与遮罩、视频原任务续查、生成产物预览与下载。RouterGo 的账号模型目录已实测，真实计费生成、供应商对参数限制的执行和安装版设备链路待验收。
