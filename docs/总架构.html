BenchGo 总架构与运行机制

官方 Harness 提供运行底座，BenchGo 的五个源码模块合成一个插件。此页是唯一总架构图，展示板块关系与 SuperAgent 全链路；详细设计按板块和小模块分别维护，同一主题只保留一份正文。

已定目标路线 · 实现状态另列

一、产品板块与宿主

桌面 / Web / Link 移动入口 → 官方 Harness 会话、模型与工具服务 → BenchGo 业务模块。基础层提供公共配置、模型、项目和更新；Harness 聚合提供 commander 服务；SuperAgent 依赖基础层与聚合；Voice、Link 独立启停，不硬依赖聚合或总助手。只安装一个 benchgo-plugin，不修改官方引擎源码。

设备与远程连接

Link 管理配对、授权设备、远程工作台与直连 / 中继传输。远程会话复用原宿主能力，不另建 Agent 引擎。

工作台与 Agent

工作台、项目与会话入口，原生 Agent 聚合，共享组件、视觉规范与产物预览；统一产品形象与交互。

实时语音

ASR → 原会话 Agent → TTS。提供输入、朗读和通话，复用原会话权限与审批，不另建语音助手。

模型与工具

共享供应商、模型、工具与技能能力。显式选择优先，模型 ID 和协议值原样保存，可用性必须反映真实状态。

更新与发布

官方引擎 pin、BenchGo 单包构建、品牌注入、独立插件更新与回滚；开发产物和正式发布分别验证。

SuperAgent

可信入口、Router 分诊、工单执行、Worker 自校验、Router 表达交付与后台记忆；执行使用官方 Harness Agent。

六个文档板块是产品设计分类，不是六个安装包。源码只有基础层、Harness 聚合、SuperAgent、Voice、Link 五个包，经构建统一交付；参考仓库只供设计核对，不参与产品依赖或构建。

二、SuperAgent 全链路目标

桌面主人直通；仅准备新开单时核对当前原话、拟派事项与现成只读能力，可直答则退回同一 Router。渠道仅是适配器，外部消息经过统一入口管线。Super Harness 机制统合调度与执行、上下文管理、模型调度三层；权限、持久化与记忆横向支撑，沿用现有插件边界。图示是目标，实现状态见末节。

管理总则（目标）：SuperAgent 与 BenchGo 自身的设置和状态可在主聊直接管理，页面共用同源服务；全部注册配置默认可通过通用目录、读取和修改契约管理，普通明确修改直接办理，只改用户要求的内容。可信服务注册变更影响与确认类别，宿主执行分类；保存与真实即时生效分别回执，审计可查、变更可回滚。安全防线变化须真人明确确认，秘密仅走安全输入，外部高危动作继续逐次审批。大范围删除先确认本次具体清单，可缩小子集、不重复叠卡；工单默认清理终态，非终态另确认并先核实真实停止，再移入归档，保留墓碑审计且不联删成果，硬删除须另行明确要求。通用管理与主动清理尚待实施，权威正文见统一配置契约与工单清理生命周期。

事实层：适配器提取身份与来源标注、转换协议和消息、声明能力；规则层：统一管线核对身份与聊天范围、判准入和研判，不把规则放进适配器。来源标注先于核对，正文归一晚于核对；字段、飞书映射及停单条件以链接与渠道为唯一正文。

派工固定附带快速轻量自校验要求，优先使用能跑的测试、构建和命令输出。缺少自检记录时，经官方关闭前接缝让原 Worker 在同一会话补全一次，仍缺失则明确等待处理。明显错误在原单修正；纯文本无需强行生成文件，自检不新增 Agent 或内容评分层。详见自校验与交付。

三、工单生命周期与执行中沟通

开单与授权

Router 生成标题与活摘要，先查重；同一 Trigger 只生一单。Mandate 固定记录策略版本、范围、强度、命中规则、发起人身份，绑定真实原话；派工范围不得超过用户原话。

普通插话即修订

主聊、渠道会话与执行会话涉及同单的消息都登记到同一工单输入账；状态、投递和关单也只有一份记录。范围内由 Executor 在下一工具边界整份切换要求，不打断正在进行的工具动作；版本只作后台防丢、防重与当前执行编号。

暂停、停权与扩权

用户在会话里说暂停，由 Router 调用真实生命周期控制并写入同单输入账；等待核查不等于暂停，回执确认前不声称已暂停。待核实也可暂停，暂停撤销延期续接，只收修订、不自动续跑。停止、撤权、收窄权限立即拦截后续动作，不等普通修订检查点。超 Mandate 的调整交 Router，经真实用户确认后生成新授权版本并保留旧版。

情况处理与关单条件
执行完成Worker 轻量自检通过后保存原稿、证据与自检记录并向 Router 发完成信号。Router 主动用自己的话说明事情与产出，自选摘要或完整回复，保存正式稿后由 outbox 交付原来源；原稿留工单详情，不原样直投工单、报告或系统状态文案。回复确认送达后 completed 关单，Router 不重派或增加内容验收。
生成失败 / 投递失败 / 送达未知原稿保留且工单待交付；生成失败只重试 Router 表达，明确未送达只补投已存回复，效果未知先查回执，不重跑 Worker，也不盲目重发。
问题 / 受阻Worker 上报 Router；有确定依据就内部答，必须用户拍板才发选项卡。答复按问题编号回原单；只停受影响部分，其余独立且已授权的部分按稳妥默认继续。缺信息或权限保留等待。
执行失败偶发网络、供应商故障先退避重试；只有结构性无解才报失败。保存实际尝试、原因与恢复条件，由 Router 自行组织自然说明，不套固定报告；送达后 failed 关单。用户回话可续原单或开关联调整单。
执行超时与中断待核实原因区分会话中断或重启、Worker 未跑完、证据不一致、外部效果未知、暂停恢复未确认。Router 收到原因与核查进度信号，主动自然通报并在原授权内异步协调；看板显示原因、核查次数和下次时间，不让用户代查。证据核清后才沿原单原会话安全续接，处置后由 Router 报告；自动续接退避且有上限，预算跨执行归属变化与重启累计，耗尽留待核实并由 Router 升级通报，普通核查不重置预算。用户明确继续仅授权当次处置。外部效果未知只核查、不重发。看板区分动作已拦与执行端退出确认。权威规则见待核实通报与自主处置。
追问 / 修改成果Router 表达交付或答问均可读取已存成果，不重新派工或验收。实际修改在办结果走修订；成功交付后不回改原稿，新开关联调整单并引用原单结果。
无关新任务独立分诊，查重后新开工单并行执行；仅在资源冲突处串行或隔开工作区。Router 自行组织可辨的自然回复，不固定工单标题前缀。

确认送达指原逻辑会话已持久接收，或原渠道返回可信发送成功回执；排入 outbox、设备播放和用户已读是不同事实。详细生命周期与问题协议见任务与执行、自校验与交付。

执行事实复用官方持久 Session、工单账和最小索引，列表与详情通过官方增量流共享；主聊和旁聊侧的任务列表均展示全部工单，后台重连保留内容、静默补偿。辅助摘要只用辅助模型，无可用模型时确定性降级；文件产出观察复用已允许工具的检查点，缺口保持未知。独立 Watchdog 使用独立宿主、profile 与官方 Schedule，只观察并向 Router 发信号，不改工单、不重启宿主；已完成对安装版的真实周期检查与停止隔离，实际故障及模型判断仍须分别验收。角色与最终流式交接的安装版适用验收不得由定向结果推定。权威契约见服务契约与任务与执行；Router 的人格与表达统一见Router 对话准则。

四、权限继承与对外审批

内部继承与逐层裁剪

用户指令是业务授权唯一源头。Router → 工单 → Worker → 一层子代理只能收窄，工具面逐层裁剪；每个主 Worker 可有多个并行子代理，子代理无凭据工具、禁止再委派。自有会话通过官方插槽隐藏档位入口，不显示角色或内部配置标签；普通会话保留官方预设。Agent preset、沙箱审批与模型路由分别核验，权限叠加宿主限制，不因隐藏选择器获得完全权限。

整站许可具有明确边界

许可绑定精确 origin、动作类别、期限和真实授权人，持久留痕、可查看、可撤销。自用可明确覆盖较宽的常规敏感类别；四类高危始终除外。许可与工单 Mandate 叠加，互不替代。

凭据仅经保险库

Agent 仅见条目与句柄，由系统安全代填。缺少凭据时提示用户安全录入保险库或接管；秘密不进入聊天、模型和日志。凭据录入与动作批准分别处理，录入不自动扩大授权。

支付购买、改密码、删账号、另行对外发送与分享只通过已注册的结构化通道自动提交，并永远逐次审批。审批卡冻结实际对象、最终内容和影响，一次只执行此件；无通道则准备好接管点，由用户完成最后一步。原来源正常回复、进度、问题与成果交付，以及公开浏览、搜索和资料下载免审批，仍复核 Mandate、来源归属与现行规则。

能力声明进入核心注册表

连接器等能力声明自身支持的高危类别、专用操作、内容预览与回执，核心统一校验后放行。未接通类别默认 handoff，优先外发与支付；新渠道只补适配与声明，不改审批核心。

终端与浏览器做到提交前

保留完整能力完成其他工作及准备，抵达高危提交前停止：有通道走冻结审批卡，无通道生成用户接管点。放弃任意脚本或点击的万能提交识别，禁止脚本拼接、直接请求或拆步骤绕过。

结构化动作顺序：复核工单与当前规则 → 匹配注册类别和可用通道 → 冻结最终对象与内容并逐次审批（常规敏感类别可匹配有效整站许可） → 凭据仅经保险库 → 提交前复核同一快照并单次执行 → 记录效果与回执。能力发现与本地准备不提交外部动作；提交工具返回成功也须核对实际效果。无通道转用户接管；未知效果先核实，不能靠重试业务动作探测。

审批呈现分三层：Worker 正式待批时向所属 Router 发事实信号，Router 先在对话中以自己的话提醒；原官方卡挂在对应提醒处随对话流，不置顶、不弹窗；工作台「任务 → 审核」聚合全部待审批项，可跳转对应卡片，只作兜底、不替代提醒。三层复用同一官方请求，真实用户批准或拒绝，Router 不代批；这不是任务成果验收。卡片挂流与看板定位是新定目标，接线及真实验收边界见对话交互，交互唯一正文见权限与安全输入交互。

连接器与外部服务分别授权；不同连接器仅由可信适配器映射到同一站点，禁止跨服务借用许可。详细授权规则唯一正文见任务与执行；安全输入见链接与渠道。

渠道接入授权逐适配器连接绑定，可独立撤销，由统一服务在读取与发送前复检；接入授权不替代 Mandate 或动作许可，适配器不据此自行做准入判断。见渠道授权。

高危提交的当前通道与逐工具权限边界见任务与执行；登录、上传、安全输入及用户接管的适配范围见链接与渠道。许可存在不等于对应执行适配器已经具备。

五、统一渠道会话与真实执行会话

渠道复用统一会话

渠道会话出现在工作台会话列表，带来源标记，可打开并直接回复。可以采用旁聊形态，列表、消息流、输入与存储复用工作台机制，不另建渠道会话实现。

渠道无专属人设，出厂无名

适配器与渠道会话不预设人格、自称或自我介绍，不拿品牌或所用模型当身份；各入口共用内置层与 SOUL / IDENTITY 文档链。出厂姓名为空，等待用户正式命名；未命名被问身份时如实说明是用户的个人助手、还没有名字，不自编称呼。唯一正文与验证边界见身份与形象。

入口不同，工单同账

渠道会话与执行会话保留各自职责，涉及同一工单的输入、状态、投递记录和关单条件全局唯一；适配器不保存自己的对话状态，不复制第二张工单。

能力与回执如实呈现

文本、图片、卡片、回执按适配器声明显示能力；直接回复走统一投递路径，Router 成果回复由 outbox 经来源适配器返回原会话或话题，原稿留工单详情，回执回到同一本工单账。

项目列表里的真实会话

执行会话显式归入所属项目的工作区会话列表，带工单标记，与用户自建对话区分。从任务列表打开工单详情可进入同一 session；聊天消息不提供“查看执行会话”入口，不复制会话或创建第二份执行记录。

直接插话，共用一本账

用户始终与 Router 对话；执行会话保留直接插话入口，与主旁聊共用 Router 跟进协调及同一工单输入账。Executor 消费范围内修订，超 Mandate 的输入由 Router 确认或分新单，不把普通会话输入当作新增执行权。

无项目与防淹没

不涉及项目的任务归入官方「未分组」，这就是本设计的“最近”：按最近活动排序、随时可翻到，不另建工作区。确认关单后工单自动进入“已归档”，关联执行会话一并沿官方机制归档；历史仍可打开原单和原会话，不丢输入或结果。等待、暂停及待交付不提前归档。详见任务列表。

渠道定位、同会话显示投影与恢复边界见链接与渠道；镜像不直接写入模型消息面。渠道对话不等于 Worker 执行会话，二者都复用统一会话机制。

Router 主 / 旁聊承担对话、调度与成果表达；工单完成后主动自然提醒，自选摘要或完整回复。状态说明由 Router 按真实情况自行判断，无固定工单报告、标题前缀、系统状态文案或硬兜底；消息排在人类请求之后，表达可读成果但不重派或验收，发布前复核状态与授权。聊天消息不显示通用等待或系统状态块、重复问题及刷新、停止、执行会话按钮，保留真实提问与授权卡。真实状态、技术原因和控制入口统一在任务列表与工单详情，Router 暂时不可用时保留待交付或异常事实。执行会话保留真实过程并允许直接输入；空、加载、错误和有数据四态保持真实。详见对话交互与任务列表交互。

六、模型归属、上下文与记忆

三角色模型

Router 使用系统对话模型；Worker 使用系统工作角色模型，项目归属不让项目默认模型覆盖实际请求；辅助模型承担生成、压缩、研判与整理，不审核任务内容或决定交付。

续跑保持创建路由

执行会话创建时冻结工作角色模型队列与参数，委派、修订和目标节点不接受模型覆盖；续跑不随系统或项目默认修改而重选。运行故障可在该冻结队列内切换备用，保存最近实际选择。子代理继承父 Worker 当前工作模型，不能借模型覆盖转成其他角色。

当面记忆与闭单整理

记住、纠正、遗忘由 Router 当场直写，不开工单。Worker 不直接写长期记忆；后台按计数器从已关工单提炼，不经 Router 上下文，整理结果可纠正、可回滚。

任务包和子代理上下文仅含所需切片及原文指针，不复制父完整历史。模型 ID 保持不透明，不猜别名；未配置工作队列时的继承与允许的显式选择由系统角色配置明确约束。权威规则见模型与上下文、记忆与技能。
