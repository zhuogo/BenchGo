# 前端视觉规范

板块入口见[工作台与 Agent](设计.md)。

本文是 BenchGo 自有前端的视觉真源，适用于五个源码包的客户端、Link 移动界面和 Windows 启动页。官方界面继续通过适配入口复用；不修改官方子模块样式源码。

## 视觉原则

现代产品质感、清楚的信息层级和一致交互优先。信息可用卡片、图标、状态色、适度渐变与阴影表达，装饰与层次服务于内容识别和操作反馈。页面标题、工具栏和保存区不因为包含按钮就套灰色外框；优先用对齐、留白、字号和字重建立层级。

同类任务、状态、空缺和操作复用已有组件，不逐页建立另一套外观。品牌形象与插画素材以 `assets/brand/` 为唯一来源；PC、移动端与初始化使用同一 BenchGo 形象。图标用既有 iconsax 或同风格描边 SVG，不用表情符号代替图标。

悬停与键盘提示复用官方公开 Tooltip，共享薄适配只统一默认位置、延迟、portal 与禁用控件锚点，不另建气泡渲染、定位或事件实现；iframe 等语义标题保留。确需普通确认的操作复用共享确认弹窗，默认聚焦取消，关闭、取消或组件卸载均不执行；普通明确配置修改不另加二次确认，分类与安全确认遵循[统一配置契约](../06-superagent/服务契约.md#对话管理与统一配置目标)。工单清理的具体清单在原容器内联确认，不重复叠加弹窗；高危动作仍走原官方审批，不以普通确认替代。

首次加载使用居中纯文字，字符依次短促提亮、轻抬；减少动效时显示静态文字。后台刷新保留已有内容，手动刷新有忙碌反馈，失败明确说明且不清空草稿。

## Windows 启动页

启动卡片与初始化页共用 `scripts/desktop/renderer/` 的品牌呈现。吉祥物使用 `assets/brand/benchgo-mark.svg` 透明正式母版，保持原比例、身体与品牌颜色，不使用带背景的应用图标版本；吉祥物/Logo 自身无底板、边框或外部包裹卡片。应用、托盘和安装器图标仍按各自品牌用途生成。

标题「BenchGo」与吉祥物在同一时刻开始同一轮 240ms 轻柔渐显与短距离位移，持续时间一致，不先出标题或分段延迟；状态文字和操作区域保留稳定位置，不因动效跳版。吉祥物保留原形象，以既有眼睛进行短促眨眼、轻微左看、右看及回正；复用本地 SVG/CSS 动效，启动页移除整组阴影滤镜以减少重绘，不重绘或生成另一套形象、不调用模型，不把装饰表情当作初始化成功或失败的事实。

准备插件、启动服务、连接和打开工作台使用实际阶段提示；主进程在本地 `logs/benchgo-startup.json` 覆盖记录固定阶段耗时，不记录会话或配置。进入工作台前的官方品牌加载页通过打包注入改为居中纯文字逐字提亮/轻抬，保留原错误、恢复及页面交接生命周期。

整个启动窗口和页面从首帧起跟随 Windows 系统明暗主题，包括原生窗口底色、页面背景、标题、状态文字、错误与按钮；系统主题切换时同步更新，不出现固定暗底、浅色边条或首次白/黑闪烁。吉祥物透明区域直接透出主题背景，品牌本体配色保持一致。尊重 `prefers-reduced-motion`：关闭进入位移、表情循环及其他非必要动效，内容直接可见，不延迟进入工作台。

2026-11-10 已实现，准备后的实际启动页面已通过浏览器渲染核验，原生首帧主题与监听清理已有定向测试。验收覆盖启动等待、初始化可操作、错误与重试、进入工作台，核对浅色/深色及运行中系统切换、首次绘制、标题与吉祥物同步进入、透明无框表情和减少动效；启动结束或窗口销毁及时停止动画。图形应用由用户明确授权后启动，安装版最终视觉由用户验收。

## 字号、间距和颜色基线

字体继承宿主与既有 BenchGo 字体，不在单页引入新字体体系。下表记录现有共享样式与工作台的明确尺度，优先直接复用组件；业务页面可按内容密度调整，不能据此批量覆盖宿主样式。

聊天正文使用系统无衬线阅读字体，字号至少 15px、行高 1.8、段落间距 1em，并尊重用户更大的字号设置；规则仅作用于消息正文，导航与设置保持既有字体，代码保留官方等宽字体。

主聊与旁聊的 AI 回复在既有 QuietChat 消息容器内，采用与用户消息一致的气泡语言，以主题文字与背景混合的淡中性底色和左右位置区分，沿用 16px 圆角；不显示助手名称、固定身份头、左侧装饰线或角色诊断。可访问标签仍用于屏幕阅读器，正文继续复用官方 Markdown 渲染与上述段距。流式时即预留操作区，结束后只改变操作可见性；窄容器将操作放到正文下方，不在完成时挤窄正文或改变滚动位置。新挂入的 Markdown 顶层块一次性轻渐显约 180ms，同段文字追加与正式交接不重播；减少动态时关闭，不增加逐字等待或第二份文本缓存。该适配不增加消息状态、替换审批或按流式阶段重建容器；官方执行会话仍沿用原消息渲染器。明暗、窄容器、长代码与表格、减少动效已有浏览器 fixture 定向验证，安装版视觉仍由用户验收。

同轮多段气泡、顶部“形象 + 姓名 + 工作状态”和消息尾部活动指示统一遵循[对话交互](../06-superagent/对话交互.md#顶部身份与活动指示)。活动动效占位稳定、范围轻微，工具工作使用紧凑标签；减少动态时保留静态状态。聊天顶部不嵌入完整 HTML 名片，不为状态额外套大卡片。

| 项目 | 现有基线 |
| --- | --- |
| 共享间距单位 | `0.25rem`；常用组合为 4 / 8 / 12 / 16 / 24px |
| 紧凑侧栏、辅助说明 | 12px；工作台基础与按钮 13px；内容正文按既有页面使用 13–14px |
| 折叠标题与说明 | 标题 14px、字重 550、行高 1.5；说明 12px |
| 通用弹窗标题 | 20px、字重 600、行高 1.4；正文说明 13px、行高 1.65 |
| 默认按钮 | 高度至少 36px，内边距 8px 14px，图文间距 8px，圆角 8px |
| 按钮尺寸 | 小号至少 30px；大号至少 42px；图标按钮宽 36px；移动端保留既有触控尺寸和安全区 |
| 共享圆角 | 6 / 8 / 12px；通用弹窗 14px |
| 焦点反馈 | 2px 清晰焦点轮廓；共享按钮外偏移 3px |
| 文本与背景 | 优先 `--dsw-alias-label-primary/secondary`、`--dsw-alias-bg-base`；共享浅色回退 `#202124` / `#6b6b70` / `#fff` |
| 深色回退 | 主文字 `#ededee`，次文字 `#a3a3a8`，背景 `#19191b` |
| 主动作色 | 优先 `--dsw-alias-state-business-primary` 或 Link 主题；共享回退 `#315be8`，工作台既有回退 `#4d6bfe` |
| 工作台状态色 | 运行/连接 `#438bea`，完成 `#36a36b`，等待 `#b98824`，失败 `#d05c5c`；同时提供图标和文字 |

共享主题变量优先于硬编码回退；上述两种主色回退是现有不同容器的兼容值，不允许据此另造页面主题。边界线和悬停底色使用主题混色，延续明暗模式与减少动画偏好。

**可用性与选中状态分离。** 工具、供应商或连接器已安装且真实可用时显示品牌色，不可用时显示灰色；不能因为选中而变成可用颜色。选中使用单层底色、轮廓或文字强调，连接状态另行显示；保存了 `enabled` 不代表认证成功或服务可用。

## 四态

| 状态 | 必须呈现的内容 |
| --- | --- |
| 空 | 居中图标或 SVG、一行标题、一句说明；有下一步时给行动入口，不只放左对齐“暂无”裸文本 |
| 加载 | 首载使用居中逐字动效文字；后台刷新保留内容，不白屏、不闪烁跳版 |
| 错误 | 说明发生了什么、必要的真实原因与重试入口，不只显示原始错误码 |
| 有数据 | 任务列表提供标题、摘要、状态图标或徽章、时间；信息层级清楚，状态不只靠颜色区分 |

对话侧栏是紧凑导航：单行标题，右侧时间和状态，不显示摘要。悬停或键盘聚焦时显示置顶、归档、更多操作，图标规格和圆角一致，操作区背景透明；触屏仍有可达入口。

侧栏先呈现快捷操作，再呈现官方「工具」「自动化任务」入口；宽栏双列、收起后纵列，视觉顺序与键盘顺序一致。普通项目和最近会话继续共用列表，不因入口布局调整删除未分组会话；Router 主旁聊由 SuperAgent 收纳；Worker 与官方子代理在工作台侧栏及普通列表可见并支持直接输入。

## 共享组件与表单

既有实现采用 React JSX + esbuild、本地维护的 shadcn/ui 组件组合、Radix 行为基础与按需 Tailwind v4。公共组件位于 `plugins/shared/client/ui/`；shadcn `new-york` registry 组合的参考校对日期为 2026-11-03，适配源码保留 MIT 许可，不额外安装一套插件。

- 普通动作使用 `Button variant="ghost"`，主要提交用 `default`，危险动作用 `destructive`。
- 普通按钮默认不提交；表单提交显式设置 `type="submit"`，禁用与忙碌状态遵守真实操作状态。
- 即时生效的布尔设置复用官方 `Switch`：左侧标题与一句简短说明，右侧固定尺寸开关；辅助状态和试听等次级动作放在下方紧凑一行。不用裸复选框代替开关，不把同一设置重复写成标题和标签，也不在每项外再套卡片。存储位置等实现细节仅在影响用户操作时解释。
- 表单的通用宽度、内边距与背景仅适用于文本输入，不得污染 checkbox、radio、Switch 或官方会话控件；组件的焦点轮廓应围绕控件本身，不得撑满整行。
- 折叠使用 `Disclosure`：完整标题行、右侧 Chevron、悬停和焦点反馈；可用受控或默认展开状态，展开区不重复嵌套卡片。
- 分段控件只保留单层选中底色；输入框、独立内容边界和浮层按需要使用边框。
- 折叠内容可能卸载，必填校验基于完整草稿；错误时展开对应区域，不能只依赖隐藏字段的浏览器校验。
- 定时、审批、提问等可操作事件使用与宿主一致的卡片。动作审批先由 Router 自然提醒，原官方卡挂在提醒处随对话流，不置顶、不弹窗；「任务 → 审核」聚合同一批待审批项并可跳到对应卡片，只作兜底、不替代提醒。三层呈现与归属唯一正文见[对话交互](../06-superagent/对话交互.md#权限与安全输入交互)。最终交付由 Router 用自己的话作为普通助手消息主动发出，不另套“交付通知”外框或已读操作。
- Router 主聊和旁聊由 Router 自行组织结论、提问和必要说明，不固定报告、标题前缀或系统状态文案；真实提问与授权卡保留。工单与看板提供真实状态、执行摘要及同一真实执行会话的入口。Router 保留专属窗口入口，Worker 与官方子代理在工作台侧栏及普通会话列表可见并可直接输入；执行会话复用官方渲染与输入，服务判定只读时明确说明并提供原工单入口；具体入口、收纳与验证边界遵循[任务列表交互](任务列表交互.md)。失败事实在任务列表与详情如实显示，不能用模型推测替代。
- 渠道会话沿用工作台的会话列表、消息流和回复入口，附来源标记；即使呈现为旁聊也不另建渠道专属会话实现或第二份对话状态。用户打开后可直接回复，发送与回执显示真实状态；能力差异按适配器声明呈现。统一机制及待实施边界见[链接与渠道](../06-superagent/链接与渠道.md)。

`plugins/benchgo/scripts/shared-ui.mjs` 扫描 `bg:` 前缀工具类并编译主题，不加载 Tailwind preflight 或全局元素重置。动态拼接类名不能假定被扫描；插件构建保持 React external，Link 明确统一 React 解析位置。共享样式按使用者计数挂载，热加载更新，最后一个使用者卸载后清理。

选择器与配置语义见[统一选择器](统一选择器.md)，任务业务列表与详情见[任务列表交互](任务列表交互.md)。

## 实现与验收边界

共享组件与样式已有实现。旧页面是否全部符合本规范，应按真实入口核验，不能由统一组件或构建成功推定。

客户端改动完成重建后，逐页自查空、加载、错误、有数据四态的实际渲染；设置控件按真实业务覆盖关闭、待启用、启用中、成功和失败，不强造无意义的空态。移动触控、安全区、焦点、弹层与折叠表单须检查实际交互。浏览器验证必须使用实际页面容器、全局样式和真实组件样式，并包含邻近内容，检查桌面/窄屏、明暗、对齐、尺寸和换行；孤立组件能点击、没有横向溢出不代表视觉合格。交付前查看截图，不能只凭断言或构建成功宣称视觉通过。最终视觉由用户验收。

重建与加载流程见[源码架构](源码架构.md#构建与开发)。
