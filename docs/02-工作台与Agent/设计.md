# 工作台与 Agent 设计

本文件维护板块范围与设计导航。各小模块独立维护一份设计，公共规则通过链接引用，不在板块总览重复。整体关系见[总架构](../总架构.html)，SuperAgent 的任务业务见[总助手设计](../06-superagent/设计.md)。各设计区分既有实现、设计约束与待完成边界，不以历史测试数量代替当前验收。

## 产品范围与入口

BenchGo 工作台承载项目与会话导航、Agent 接入、公共设置、模型与工具、统计和更新；SuperAgent、Voice、Link 在同一产品体系内提供各自入口。桌面和移动端沿用同一品牌、共享组件与授权服务。

用户的主要路径是进入工作台、选择项目或会话、使用对应 Agent、查看任务进展与产物，再返回原会话继续。设置中显示真实安装、连接与能力状态；服务缺失或停用时保留必要说明和配置入口，不伪装成可操作能力。

主聊天、旁聊、任务、产物和设置应有明确入口与返回路径。切换列表、打开详情、返回页面不丢失位置或未保存草稿。桌面复用官方工作台接入点，Windows 启动页由 `scripts/desktop/renderer/` 维护，不修改官方欢迎页。
