# 统一产物预览服务

状态：已实现。Desktop 与 Link 复用公共预览界面及现有受授权文件接口，不新增任意路径或 URL 读取能力。公共交互与格式边界见 [产物快览](./产物快览.md)。

MD、JSON、Excel、DOCX、HTML 在浏览器按需解析；PDF 复用 PDF.js，图片与音视频复用浏览器能力。HTML 使用无脚本、无网络权限的 sandbox，原文件仍可下载。Excel 为数据快览，不承担公式计算及完整 Office 排版。

PPT/PPTX、DOC/ODT/RTF 使用可选 LibreOffice 转 PDF，默认安装不捆绑转换器。现有 artifact 与 system-file GET 接口增加 `preview=pdf`；成功返回 PDF，失败返回明确错误及状态码，客户端保留原文件下载入口。未安装返回 503 与 PREVIEW_CONVERTER_UNAVAILABLE；不支持格式返回 415。

转换仅接收已通过既有根目录、符号链接、文件大小检查的字节。进程使用独立临时用户目录、无 shell 参数传递、隐藏 Windows 窗口，60 秒超时；串行转换、最多 8 个待处理请求，相同输入合并。缓存以内容哈希、扩展名与 LibreOffice 版本为键，内存 LRU 上限 64 MiB，单个输出最多 25 MiB，临时目录在成功和失败时均删除。缓存仅在当前进程存在。

HTTP 是人端读取契约，不新增 MCP 文件读取工具，避免扩大模型权限。Link 继续复用已授权工作台 API 透传。

参考成熟实现：LibreOffice 官方 headless `--convert-to pdf`；浏览器侧由统一客户端适配器承担格式解析，不引入整套 Office 编辑器。

`BENCHGO_LIBREOFFICE` 可指定转换器可执行文件；未指定时搜索系统安装位置和 PATH。环境中未发现 LibreOffice，本轮已验证模拟转换、错误分支、缓存、并发和清理，未验证实际 Office 到 PDF 的转换保真度。强制终止宿主进程可能留下系统临时目录，正常成功、失败与超时均清理。
