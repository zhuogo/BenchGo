# BenchGo 前端组件与视觉规范

## 已实现（2026-11-03）

沿用 React JSX + esbuild，采用本地维护的 shadcn/ui 组件组合与 Radix 行为基础，按需编译 Tailwind v4。公共组件在 `plugins/shared/client/ui/`，不是额外安装的插件；最终仍发布一个 `benchgo-plugin`。组件接口、上游参考和许可见该目录的 README。

本轮整理覆盖 BenchGo 主工作台、模型与供应商、工具与技能、统计与更新，SuperAgent 首页、任务工单、连接、模型、身份宠物、产物文档、记忆与系统文件，以及 Voice、Link 桌面与移动界面、Windows 启动页。官方界面继续通过已有适配入口复用，不修改官方子模块。

## 视觉规则

以下保留 2026-11-03 组件整理约定；视觉与验收以 2026-11-04 [前端视觉规范](前端视觉规范.md)为准，适度阴影、渐变与状态色按产品需要使用。

- 页面标题、分组标题、工具栏和保存操作区不因包含按钮而增加灰色外框。层级主要来自对齐、间距、字号与字重。
- 分段控件保留单层选中底色，不在外面再套容器。组件可用性颜色与选中状态分离。
- 普通动作使用 `Button variant="ghost"`，主要提交使用 `default`，危险操作使用 `destructive`。表单提交必须显式声明 `type="submit"`，普通按钮默认不提交表单。
- 折叠使用 `Disclosure`：完整标题行、右侧 Chevron、悬停与键盘焦点反馈；可选 `description`、受控 `open/onOpenChange` 或 `defaultOpen`。展开内容不套重复卡片。
- 输入框、真正独立的内容边界及浮层可以使用边框；阴影与层级表达遵循现行视觉规范，不限于浮层。
- 延续现有品牌、宿主主题和明暗模式，保留移动触控尺寸、安全区与减少动画偏好。

## 构建与维护

`plugins/benchgo/scripts/shared-ui.mjs` 扫描客户端中的 `bg:` 工具类，编译内联主题变量，不加载 Tailwind preflight。不要添加全局元素重置，也不要把动态拼接的工具类当作扫描器可以自动发现的类名。

插件构建保持 React external，Link 构建显式统一 React 的解析位置。共享样式按使用者计数挂载，热加载时更新内容，最后一个使用者卸载后清理。

业务配置、供应商模型 ID 与协议值不因 UI 整理改写。折叠内容可能卸载，必填校验应基于完整草稿进行，并在错误时展开相关区域；不能只依赖隐藏字段的浏览器校验。

修改客户端后运行 `npm run reload:plus`，生成统一客户端、模块与 Link 网页；浏览器刷新获取页面。不要为此重启 Web 或生成服务器种子包。

## 验证边界

共享组件测试覆盖默认按钮不提交、显式提交与禁用、asChild、折叠的可访问状态与内容隐藏，以及构建复用宿主 React。各页面原有交互测试继续检查配置、任务和连接流程；浅渲染的组件 mock 只验证业务边界，不能替代 Radix 的浏览器交互验证。

2026-11-03 当次按用户要求未进行视觉验收，也未启动图形应用。该历史记录不豁免后续前端变更的空、加载、错误、有数据四态实际渲染自查；完整交互与最终视觉效果由用户验收。
