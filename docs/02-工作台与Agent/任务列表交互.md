# 任务列表交互

主对话侧栏采用两行任务卡片：第一行是名称和时间，第二行是状态和摘要；整项可点击打开详情弹窗，长内容在列表中省略、在详情中完整展示。停止操作收进详情，不设独立「查看记录」按钮或「审核」分页。任务通过自动核验后直接完成，报告自动发送到原会话，无需用户再次确认；执行中需要补充信息或权限时仍显示真实等待状态。

工单、持续目标、待处置评估共用 `plugins/superagent/client/task-list.jsx` 的摘要行和详情容器。列表只展示完成勾选框、名称、两行摘要与右侧图标操作；标题和摘要是详情入口。暂停、继续、重开、重命名和删除使用带可访问名称、悬停说明的图标按钮，触屏保留常驻入口。

## 操作与执行的边界

- 重命名修改列表名称，保留原始任务要求、目标和消息。
- 人工完成是整理标记，不能充当自动验收通过的证据；已自动完成的记录沿用其验收状态。
- 取消人工完成标记不会自动重新执行。重新执行继续使用原来的工单重开、目标恢复或重新评估流程。
- 删除从列表移除，保留执行与处置历史。仍可能执行的条目须先安全停止，不能删除列表记录后继续后台执行。
- 修改持久化并校验版本，旧页面不能覆盖更新后的名称或标记。

详情保留工单问题答复、要求修订、证据、文件检查点、目标预算及评估处置入口。关闭详情与切换分类继续保护未保存草稿。

源码实现与验证以本轮交付为准；不变更官方引擎，不替代原有调度、预算和验收机制。
