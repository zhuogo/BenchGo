# 任务列表交互

板块入口见[工作台与 Agent](设计.md)。 本文维护任务列表与详情的用户操作；调度、授权、自校验与交付机制见[SuperAgent](../06-superagent/设计.md)。

## 列表与详情

主对话侧栏的任务卡采用两行：名称与时间、状态与摘要。整项可打开详情，长内容在列表中省略、在详情中完整显示；停止入口放在详情，不另设“查看记录”按钮或“审核”分页。这里的任务卡不同于[视觉规范](前端视觉规范.md#四态)中的单行会话导航。

工单、持续目标、待处置评估复用 `plugins/superagent/client/task-list.jsx` 的摘要行与详情容器。业务列表包含完成标记、名称、最多两行摘要和右侧图标操作；标题与摘要都可进入详情。暂停、继续、关联调整、重命名、删除提供可访问名称与悬停说明，触屏保留入口。

- 重命名只改列表名称，保留原始要求、目标和消息。
- 人工完成是整理标记，不等于成功送达或系统关单；取消标记不能自动重新执行。
- 对成功交付结果的调整新开关联调整单，不改原单；结构性失败关单后，用户回话可在原单继续或调整并保留历史结果；未关闭工单按原单继续、持续目标按恢复流程、准入评估按重新评估流程处理，不绕过授权或重放已生效动作。
- 删除只移出列表，保留执行及处置历史；仍可能运行的条目须先安全停止。
- 修改持久化且校验版本，旧页面不能覆盖新名称或状态；切换分类和关闭详情保护未保存草稿。

详情保留问题答复、要求修订、实际证据、文件检查点、目标关联与准入评估处置入口。不设独立任务内容验收：每次派工固定要求 Worker 在原上下文快速轻量自检，优先适用的机械测试、构建和输出检查；正式结果写工单后直接交付原来源并带标题，Router 默认仅收状态，用户终审。成功成果确认送达后 completed 关单，正常原来源交付免审批；投递失败保留待交付且只补投结果。偶发故障退避；结构性失败报告列明尝试、死因和可变条件，送达后 failed 关单，用户回话可原单续做或调整。缺少信息、权限或范围决定时显示真实等待状态；执行超时先核实运行并从 checkpoint 原单恢复，外部效果未知先核实、禁止盲重跑。具体机制见[自校验与交付](../06-superagent/自校验与交付.md)。目标仍可跟踪，用量仍可统计；金额、执行时长和 Goal 补时预算闸门已移除，不再展示旧预算操作。

## 执行会话入口（待实施）

实际 Worker 执行会话显式归入所属项目的工作区会话列表，不涉及项目的任务归“最近”工作区，均带工单标记，与用户自建对话区分。主聊天工单和任务详情提供进入执行会话的入口；各入口跳到同一个官方 session，不复制出第二份聊天。会话标题、工单归属与执行状态取真实记录，缺失时提示无法定位并保留工单详情入口。

用户以在执行会话直接插话为常态，与 Router 转来的跟进共用原工单输入账本、顺序和消费状态。普通调整下一工具边界整份切换，不打断在途工具；暂停只收件不续跑，越权要求交 Router 确认或分新单。执行会话可收起；工单结束后自动沉底或归档进工单记录，保留同一会话、消息和成果入口，不能删除执行证据或仍显示为活动执行。交互规则见[执行会话与直接插话](../06-superagent/对话交互.md#执行会话与直接插话待实施)。

来自渠道会话的同单输入也复用这一本工单账，任务列表的状态、投递记录与关单事实均读取统一记录，不维护渠道侧副本。渠道会话在工作台列表带来源标记，可打开并直接回复；其呈现与适配器分工见[链接与渠道](../06-superagent/链接与渠道.md)，该路径仍待实施。

## 聊天任务线与执行动态

聊天中的助手看板沿用两行任务摘要：名称与任务更新时间、状态与当前活动。有可核实的子 Worker 时固定显示“子任务 已返回数/总数”，活动过长先截断，子任务数量保留。工具活动不改变列表排序，避免执行时任务持续跳位。

打开工单详情，以简约纵向任务线展示主 Worker 与缩进的直接子 Worker：当前动作、运行、等待、已返回、失败、停止或未知。时间在执行动态处汇总，单个子任务结束只表示返回父 Worker；执行、Worker 自校验、待交付与已送达分别展示，不设置独立内容核验阶段，不据工具成功或子任务结束推算工单完成，不显示猜测的百分比或剩余时间。工具参数、原始输出、模型思维与凭据不进入任务线。

看板打开且存在未结束任务时共享约两秒一次的刷新，其他情况约十秒，页面隐藏时停止轮询；刷新失败保留最近记录并提供重试。暂停、停止、终态或过期数据明确显示为最近执行记录，不能将旧“运行中”冒充当前状态。重启后未加载的历史、缓存淘汰或无法关联的子任务明确提示记录不完整，不把未观测当作零任务。

详情中的“前往任务管理”定位原工单，复用提问答复、暂停与修订入口。普通调整插话即记入原工单输入账本，后台编号记账，Worker 在下一工具边界把新要求整份切换生效，不打断在途工具，不增加确认或先暂停/停止流程；暂停期间只收修订，不自动续跑。叫停和收权立即拦截后续动作；只有超 Mandate 扩权才由 Router 确认并生成新授权版本。任务线只读展示执行事实，不另建任务控制流程。执行观测边界见[任务与执行](../06-superagent/任务与执行.md#执行动态观测)。

## 实现与验收边界

共享摘要行与详情容器已有实现，任务的业务状态仍以实际服务返回为准，不能用人工整理标记替代执行结果或交付状态。2026-11-08 确定的无独立任务验收、固定轻量自检、原结果直投、送达后关单、结构性失败报告与原单恢复、插话整份切换，以及执行会话入口、标记和收纳均为待实施目标。

验证列表入口、触屏操作、详情返回、长内容、停止、问题答复、修订、重命名、完成标记和删除；检查并发版本冲突及未保存草稿保护。逐入口检查[四态实际渲染](前端视觉规范.md#四态)，浅渲染通过不代表真实交互完成验收。

动态任务线已有组件与运行时接线，需验证主、子 Worker 状态原位更新、子任务失败、自校验与交付区分、结构性失败报告送达关单及原单续做、暂停旧记录、读取失败重试，以及窄屏和明暗主题。补验项目/最近列表工单标记与任务详情均跳同一执行会话、直接插话共用输入账本、下一工具边界整份切换且不打断在途、暂停不被修订唤醒、越权交 Router、结束后收纳、成功交付调整新开关联单和投递重试不重跑任务。审批另验支付购买、改密码、删账号、另行对外发送逐次审批不被整站覆盖，原来源回复免审；整站范围、期限、审计和撤销遵循[权限规则](../06-superagent/任务与执行.md#权限与对外审批)。既有浏览器验证使用真实组件与合成 API 数据；正式桌面真实工单的运行验收与海量任务性能仍需单独验证。
