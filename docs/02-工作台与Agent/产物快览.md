# 产物快览

板块入口见[工作台与 Agent](设计.md)。 本文统一维护快览交互、格式能力、授权文件接口与可选转换服务；视觉遵循[公共规范](前端视觉规范.md)。

## 已有实现与交互

Desktop 与 Link 共用 `plugins/shared/client/artifact-preview.jsx` 和既有受授权文件接口，在产物卡片、列表和系统文件中只读快览。共享组件是唯一预览入口，按扩展名选择渲染器。不引入在线编辑器、任意文件路径/URL 读取能力或外部文档上传服务。

点击文件进入内容页，顶部保留返回、文件名、下载原文件；返回恢复列表位置。正文占主要区域，加载、错误、重试和格式限制在正文区呈现。移动端只展示当前内容，表格在自身区域滚动，沿用品牌字体、主题和按钮。

| 格式 | 渲染与能力边界 |
| --- | --- |
| Markdown | Marked + DOMPurify，支持 GFM，过滤主动内容，可切换原文 |
| JSON | 原文或按需展开树；逐层分页，避免一次创建巨大 DOM |
| XLS/XLSX/CSV/TSV | SheetJS + Worker，工作表切换、搜索、虚拟行、单元格原值；只读已保存结果，不执行公式，不承诺图表/透视表和完整样式还原 |
| DOCX | docx-preview，在隔离 iframe 中排版；失败可尝试 PDF 备用预览 |
| PDF | PDF.js 按页渲染 |
| PPT/PPTX/DOC/ODT/RTF | 可选本机 LibreOffice 转 PDF；默认安装不捆绑转换器 |
| HTML | 无同源权限的 sandbox iframe；禁止脚本、网络、表单与跳转，只预览自包含页面，明确提示外部资源限制 |
| 图片、音频、视频 | 复用浏览器原生展示 |

HTML 完整交互只能下载原文件后打开，不提供宿主内脚本开关。HTML、DOCX 不插入宿主 DOM，文档内容不能读取宿主凭据。

重型解析器作为独立本地 ESM 静态资源，经基础层授权路由按需加载，不进入首屏客户端包，不使用运行时 CDN。直接依赖成熟库，不复制其实现；保留许可证，随唯一插件发布。

| 库 | 既有固定版本与来源 |
| --- | --- |
| Marked | 18.1.2，`markedjs/marked` |
| DOMPurify | 3.4.17，`cure53/DOMPurify` |
| docx-preview | 0.4.1，`VolodymyrBaydalka/docxjs` |
| SheetJS CE | 0.20.3，`git.sheetjs.com/sheetjs/sheetjs` |
| PDF.js | 5.4.624，`mozilla/pdf.js` |

## 文件和资源边界

沿用授权、根目录、符号链接与文件大小检查。文本快览上限 2 MiB，Office 输入上限 25 MiB，ZIP 声明展开内容上限 64 MiB / 4096 项，表格上限 10000 行 / 100 列；截断或限制必须说明。关闭预览时中止读取、终止解析 Worker、释放 PDF 资源。

现有 artifact 与 system-file GET 接口使用 `preview=pdf` 请求转换。成功返回 PDF；未安装转换器返回 503 / `PREVIEW_CONVERTER_UNAVAILABLE`，不支持格式返回 415；客户端保留原文件下载。HTTP 变更同步 OpenAPI，不新增 MCP 文件读取工具。Link 透传已授权工作台 API，不扩大远端权限。

转换只接收已经通过文件检查的字节。调用 LibreOffice 使用独立临时用户目录、无 shell 参数传递、隐藏 Windows 窗口；60 秒超时，串行转换，最多 8 个排队请求，相同输入合并。

缓存键包含内容哈希、扩展名和 LibreOffice 版本；进程内 LRU 上限 64 MiB，单份输出上限 25 MiB。成功、失败和超时清理临时目录；宿主被强制终止仍可能遗留系统临时目录。`BENCHGO_LIBREOFFICE` 可指定可执行文件，否则查找系统安装位置和 PATH。

## 实现与验收边界

快览组件和转换服务已有实现，LibreOffice 可选能力缺失时的提示已有实现；真实 Office 转换、复杂文档保真度和各端最终视觉不能据模拟结果认定通过。

按格式验证真实内容解析、返回位置、原文件下载、加载/错误/重试、限制提示与资源释放；按服务验证授权、根目录与符号链接边界、缓存、串行与队列、超时清理和 Link 透传。测试样本通过不代表复杂文档或真实设备已经验收。
