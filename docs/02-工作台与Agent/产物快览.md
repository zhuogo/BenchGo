# 产物快览

## 目标与边界

状态：已实现。在 BenchGo 产物卡片、列表及系统文件中直接查看文件；Desktop 与 Link 工作台使用同一组件与授权文件接口。只读快览，不引入在线编辑器或外部文档上传服务。本设计先于实现创建，验证范围见文末。

## 交互

点击文件进入内容页，顶部固定保留返回、文件名、下载原文件；返回恢复原列表位置。移动端只显示当前内容，表格在自己的区域滚动。沿用 BenchGo 字体、主题和按钮，不另建视觉体系。主问题是“这个产物的内容是什么”，正文占主区域；加载、错误、重试与格式限制在正文区显示。

界面参考 design-taste-frontend 的 framed-sheet 方向（seed 786454071），保留现有工作台壳层及品牌字体/配色；文档以独立白色内容区承载，表格使用原有主题，不添加装饰或示例业务数据。

## 共用实现

- `plugins/shared/client/artifact-preview.jsx` 是唯一预览入口，按扩展名选择渲染器。
- 重型解析器构建为独立本地 ESM 静态资源，通过基础层授权路由按需加载，不进入首屏客户端包；不使用 CDN 运行时脚本。
- MD：Marked + DOMPurify，支持 GFM；禁用主动内容，提供原文切换。
- JSON：原文与按需展开树；每层分页，避免一次创建巨大 DOM。
- XLS/XLSX/CSV/TSV：SheetJS，Worker 解析，工作表切换、搜索、虚拟行与单元格原值；读取已保存结果，不执行公式。不承诺图表、透视表及完整样式还原。
- DOCX：docx-preview 排版，隔离 iframe 呈现，失败可尝试 PDF 备用预览。
- PPT/PPTX/DOC：可选本机 LibreOffice 转 PDF；PDF.js 按页渲染，不捆绑转换器。
- HTML：无同源权限的 sandbox iframe，禁止脚本、网络、表单与跳转；仅预览自包含页面，外部资源限制明确提示。完整交互通过下载原文件后打开，不提供宿主内脚本执行开关。
- 图片、音频、视频复用浏览器原生展示。

文件读取沿用现有权限、根目录限制与大小上限。文本快览限制 2 MiB，Office 输入限制 25 MiB，ZIP 中声明的展开内容限制 64 MiB/4096 项；表格限制 10000 行与 100 列并明确提示。关闭后中止读取、终止解析 Worker、释放 PDF 资源。HTML/DOCX 不插入宿主 DOM，文档脚本无法获取宿主凭据。
