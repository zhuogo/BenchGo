# 跨设备资源导航

板块入口见[工作台与 Agent](设计.md)，图示见[架构图](架构.html)。本文是侧边栏跨设备「项目 / 最近」的界面与交互正文；设备授权、资源身份、查询和执行归属统一见[跨设备协作](../01-设备与远程连接/跨设备协作.md)，公共视觉与四态遵循[前端视觉规范](前端视觉规范.md)。

**实施状态：源码已接通，已验证本机至襄阳服务器的资源打开与页面复用，完整用户路径待验。** 侧栏已支持当前设备、全部、指定设备，范围服务端持久化；项目按设备分组，最近保留源候选后聚合。远端内容复用目标 Link 工作台，入口侧栏和本地草稿保留。浏览器 fixture 已覆盖空、加载、错误、有数据、明暗及窄屏；实机验证未发送消息或启动模型执行，不代替两台真实设备的完整用户验收。

## 显示范围与入口

在侧边栏「项目 / 最近」共同的工具区提供紧凑的「显示范围」入口，当前值始终可辨；收起侧栏、窄屏与触屏仍有可达入口。复用既有共享菜单、选择和设置反馈，不新建一套设备管理页。该设置统一作用于两个列表，不分别维护相互冲突的设备集合。

| 选项 | 含义 |
| --- | --- |
| 当前设备（默认） | 当前工作台所属设备；手机或浏览器访问 B 时指 B，不指浏览器所在手机或电脑 |
| 所有已连接设备 | 当前设备，加上设备目录中已保存并授权的设备；「已连接」指建立了连接关系，包含暂时离线条目，不只筛选此刻在线设备 |
| 指定设备 | 从同一设备目录勾选设备，保留其稳定 ID；未选择时说明「请选择设备」，不暗中改成全部设备 |

显示范围按入口工作台的用户配置持久保存，重新加载后恢复；设备名只作展示，改名不丢选择。保存失败保留草稿并给重试入口，不能伪装成已保存。修改本项保留已有搜索、归档、折叠和其他配置；旧版本首次使用默认当前设备，不自动打开所有设备的查询。

当前设备与所有设备范围始终包含已加载的本机项目和最近，不等待设备目录成功；只有指定设备的显式选择可隐藏本机。目录加载失败保留原列表，使用紧凑图标提示并按下文退避规则自动重试，图标保留手动重新连接入口；范围保存失败单独提供「重试保存」。远端读取失败不清空已取得的有效列表。

筛选只改变可见列表，不授予设备权限、不切换项目执行位置，也不限制 SuperAgent 按用户要求查询其他已授权设备。通过现有设备切换入口切换整个工作台时，显示所属工作台及其配置；在聚合列表打开远端条目，不隐式切换当前显示范围或主助手会话。

源码已接通：A 的 Router 受理任务后，业务工单始终归 A；在 B 的项目执行、打开 B 的会话、进入 B 的完整工作台或改变本列表显示范围，均不转移工单。项目/会话的所属设备与工单宿主分别呈现，B 只有该工单关联的执行实例，不在 B 的任务列表重复建单；B 无需启用 SuperAgent。B 的受委托执行会话当前只读并可返回 A 原工单，任务入口与四态验证边界统一见[工单宿主与远端执行](任务列表交互.md#工单宿主与远端执行)。

以组成员身份打开远端工作台时，侧栏同样提供显示范围设置，可选当前、全部组内设备或指定设备。范围保存在当前工作台所属主机。Windows 桌面切换到资源所属设备后打开选中的项目或会话，并保留原工作台页面和草稿。独立配对会话只显示所属主机的资源；独立浏览器跨域嵌入其他组员工作台受网关和页面内容安全策略限制。

Windows 桌面首次启动打开本机。成功切换后，下次启动自动打开上次使用的工作台。远端恢复失败时提供重试与返回本机，主动返回本机后下次启动进入本机。切换器只显示当前工作台和连接状态。

远端页面先读取项目列表和模块可用性，确认总助手启用后立即读取其状态。项目和总助手状态的首轮读取结束后，页面空闲时加载方圆字体，期间使用系统字体。文件、Git、终端和预览的本机适配脚本单独构建，仅由本机工作台加载。

桌面代理发现工作台会话过期或被淘汰时，沿已验证的路线使用原配对重新取得会话。同一代理的并发请求共用一次续签，页面和草稿继续保留。首屏状态查询和 GET、HEAD 可自动重试一次，写入由用户确认后重新发起。配对已撤销时提示重新配对。

## 项目与最近的呈现

- **项目**按设备分组，可折叠；当前工作台所属设备置前，其余沿设备目录顺序。组标题显示真实设备名称与可达状态，项目保留既有会话层级和活动标记。同名项目不合并；有歧义时提供所属设备和项目路径的可聚焦提示。
- 本机与远端共用项目标题和会话行组件。点击项目名称或箭头只展开/收起，Enter、Space 等价；「＋」才在所属设备新建。会话行共用 Harness 品牌图标、真实活动状态、选中反馈与更多入口，远端额外保留设备归属；同名、同 ID 不调用本机操作。
- **最近**聚合各设备原有的最近候选：默认工作区会话及未分组会话，合为一份列表，不按设备分组展开。默认工作区按所属主机持久化的工作区身份识别，其会话进入最近，`default-workspace` 不作为项目展示；真实同名用户项目不按标题误排除。它不是所有项目会话的活动榜；不因聚合把已归属项目的会话重复收进最近。Router 入口与 Worker、官方子代理的既有可见性规则保持一致。
- 最近列表保留既有置顶优先规则，其余按来源活动时间近似倒序合并；每条显示设备标记，平局以稳定资源身份保持顺序。置顶、归档等状态仍来自所属设备，不在入口工作台再维护一份业务状态。
- 来源活动时间与本次观测时间分开。设备时钟未同步时不能承诺严格的跨设备全局时序；时间缺失或明显异常时提供提示并稳定排列，不使用本次刷新时间伪造会话活动，不改写源记录。
- 列表继续使用紧凑单行标题与时间、状态；设备标记不挤掉主要标题。悬停与键盘聚焦可查看完整名称及归属，触屏提供等价入口。选中反馈和真实可用性分离，已保存、已选中都不等于可连接。

资源唯一身份、查询覆盖与分页契约见[资源身份与查询](../01-设备与远程连接/跨设备协作.md#资源身份与查询)。前端缓存、选择、高亮及跳转都携带设备身份和原始资源 ID；不按名称、路径相同或未经限定的 sessionId 合并不同设备的条目。

目标会话与最近目录使用窄摘要查询，不读取模型目录；同一次查询共用一份项目快照。官方会话构建会话 ID 到首个所属项目的索引，原生会话按项目 ID 与原始路径精确核验；保留私有会话、子会话、归档和未注册会话的既有可见性及来源顺序，不跨请求缓存项目归属，实际操作仍实时复核。

## 打开、创建与操作

点击 B 的项目标题在侧栏展开/收起；点击其中会话，在当前工作台的内容区打开 B 的对应资源，保留聚合侧栏、筛选、滚动位置和原会话草稿；不另加返回、设备名称或远端资源顶部栏，通过已有设备切换入口返回或切换完整工作台。桌面设备中心点击设备也关闭面板并复用同一工作台切换器，不再打开第二层工作台。复用官方会话组件与已有 Link 会话接入，不复制完整聊天或创建本地替身会话。仅打开列表或会话不恢复归档、不启动执行、不重放消息。普通项目打开请求只允许打开既有会话；空项目明确提示使用新聊天，不再隐式创建。

已实现：导航列表的可见性与当前工作台生命周期分离。展开/收起本机或远端项目、设备分组、项目/最近区，以及搜索、显示范围、归档切换、后台刷新、临时离线和切回前台，均保留已打开的远端工作台文档、草稿与阅读位置，不重新领取入口或重放打开请求。

聚合侧栏点击本机会话、新聊天或工具面板时退出远端资源层，再执行本机原有导航；SuperAgent 主聊、旁聊及同一面板再次选择同样恢复本机内容。明确移除目标设备、授权失效或删除当前目标资源仍释放远端内容。原本机草稿保持可编辑。取消添加项目时保留当前远端内容；成功添加后在项目所属设备打开新会话。

PC 桌面托管远端工作台时，只保留标题栏「应用」左侧的原生侧栏按钮，控制当前显示设备的展开/收起并同步可访问标签；远端页面不再显示重复按钮或占位。该原按钮保持在本机内容被隔离时可操作，切回本机恢复本机侧栏语义。只有收到可信桌面父窗口声明的嵌入页才隐藏自身入口，独立浏览器与手机继续保留原有侧栏控制。

项目内「新聊天」绑定该项目所属设备。「添加项目」直接打开一个弹窗：桌面宽约 480px，紧凑设备选择器与「文件夹 / GitHub」位于同一行，设备状态放在选项中，不另加环境说明；窄屏保持同排并截断过长设备名。下方复用已有磁盘、目录搜索与提交区；不先弹设备列表，也不因切换设备重新打开弹窗或提前切换整页工作台。设备选项来自已授权目录，显示范围只决定初始值，不限制可创建的设备：范围内仅一台时默认该设备，否则默认当前工作台。开始选择后，后台刷新不能替用户更换目标；设备消失时清除可提交内容并提示恢复。

设备切换后重新读取目标目录，清空旧目录、磁盘与搜索状态，丢弃旧请求结果；保留用户选定的添加方式和仓库地址。提交期间禁用设备切换和关闭。远端目录不能误用入口电脑的系统文件夹选择器；系统选择器只在当前平台确实能选择目标主机目录时显示。设备可用性按真实状态着色，与选中反馈分离；没有设备、读取失败、连接中均在同一弹窗呈现，并给设备中心或重试入口。

已实现：目标设备在自身 BenchGo 数据目录持久保存上次成功添加的项目文件夹（包括系统选择与 GitHub 克隆）；下次打开「添加项目」或切换到该设备时，内置目录浏览优先显示该文件夹。仅浏览、取消和添加失败不更新记录，显式目录导航优先；记录不可读、目录已删除或无法访问时回退目标设备用户主目录。记忆写入失败记录日志，不将已成功添加的项目误报为失败。官方 Desktop 系统选择器沿用宿主行为，此记忆控制内置目录浏览的初始位置。

已实现的目录管理在当前目标设备执行。工具栏在当前目录新建文件夹，条目的右键菜单与「更多」提供打开、新建子文件夹、重命名、移到上一级和删除。鼠标按住条目拖动，触屏长按文件夹图标拖动，可将条目移入同级文件夹或拖到「上一级」。操作成功后刷新目录列表。删除确认展示完整路径，提交后永久删除文件夹及其内容。链接条目支持打开，移动和重命名遇到同名目标时保留原目录，已登记项目及其祖先目录受保护。旧版远端仍可浏览和添加项目，目录管理需要目标端同时声明操作能力。

最近区与顶部「新聊天」直接打开当前工作台的空白会话。可选多台设备时，首次发送前在工作区选择器左侧显示设备选择器。选择远端设备后，沿现有远端资源层打开目标设备的空白会话，由目标设备提供工作区、模型和发送入口。首次发送前可切换回本机。首次发送后，设备选择器随新会话工作区入口一同收起。

远端项目表单通过既有授权工作台的窄消息桥调用 `browse / project / clone`；父窗口与 origin 必须同时匹配，按请求 ID 应答并去重。仅传递项目操作所需字段，不开放任意 API 代理、不扩大设备权限；旧目标未声明能力时明确提示升级。关闭或换设备后释放连接与请求，成功后复用目标工作台打开项目新会话。

已实现：本机与远端会话共用置顶、归档快捷按钮、对话菜单、重命名弹窗和删除确认。远端动作通过 `sessionAction` 发送到所属设备，能力来自该设备的 `sessionActions / nativeSessionActions` 声明；操作明确指定置顶/取消置顶、归档/取消归档，不能发送含糊的 toggle。官方会话复用目标的工作区与会话服务，原生会话只启用实际支持的操作；尚无可靠远端分叉能力时禁用并说明原因。复制远端引用始终带设备与原始会话身份。菜单贴合实际触发行，空间不足时先向上或左侧展开，最后才使用窗口边缘兜底。

能力首次加载、读取失败或旧目标未声明时，保留相同的操作入口并禁用写入，菜单及提示说明加载、失败或需要升级目标设备；不回落到同 ID 的本机服务。重命名和删除弹窗标明所属设备，取消不发送写请求。收到与请求身份匹配的确认后刷新最近及已展开项目的权威摘要，保留已加载分页覆盖；失败保留原条目并提示，不伪造成功。每次写入仍由目标复核配对、可见性和项目归属，协议与有界回执约定见[跨设备协作](../01-设备与远程连接/跨设备协作.md)。本机热加载不等于远端已升级，双机真实写操作仍需部署目标端后验收。跨设备批量操作仍不在本轮范围内。

已实现：远端项目复用本机「删除这个项目？」确认弹窗，经原授权项目消息桥的增量 `deleteProject` 能力移除目标工作区注册，不删除项目文件夹或文件。连接回包必须匹配弹窗打开时的设备、主机及配对身份；目标等待既有默认工作区初始化完成，再实时校验项目原始 ID、路径与真实默认项目 ID。初始化失败或默认身份仍未知时拒绝删除并说明原因，不误报成默认项目不可删除。旧目标只禁用新增删除操作，原有目录浏览、添加和克隆能力保持兼容。取消不移除；失败保留条目，超时提示先刷新核验，不自动重放删除。成功刷新项目与最近，并仅关闭该设备该项目正在打开的远端内容。

本机与远端新建会话默认使用官方「完全权限」预设（`danger-full-access`、`approval: never`），由会话所属设备的官方权限服务初始化并写入会话事件；远端入口不另存一份权限。保留只读、工作区写入与完全权限三档，用户显式选择及用户 profile 默认优先，恢复旧会话沿用其已保存权限，不在打开或重连时强制升权。该默认值通过 BenchGo bundle 配置发布，本机热加载须同步实现包与已启用 wrapper 的配置，远端也须更新目标端；既有配对、撤销与来源校验仍独立有效。

项目执行使用项目所属设备的 Harness、文件与环境；对于 A 工单委派给 B 的执行，A 根据 B 公布的真实 Harness/模型能力选择并冻结执行配置，B 使用本机凭据校验执行，不依赖 B 的 SuperAgent 工作模型设置。该链路源码已接通，Link v2 每次冻结一个 Harness 与模型组合，见[项目归属与远端执行](../01-设备与远程连接/跨设备协作.md#项目归属与远端执行)。前端读取 A 工单及其真实执行投影，设备断连不等于任务停止或失败，失联时保留最后已知状态并标明信息可能过期；跨设备执行的物理双机、安装版与真实供应商请求仍待验收。

工作台列表继续按设备定位资源。服务器卡的 SSH 终端和管理连接状态由[SSH 服务器运维](../01-设备与远程连接/SSH服务器运维.md#设备卡与人工终端)维护，工作台资源加载失败时仍可从该入口诊断服务器。

## 数据加载与失联恢复

项目、最近和 SuperAgent 共用设备资源服务，不分别扫描远端目录或维护独立连接。按当前显示范围有界并发查询，单设备慢或失败不阻塞其他设备；首次只读取列表所需摘要，分页与按需详情不拉取全部会话正文或项目文件。

各设备保留独立分页进度、观测时间和错误。界面明确仍在加载、尚有更多或部分设备未返回，不能把已加载的一个分页说成全部结果。最近列表只对已返回候选合并排序；加载更多后保持阅读位置，不让实时更新打断当前操作。

复用现有订阅与可见性刷新机制，同一设备的消费者共享连接；页面隐藏、范围切换和卸载后取消无用请求与订阅。代次或请求标识隔离迟到响应，旧范围的数据不能覆盖新选择。重连按源版本更新元数据，保留同一资源的稳定选中身份，不重复创建会话。

短暂离线保留已授权范围内的有界摘要缓存，启动或恢复可见时自动沿用原配对选路读取资源；瞬断和查询失败按 1、2、4、8、16、30 秒退避，之后最多每 30 秒重试，不并发叠加。侧栏不展示资源查询失败段落，连接与异常使用紧凑图标，原因和设备中心入口放在提示中；不将重试中的设备标为可用。权限撤销、设备移除或用户身份变化后清除相应缓存及可打开引用，不继续展示失效授权下的内容；身份、权限与协议不支持不进入短重试。缓存仅用于导航，实际读取与写入仍由目标服务复核。

## 四态与恢复入口

| 状态 | 呈现与操作 |
| --- | --- |
| 空 | 成功查询后无项目或最近才显示空态；给「添加项目」「新聊天」或调整显示范围入口。未选择设备、没有匹配搜索分别说明 |
| 加载 | 侧栏设备资源以紧凑连接图标表示自动连接，不显示查询失败文案；设备独立返回，已有列表、草稿与位置保留 |
| 错误 | 侧栏以图标及提示说明真实连接、授权或能力原因，需用户介入时可打开设备中心；其他设备继续可用，失败不冒充空结果 |
| 有数据 | 展示设备归属、项目与最近原有层级、活动时间和真实状态；分页、筛选、键盘与触屏操作完整可达 |
| 离线或过期 | 保留合规缓存并自动退避重连；图标提示真实状态，远端写操作不可用且说明原因，已知任务状态标为过期而非改成失败 |

身份或证书变化、重新配对和连接恢复遵循[授权与互通](../01-设备与远程连接/跨设备协作.md#授权与互通)，不由列表自行绕过。普通连接设置也可交给助手，具体路径见[连接与中继管理](../01-设备与远程连接/跨设备协作.md#连接与中继管理)。

## 实现位置与验收条件

实现入口是 `plugins/base/client/index.jsx` 的项目与最近槽位、`resource-creation.jsx` 的添加项目弹窗、`project-picker.jsx` 的复用表单、`plugins/link/client/project-bridge.mjs` 的授权项目消息桥、`resource-navigation.jsx` 的范围、分组及远端内容区域，以及 `resource-state.mjs` 的身份和排序。数据共用 `benchgoLink.resources`；首载与加载更多每页 30 项，后台刷新按已加载覆盖量合并请求、单页最多 100 项（90 项一次读取，120 项分 100 + 20），最多 4 并发。启动自动读取已选范围；成功列表每 30 秒刷新，暂时失败的列表独立退避，不带动健康列表加频。单次读取最多等待 15 秒；隐藏、身份变化、切换范围及卸载取消无用请求，恢复可见立即刷新。已有数据静默刷新并保留已加载的分页覆盖，列表缩短时移除过期条目；无数据期间仅显示紧凑连接图标。每轮结束重读设备状态，状态变化不重启轮询。当前不新增资源事件总线。

远端内容区域嵌入既有目标工作台，父子窗口核验来源和请求身份。接收器安装后主动通报就绪，保留页面加载探测，避免官方壳先完成加载时丢失唯一探测。同一设备内切换资源复用已挂载页面，只发送新的资源请求；换设备或显式重试才领取新的一次性入口，不缓存入口地址用于重挂。请求按接收顺序执行，同一请求重发复用处理结果，避免重复创建或较早的异步操作覆盖最后选择。项目与会话目录分别按实际就绪状态有界订阅等待，创建失败回传入口错误。

嵌入只隐藏目标重复的左侧导航，不删除官方文件、Git、终端等项目工作区。已实现：左侧宽度按零参与官方三栏解算，右侧保留展开、收起、拖动与全屏；不再以两栏 CSS 覆盖布局或隐藏右栏拖柄。嵌入标记在壳挂载后变化时同步重算；窗口宽度在 768 / 1024 断点即时提交，其余变化按 90ms 合并，包括窄屏内连续缩放，不能让右栏使用陈旧宽度。真实官方壳、工作区组件与 store 的浏览器回归已覆盖本机、嵌入、标记退出、明暗、窄屏全屏与恢复，未代替两台设备的文件/Git/终端实际操作验收。

默认保留入口侧栏，需要目标完整操作时通过设备切换器进入目标工作台。项目对话先读 30 条，内联加载更多，折叠再展开及后台刷新保留已加载覆盖量；分页只查询摘要，不打开工作台或创建会话。查询先按项目、归档过滤，再按置顶与活动排序，最后分页；普通与归档缓存分开，切换后失败不能复用另一视图的偏移。远端摘要保留真实 Harness 品牌、精确模型 ID、活动及置顶状态，模型供应商单独表示。旧目标若忽略归档参数，需升级目标端才能完整支持归档分页，入口端不冒充远端已升级。桌面等待嵌入工作台握手最多 45 秒。超时后重试领取新入口，普通切换复用健康页面。未改官方子模块或增加插件入口。

1. 选择、保存、重载后三种显示范围一致；设备改名、离线和恢复不丢已选 ID，单项修改不覆盖其他设置。当前设备明确指工作台主机。
2. A、B 具有同名项目、相同资源 ID 和不同路径时仍正确区分；各设备默认工作区及未分组会话保留最近语义，Router 与 Worker 可见性不漂移。
3. 从 A 打开 B 的项目、最近或执行会话，折叠项目/设备、筛选或切换归档不关闭 B；后台等待、查询失败及恢复保留同一文档、草稿和阅读位置，且不重新领取入口。真实本机导航或明确撤销仍关闭远端层，返回后保留 A 的草稿和侧栏位置。新工单路径已有受控集成及 UI 验证，真实环境继续验收：A 委派后工单只出现在 A 的统一任务系统，B 不启用 SuperAgent 仍能按 Link v2 冻结的 Harness 与模型组合执行；B 的执行会话只读并可返回 A 原工单，能力不足明确说明，不降级到 B 的业务工单路径。
4. 单设备失败、全部离线、权限撤销、旧响应迟到、分页重试、时间缺失与明显时钟差分别核验；失败不清空其他设备，撤销后缓存不可再读。
5. 空、加载、错误、有数据及离线状态在明暗主题、窄屏、键盘和触屏中实际渲染核验；已保存、选中与真实可用性不混色。
6. 有界分页、共享连接、隐藏后停止无用刷新和重连恢复分别验证；组件或接口测试不替代两台真实设备的完整用户路径，最终视觉由用户验收。
