# 跨设备资源导航

板块入口见[工作台与 Agent](设计.md)，图示见[架构图](架构.html)。本文是侧边栏跨设备「项目 / 最近」的界面与交互正文；设备授权、资源身份、查询和执行归属统一见[跨设备协作](../01-设备与远程连接/跨设备协作.md)，公共视觉与四态遵循[前端视觉规范](前端视觉规范.md)。

**实施状态：源码已接通，已验证本机至襄阳服务器的资源打开与页面复用，完整用户路径待验。** 侧栏已支持当前设备、全部、指定设备，范围服务端持久化；项目按设备分组，最近保留源候选后聚合。远端内容复用目标 Link 工作台，入口侧栏和本地草稿保留。浏览器 fixture 已覆盖空、加载、错误、有数据、明暗及窄屏；实机验证未发送消息或启动模型执行，不代替两台真实设备的完整用户验收。

## 显示范围与入口

在侧边栏「项目 / 最近」共同的工具区提供紧凑的「显示范围」入口，当前值始终可辨；收起侧栏、窄屏与触屏仍有可达入口。复用既有共享菜单、选择和设置反馈，不新建一套设备管理页。该设置统一作用于两个列表，不分别维护相互冲突的设备集合。

| 选项 | 含义 |
| --- | --- |
| 当前设备（默认） | 当前工作台所属设备；手机或浏览器访问 B 时指 B，不指浏览器所在手机或电脑 |
| 所有已连接设备 | 当前设备，加上设备目录中已保存并授权的设备；「已连接」指建立了连接关系，包含暂时离线条目，不只筛选此刻在线设备 |
| 指定设备 | 从同一设备目录勾选设备，保留其稳定 ID；未选择时说明「请选择设备」，不暗中改成全部设备 |

显示范围按入口工作台的用户配置持久保存，重新加载后恢复；设备名只作展示，改名不丢选择。保存失败保留草稿并给重试入口，不能伪装成已保存。修改本项保留已有搜索、归档、折叠和其他配置；旧版本首次使用默认当前设备，不自动打开所有设备的查询。

筛选只改变可见列表，不授予设备权限、不切换项目执行位置，也不限制 SuperAgent 按用户要求查询其他已授权设备。通过现有设备切换入口切换整个工作台时，显示所属工作台及其配置；在聚合列表打开远端条目，不隐式切换当前显示范围或主助手会话。

仅配对授权的远端 Link 工作台保留所属主机的项目、最近和委托设备切换，不提供主机拥有者的设备目录或显示范围管理入口，也不请求这些受限接口。

## 项目与最近的呈现

- **项目**按设备分组，可折叠；当前工作台所属设备置前，其余沿设备目录顺序。组标题显示真实设备名称与可达状态，项目保留既有会话层级和活动标记。同名项目不合并；有歧义时提供所属设备和项目路径的可聚焦提示。
- **最近**聚合各设备原有的最近候选：默认工作区会话及未分组会话，合为一份列表，不按设备分组展开。默认工作区按所属主机持久化的工作区身份识别，其会话进入最近，`default-workspace` 不作为项目展示；真实同名用户项目不按标题误排除。它不是所有项目会话的活动榜；不因聚合把已归属项目的会话重复收进最近。Router 入口与 Worker、官方子代理的既有可见性规则保持一致。
- 最近列表保留既有置顶优先规则，其余按来源活动时间近似倒序合并；每条显示设备标记，平局以稳定资源身份保持顺序。置顶、归档等状态仍来自所属设备，不在入口工作台再维护一份业务状态。
- 来源活动时间与本次观测时间分开。设备时钟未同步时不能承诺严格的跨设备全局时序；时间缺失或明显异常时提供提示并稳定排列，不使用本次刷新时间伪造会话活动，不改写源记录。
- 列表继续使用紧凑单行标题与时间、状态；设备标记不挤掉主要标题。悬停与键盘聚焦可查看完整名称及归属，触屏提供等价入口。选中反馈和真实可用性分离，已保存、已选中都不等于可连接。

资源唯一身份、查询覆盖与分页契约见[资源身份与查询](../01-设备与远程连接/跨设备协作.md#资源身份与查询)。前端缓存、选择、高亮及跳转都携带设备身份和原始资源 ID；不按名称、路径相同或未经限定的 sessionId 合并不同设备的条目。

目标会话与最近目录使用窄摘要查询，不读取模型目录；同一次查询共用一份项目快照。官方会话构建会话 ID 到首个所属项目的索引，原生会话按项目 ID 与原始路径精确核验；保留私有会话、子会话、归档和未注册会话的既有可见性及来源顺序，不跨请求缓存项目归属，实际操作仍实时复核。

## 打开、创建与操作

点击 B 的项目或会话，在当前工作台的内容区打开 B 的对应资源，保留聚合侧栏、筛选、滚动位置和原会话草稿；不另加返回、设备名称或远端资源顶部栏，通过已有设备切换入口返回或切换完整工作台。桌面设备中心点击设备也关闭面板并复用同一工作台切换器，不再打开第二层工作台。复用官方会话组件与已有 Link 会话接入，不复制完整聊天或创建本地替身会话。仅打开列表或会话不恢复归档、不启动执行、不重放消息。

聚合侧栏点击本机项目、会话或工具面板时退出远端资源层，再执行本机原有导航；SuperAgent 主聊、旁聊及同一面板再次选择同样恢复本机内容。原本机草稿保持可编辑。统一创建弹窗取消时保留当前远端内容，确认本机目标后才退出远端层；远端目标继续在所属设备打开，不因关闭遮挡层创建额外会话。

PC 桌面托管远端工作台时，只保留标题栏「应用」左侧的原生侧栏按钮，控制当前显示设备的展开/收起并同步可访问标签；远端页面不再显示重复按钮或占位。该原按钮保持在本机内容被隔离时可操作，切回本机恢复本机侧栏语义。只有收到可信桌面父窗口声明的嵌入页才隐藏自身入口，独立浏览器与手机继续保留原有侧栏控制。

项目内「新聊天」绑定该项目所属设备。「添加项目」直接打开一个弹窗：桌面宽约 480px，紧凑设备选择器与「文件夹 / GitHub」位于同一行，设备状态放在选项中，不另加环境说明；窄屏保持同排并截断过长设备名。下方复用已有磁盘、目录搜索与提交区；不先弹设备列表，也不因切换设备重新打开弹窗或提前切换整页工作台。设备选项来自已授权目录，显示范围只决定初始值，不限制可创建的设备：范围内仅一台时默认该设备，否则默认当前工作台。开始选择后，后台刷新不能替用户更换目标；设备消失时清除可提交内容并提示恢复。

设备切换后重新读取目标目录，清空旧目录、磁盘与搜索状态，丢弃旧请求结果；保留用户选定的添加方式和仓库地址。提交期间禁用设备切换和关闭。远端目录不能误用入口电脑的系统文件夹选择器；系统选择器只在当前平台确实能选择目标主机目录时显示。设备可用性按真实状态着色，与选中反馈分离；没有设备、读取失败、连接中均在同一弹窗呈现，并给设备中心或重试入口。

最近区与顶部「新聊天」共用设备选择规则，多设备时打开紧凑「新会话」弹窗：复用同一设备选择器，保留取消与「创建会话」。当前设备范围且只有一台设备时保留一键创建；指定单台远端时在弹窗中默认该远端，确认后进入目标工作台，由目标端原有机制创建最近会话。取消不创建，原工作台与草稿保留，不增加项目、模型或 Harness 的重复配置。

远端项目表单通过既有授权工作台的窄消息桥调用 `browse / project / clone`；父窗口与 origin 必须同时匹配，按请求 ID 应答并去重。仅传递项目操作所需字段，不开放任意 API 代理、不扩大设备权限；旧目标未声明能力时明确提示升级。关闭或换设备后释放连接与请求，成功后复用目标工作台打开项目新会话。

重命名、置顶、归档、移除项目和会话等动作发送到资源所属设备，沿用原有动作语义、真实能力与必要确认。菜单与反馈必须可辨目标设备；不以一个设备的成功冒充批量全部成功。暂不可用的动作说明原因，不能静默在当前设备新建同名资源或改为本地执行。新增跨设备批量操作不在本轮默认范围内。

执行始终使用项目所属设备的模型、Harness、文件与环境，见[项目归属与远端执行](../01-设备与远程连接/跨设备协作.md#项目归属与远端执行)。前端只投影真实执行状态；设备断连不等于任务停止或失败，失联时保留最后已知状态并标明信息可能过期。

## 数据加载与失联恢复

项目、最近和 SuperAgent 共用设备资源服务，不分别扫描远端目录或维护独立连接。按当前显示范围有界并发查询，单设备慢或失败不阻塞其他设备；首次只读取列表所需摘要，分页与按需详情不拉取全部会话正文或项目文件。

各设备保留独立分页进度、观测时间和错误。界面明确仍在加载、尚有更多或部分设备未返回，不能把已加载的一个分页说成全部结果。最近列表只对已返回候选合并排序；加载更多后保持阅读位置，不让实时更新打断当前操作。

复用现有订阅与可见性刷新机制，同一设备的消费者共享连接；页面隐藏、范围切换和卸载后取消无用请求与订阅。代次或请求标识隔离迟到响应，旧范围的数据不能覆盖新选择。重连按源版本更新元数据，保留同一资源的稳定选中身份，不重复创建会话。

短暂离线保留已授权范围内的有界摘要缓存，并显示离线与最近成功更新时间；没有缓存则说明未能读取。权限撤销、设备移除或用户身份变化后清除相应缓存及可打开引用，不继续展示失效授权下的内容。缓存仅用于导航，实际读取与写入仍由目标服务复核。

## 四态与恢复入口

| 状态 | 呈现与操作 |
| --- | --- |
| 空 | 成功查询后无项目或最近才显示空态；给「添加项目」「新聊天」或调整显示范围入口。未选择设备、没有匹配搜索分别说明 |
| 加载 | 首载使用共享文字加载反馈；设备独立返回，已返回内容先呈现。后台刷新保留列表、草稿与位置，不整栏清空 |
| 错误 | 在对应设备组或条目标明连接、授权、能力不支持或读取错误，提供重试和设备管理入口；其他设备继续可用，失败不冒充空结果 |
| 有数据 | 展示设备归属、项目与最近原有层级、活动时间和真实状态；分页、筛选、键盘与触屏操作完整可达 |
| 离线或过期 | 保留合规缓存并说明更新时间，允许重连；远端写操作不可用且说明原因，已知任务状态标为过期而非改成失败 |

身份或证书变化、重新配对和连接恢复遵循[授权与互通](../01-设备与远程连接/跨设备协作.md#授权与互通)，不由列表自行绕过。普通连接设置也可交给助手，具体路径见[连接与中继管理](../01-设备与远程连接/跨设备协作.md#连接与中继管理)。

## 实现位置与验收条件

实现入口是 `plugins/benchgo/client/index.jsx` 的项目与最近槽位、`resource-creation.jsx` 的统一创建弹窗、`project-picker.jsx` 的复用表单、`plugins/link/client/project-bridge.mjs` 的授权项目消息桥、`resource-navigation.jsx` 的范围、分组及远端内容区域，以及 `resource-state.mjs` 的身份和排序。数据共用 `benchgoLink.resources`；首载与加载更多每页 30 项，后台刷新按已加载覆盖量合并请求、单页最多 100 项（90 项一次读取，120 项分 100 + 20），最多 4 并发。可见时每轮刷新完成后等待 30 秒再读摘要，隐藏时取消当前无用请求，恢复可见立即刷新，切换范围/卸载取消请求。已有数据静默刷新并保留已加载的分页覆盖，列表缩短时移除过期条目；只有首载无数据时显示加载反馈。每轮结束重读设备状态，状态变化不重启轮询。当前不新增资源事件总线。

远端内容区域嵌入既有目标工作台，父子窗口核验来源和请求身份。接收器安装后主动通报就绪，保留页面加载探测，避免官方壳先完成加载时丢失唯一探测。同一设备内切换资源复用已挂载页面，只发送新的资源请求；换设备或显式重试才领取新的一次性入口，不缓存入口地址用于重挂。请求按接收顺序执行，同一请求重发复用处理结果，避免重复创建或较早的异步操作覆盖最后选择。项目与会话目录分别按实际就绪状态有界订阅等待，创建失败回传入口错误。

默认保留入口侧栏，需要目标完整操作时通过设备切换器进入目标工作台。项目对话先读 30 条，更多通过目标工作台查看，避免复制业务菜单与状态。旧端缺少嵌入协议时显示超时和恢复入口；工作台切换等待最多 15 秒，失败后重试领取新入口，健康工作台继续复用已挂载页面。未改官方子模块或增加插件入口。

1. 选择、保存、重载后三种显示范围一致；设备改名、离线和恢复不丢已选 ID，单项修改不覆盖其他设置。当前设备明确指工作台主机。
2. A、B 具有同名项目、相同资源 ID 和不同路径时仍正确区分；各设备默认工作区及未分组会话保留最近语义，Router 与 Worker 可见性不漂移。
3. 从 A 打开 B 的项目、最近或执行会话，返回后保留 A 的草稿和侧栏位置；在 B 新建或继续任务确实使用 B 的模型、Harness 和文件，服务不支持时明确说明。
4. 单设备失败、全部离线、权限撤销、旧响应迟到、分页重试、时间缺失与明显时钟差分别核验；失败不清空其他设备，撤销后缓存不可再读。
5. 空、加载、错误、有数据及离线状态在明暗主题、窄屏、键盘和触屏中实际渲染核验；已保存、选中与真实可用性不混色。
6. 有界分页、共享连接、隐藏后停止无用刷新和重连恢复分别验证；组件或接口测试不替代两台真实设备的完整用户路径，最终视觉由用户验收。
