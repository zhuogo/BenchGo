# 项目文件操作

本机和 Link 远端工作台的右侧项目文件树提供新建文件、新建文件夹、重命名、删除和项目内复制粘贴。文本编辑与保存沿用已有编辑器，复制路径保留独立动作。Link 操作经已有配对连接发送至项目所在设备，由工作台根据会话解析当前工作目录。切换工作树后，之前打开的菜单需要重新打开。

桌面可将文件或文件夹拖进同一项目的其他文件夹。有效目标高亮，松手后执行移动。行菜单提供「移动到…」并逐层选择目标，键盘和触屏可用。Link 文件行上的「文件操作」可打开菜单，文件页工具栏的「项目文件操作」提供根目录的新建与粘贴入口。复制保存在当前工作台页面内，同名冲突保留原件。删除确认展示设备、路径和永久删除结果，删除文件夹包含其内容。

**已实现** · 本机增强树沿用已有编辑、重命名与删除，新增复制粘贴及移动。Link 远端树沿用官方文件树和菜单服务，宿主在同一项目范围内提交文件变更，成功后刷新目录。宿主文件系统上的普通文件和文件夹支持这些操作。

**验收条件** · 在本机和配对工作台验证新建、编辑保存、重命名、拖进子目录、复制、删除及同名冲突，核对磁盘结果和目录状态。正式安装版和实际两台设备之间的文件操作需在目标部署中核验。

**待实施** · 跨设备复制按文件传输推进。纯 SSH 的 SFTP 面板沿用已有浏览和传输，单独扩展写入操作。
