# 统一选择器

BenchGo 自有页面统一复用 `plugins/shared/client/custom-select.jsx`，不使用浏览器原生下拉菜单。覆盖多平台接入、宠物表情、保险库、文件预览和移动端资源导航。

保持原始协议值、数值转换、禁用状态与保存语义；键盘操作、焦点恢复与弹层定位由共享组件负责。移动端资源选项以分区名称前缀保留归属。此变更只影响展示，不改变 MCP、OpenAPI 或渠道权限。

多平台连接器图标按现行约定应由真实可用性决定：已安装且可用显示品牌色，不可用显示灰色，不随选中状态改变；连接状态独立展示，状态标记紧凑排列。2026-11-04 源码校对发现 `connections.jsx` 仍仅按已保存的 enabled 着色，认证失败也可能显示品牌色；这是待修实现偏差，不能把启用等同于可用，详见[链接与渠道](../06-superagent/链接与渠道.md)。

启用的当前渠道每三秒串行刷新连接状态，不覆盖配置草稿；切换渠道、操作中与卸载时取消旧刷新结果，避免认证验证后状态过期。

开发预览必须同步新增运行时依赖：官方包继续复用已登记引擎；缺失的第三方包使用本地已安装依赖的真实目录链接，校验版本后启动。不得只同步源码而留下缺失 SDK 的运行环境，也不得覆盖用户已有的实体依赖目录。
