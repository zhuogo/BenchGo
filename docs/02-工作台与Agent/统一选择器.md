# 统一选择器

板块入口见[工作台与 Agent](设计.md)。 视觉和共享表单行为遵循[前端视觉规范](前端视觉规范.md)。

## 复用与配置语义

BenchGo 自有页面统一使用 `plugins/shared/client/custom-select.jsx`，不使用浏览器原生下拉菜单。平台接入、宠物表情、保险库、预览与移动资源导航复用同一实现；键盘操作、焦点恢复、弹层定位由共享组件负责。

显示名称和协议值分离；保留原始模型 ID、工具名、协议值、数值转换、禁用与保存语义。移动资源列表用分区名称前缀保留归属。选择、保存、重载与实际请求必须一致，编辑一项不能丢失其他配置。

连接状态轮询不得覆盖配置草稿。启用的当前渠道沿用每三秒串行刷新；切换渠道、操作中与卸载后丢弃旧刷新结果，避免认证结果被过期请求覆盖。不支持的能力要明确提示，不能静默替换选择。

统一选择器只调整展示与交互，不改变 MCP、OpenAPI 或渠道权限。

## SuperAgent 自有会话

自有会话的归属只认服务端持久角色记录：按真实 `sessionId` 查询既有 assistant API 的 `sessionRole`，返回 `role` 记录或明确的 `null`。记录区分 Router、Worker 与子 Worker，并关联原线程、工单、Run 或父会话；不得用标题、当前页面或模型自报判断。权限与角色装配规则只在[任务与执行](../06-superagent/任务与执行.md)维护。

权限、模型、新会话 Agent preset 与会话头部 preset 通过官方插槽适配。确认自有角色后隐藏可选入口，集中只读显示实际角色和装配信息；`pending`、`ready`、`blocked` 分别呈现待核验、已就绪或受阻，实际值缺失明确未知，不以期望配置冒充生效配置。Agent preset、沙箱与审批策略、角色模型分别展示，不合成一个权限档位。此适配不替换官方输入框、消息列表或审批组件，也不靠 CSS 隐藏保证权限；执行前的真实装配与校验仍由服务端负责。

查询未完成或失败时，仅当前会话的相关选择器暂时不可操作，保留明确状态与失败重试；切换会话、重入或卸载后丢弃旧查询结果。只有明确返回 `role: null` 才恢复原控件，并保留原组件的会话作用域、注入、语言和写入通路。用户自建普通及项目会话继续使用原预设、默认值与配置机制，选择、保存、重载及实际执行不受 SuperAgent 干预；插件卸载恢复原槽位。

## 实现与验收边界

共享选择器已有实现。连接状态与选中状态分别呈现，不能仅按保存的 `enabled` 着色；认证失败或服务不可用时不得显示可用品牌色，须按真实可用性逐入口核验。

按入口验证键盘操作、焦点恢复、弹层定位、移动触控、禁用项和数值转换。选择、保存、重载及实际请求须使用同一原始值；轮询、认证、切换与卸载的旧结果不得覆盖新状态或配置草稿。四态实际渲染按[公共规范](前端视觉规范.md#四态)检查。

角色控件已有实现，定向测试与浏览器 fixture 已覆盖自有会话、加载未知、读取失败和明确普通会话四态，以及原官方 Provider 作用域、延迟注入与语言、会话切换竞争、重入及卸载恢复；未知或自有会话不会创建原预设控件的暂存选择应用器。安装版真实主聊、旁聊、执行会话、普通会话换档与重启恢复尚待验证，不能由接口记录、组件测试或 fixture 渲染推定实际装配已经通过。
