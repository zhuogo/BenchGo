# 统一选择器

板块入口见[工作台与 Agent](设计.md)。 视觉和共享表单行为遵循[前端视觉规范](前端视觉规范.md)。

## 复用与配置语义

BenchGo 自有页面统一使用 `plugins/shared/client/custom-select.jsx`，不使用浏览器原生下拉菜单。平台接入、宠物表情、保险库、预览与移动资源导航复用同一实现；键盘操作、焦点恢复、弹层定位由共享组件负责。

显示名称和协议值分离；保留原始模型 ID、工具名、协议值、数值转换、禁用与保存语义。移动资源列表用分区名称前缀保留归属。选择、保存、重载与实际请求必须一致，编辑一项不能丢失其他配置。

连接状态轮询不得覆盖配置草稿。启用的当前渠道沿用每三秒串行刷新；切换渠道、操作中与卸载后丢弃旧刷新结果，避免认证结果被过期请求覆盖。不支持的能力要明确提示，不能静默替换选择。

统一选择器只调整展示与交互，不改变 MCP、OpenAPI 或渠道权限。

## 实现与验收边界

共享选择器已有实现。旧连接页面曾仅按保存的 `enabled` 着色，认证失败仍可能显示品牌色；必须按真实可用性逐入口核验，连接状态与选中状态分别呈现。

按入口验证键盘操作、焦点恢复、弹层定位、移动触控、禁用项和数值转换。选择、保存、重载及实际请求须使用同一原始值；轮询、认证、切换与卸载的旧结果不得覆盖新状态或配置草稿。四态实际渲染按[公共规范](前端视觉规范.md#四态)检查。
