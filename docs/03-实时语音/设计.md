# 实时语音设计

本文描述语音输入、朗读和实时通话的共同设计。整体关系见[总架构](../总架构.html)，模型与供应商规则见[模型与供应商](../04-模型与工具/模型与供应商.md)。下文区分当前机制与待验收边界，不用历史协议探测代替当前兼容性结论。

## 职责与依赖

Voice 为现有会话增加语音输入、朗读回复与实时通话，文本仍进入原会话 Agent。语音不另建助手人格、工具执行器或审批体系。

- 源码位于 `plugins/voice/`，随唯一安装包 `benchgo-plugin` 交付，Cordis 入口为 `benchgo-plugin/voice-plugin`。
- 依赖基础层和官方连接、设置、凭据、模型服务；不硬依赖 Harness 聚合或 SuperAgent，独立启停。
- 复用官方输入框、消息流、模型选择、Agent 和人工审批。关闭 Voice 后，基础层保留媒体设置入口，并明确说明语音模块不可用。
- 桌面复用本机 Harness 鉴权；移动端复用 Link 已配对设备的工作台身份和现有直连或中继通道，不另部署语音中继。

## 用户路径

在“设置 → 媒体 → 语音”分别开启语音输入、朗读和通话，选择共享供应商或独立服务地址，填写准确模型 ID、凭据及音色，保存后由同一解析器检查可用性。三项能力默认关闭，不预填或猜测模型。

| 功能 | 入口与行为 | 结束与恢复 |
| --- | --- | --- |
| 语音输入 | 输入工具栏麦克风开始/停止；增量转录进入可编辑草稿，不自动发送 | 草稿被用户编辑时不覆盖，保留完整转录供复制或恢复 |
| 朗读回复 | 独立扬声器开关；只跟随当前会话新生成正文，按句合成、有序播放 | 按 turn/step 关联流式输出，最终消息只补尚未播出的后缀，不重读历史 |
| 实时通话 | 通话按钮启动；停说、最终识别完成后提交原会话 Agent | 插话取消当前语音对应的生成并清空播放；挂断释放采集、识别、合成、播放和租约，不据此停止后台工单 |

浏览器需要 HTTPS 或 localhost 及麦克风授权。拒绝授权、模型不可用、断网和发送失败须说明实际状态并提供对应恢复入口。工具权限仍在原屏幕界面确认，语音不得自动批准。

## 运行流程

```text
麦克风 → AudioWorklet 采集 / 重采样 / VAD → ASR
       → 最终转录 → 可编辑草稿 或 原会话 Agent
原会话正文 → 可朗读过滤 / 分句 → TTS → 有序 PCM 播放
用户插话 / 挂断 / 切换会话 → 取消当前媒体及相应生成，隔离迟到结果
```

识别增量仅用于展示，不提前触发工具。发送给 Agent 的内容只有真实转录，不追加内部播放状态。播放 ACK 表示本地播放器消费了片段，不保证用户听到，也不向模型声称用户听到了哪些文字。

上述插话取消针对当前媒体和相应生成，不等于叫停已经开出的 SuperAgent 工单。已确认的任务跟进按[任务与执行](../06-superagent/任务与执行.md)处理：普通调整插话即修订，只有明确叫停或收权才立即拦截后续执行；语音不得把所有插话自动解释为停工。此业务边界需随新工单链路验证，不由媒体取消能力推定已实现。

## 协议合同

仅提供明确选择的 OpenAI 兼容协议；供应商必须实际支持对应接口。模型 ID、协议值、音色均为不透明标识，不按名称或域名推断、替换。旧厂商专用协议保留原值并标记不可用，用户明确改选后才保存。

| 协议值 | 上游接口 | 数据与行为 |
| --- | --- | --- |
| `transcriptions-sse`，默认 ASR | `POST <baseURL>/audio/transcriptions` | multipart WAV、model、response_format=json、stream=true；响应增量转录 |
| `transcriptions` | 同上 | 分段 WAV 上传，返回 JSON text |
| `openai-websocket` | 默认 `<baseURL>/realtime?intent=transcription` | 持续 PCM 输入、转录增量和最终文本，显式选择 |
| `speech` | `POST <baseURL>/audio/speech` | model、voice、input、speed、response_format=pcm；默认流式播放 |
| `speech-stream` | 同上 | 在相同 PCM 请求中显式发送 stream=true；仅用于支持此扩展的供应商 |

ASR 的 HTTP/SSE 路径约每 1.5 秒或停说后上传一个 WAV 片段。SSE 是上传后的流式文字输出，不等同持续音频输入。

TTS 播放合同固定为 PCM16LE、24 kHz、单声道。响应声道或采样率元数据冲突时拒绝，不把 MP3/WAV 当原始 PCM。`tts.stream=false` 只对当前片段有界缓冲，不等待整轮回复。标准 `speech` 不发送 stream；显式选择 `speech-stream` 才发送 stream=true，请求供应商边合成边返回音频，两者均不发送 sample_rate。协议不按模型名或域名猜测，不支持时明确报错，不静默降级或替换模型。

延迟须分别测量采集分片、上游首包、BenchGo 转发及本地起播，不能以 HTTP 分块数量判断模型边生成边输出。2026-11-10 RouterGo 当前 `stepaudio-3-tts` 的合成音对照实测表明，省略 stream 时先等待完整合成，显式 stream=true 才持续返回 PCM；这是该路由的兼容性结论，不推广为所有供应商或模型的保证。`mimo-v2.5-asr` 的 SSE 文字增量正常；HTTP 分片采集等待依然存在，原生持续音频须单独验证 WebSocket 协议。

实时路由允许显式 `asr.realtime.url` 和非敏感 `query`，支持 `{model}` 占位符；切换供应商清理旧路由覆盖。API Key、token、用户名密码和授权字段不得进入 URL 或查询串。

## 实时传输与资源约束

已鉴权的 `asr.start` 发放一次性、10 秒有效 ticket，浏览器连接 `/api/voice/realtime`。Desktop 复用官方 `connection.openWebSocket`，Link 复用设备身份。代理须透传 WebSocket Upgrade，不新增公开端口或绕过鉴权。

- 上行二进制帧：epoch、utteranceId、sequence 三个 little-endian uint32，随后为 PCM16；控制消息为 attach/commit/clear。
- 返回 ready/ack/partial/final/error/closed；取消和 clear 隔离旧 epoch，迟到音频或文本不得进入新轮。
- AudioWorklet 持续采集与播放，重采样保留相位；浏览器 AEC/NS/AGC 配合自适应 RMS VAD。
- 当前上行队列最多 600 ms，拥塞淘汰旧帧并提示重说，不积累无限延迟；下行有背压，不静默丢弃朗读正文。
- TTS 三路有界预取并按原顺序播放；起播缓冲在 60–180 ms 间自适应，短暂欠载不解除回声保护。
- 单会话只有一个主动通话设备；租约 45 秒、心跳 15 秒、最长通话 30 分钟。进程重启不恢复旧音频或重放工具。

这些是实现参数，不是端到端延迟保证。网络、供应商排队、模型计算、蓝牙和设备音频链均影响实际体验。

## 配置、凭据与取消

配置默认保存于 `~/.benchgo/voice/config.json`；可由模块 `dataDir` 覆盖。目标不存在时才迁移旧 `$DSH_HOME/voice/`。文件和目录采用受限权限，API Key 只在服务端使用，前端获得配置标记与掩码；留空保留，明确清除才删除。

共享供应商解析与可用性展示使用同一请求路由。修改一项只提交变更字段，不丢失其它配置；选择、保存、重载和实际请求必须一致。可用性由模块、开关、模型、协议、路由和凭据共同决定，不以被选中代表可用。

挂断、断网、切换会话和模块卸载在媒体与相应生成范围传播取消；ASR/TTS 配置变化按影响范围取消，未变化的保存不打断媒体。取消不撤销已经完成的工具操作，也不自动叫停已独立领取的工单。

转录冲突或发送失败保留可复制、重试、恢复草稿的文本；恢复内容绑定原会话，不自动发往其它会话。当前恢复文本只在页面内存中保存，刷新后不会持久保留。静音不丢弃已识别的待发文字。

## 内容与界面

朗读过滤消费正式可见正文，处理 Markdown 和链接；代码块、表格、裸 URL 采用有界替代提示，不朗读内部工具参数或推理。过滤不等同完备的敏感信息防护。

入口、开关、状态、错误与恢复动作遵循[统一视觉规范](../02-工作台与Agent/前端视觉规范.md)。会话未开始、连接中、错误和正常收发均有明确呈现；挂断与静音可触达，禁用状态必须说明原因。

## 实现与验收边界

当前代码提供上述标准协议、媒体流水线、取消、租约、会话事件桥接和恢复入口；不修改官方引擎，不引入 TEN VAD、RNNoise，也不把独立 ASR + Agent + TTS 架构称作原生端到端语音模型。

真实供应商完整音频会话、真实手机麦克风、外放回声、蓝牙、移动后台和弱网长通话仍需分别验收。历史握手或专用协议探测不证明当前标准协议可用。

交付需验证配置往返与实际请求一致、草稿不被覆盖、朗读不重复、插话隔离迟到结果、审批不被跳过、设备租约正确，以及空/加载/错误/有数据四态实际渲染。源码定位：`plugins/voice/src/{plugin,config,availability,web,realtime,asr,tts}.mjs` 与 `plugins/voice/client/`。
