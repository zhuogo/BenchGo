# 实时语音板块

Voice 为现有会话提供独立的语音输入、朗读回复和实时通话，源码在 `plugins/voice/`，随唯一安装包 `benchgo-plugin` 交付。整体关系见[总架构](../总架构.html#modules)，板块内结构见[语音架构图](架构.html)。

## 三项能力的边界

| 能力 | 用户路径 | 模型使用 |
| --- | --- | --- |
| 语音输入 | 麦克风 → 转录 → 可编辑草稿，用户决定发送 | 只使用 ASR，不调用通话交互模型 |
| 朗读回复 | 既有正式回复 → 流式合成 → 播放 | 只使用 TTS，不改写回复、不调用通话交互模型 |
| 实时通话 | 采集 → 最终转录 → 会话交互 → 流式合成 | 按可信会话能力复用 SuperAgent 对话层，或启用普通会话轻量交互模型；未配置时明确直通原会话 |

实时通话的目标是及时接话，同时保留执行 Agent 的思考、模型、工具与审批。SuperAgent 主聊、旁聊复用已有对话层；普通 Harness 会话可配置 Voice 轻量交互模型，寒暄直接回答，需要执行时明确交接给原 Agent，由事件回传推进对话。Voice 内不引入工单系统，也不修改 SuperAgent 的委派机制。

## 实现边界

| 范围 | 当前状态 |
| --- | --- |
| 独立转录与朗读；原会话直通通话；流式协议、降噪、VAD、租约、取消与恢复 | 已实现，设备与供应商验收边界见[媒体管线](媒体管线.md#实现与验收边界) |
| 按可信身份选择通话路径、独立交互 LLM 配置、普通会话交接及终态回传、统一通话表达与语速工具 | 已有源码接线；运行与供应商验收边界见[实时通话](实时通话.md#实现边界与验收) |
| 语音层完整任务整理、最多五条必要补充与跨委派去重 | 已接入源码；真实模型整理质量待通话验收；唯一正文见[任务整理与有界委派](实时通话.md#任务整理与有界委派) |
| 公共低延迟调度、分句、自适应播放与分阶段指标 | 已接入源码，规则见[媒体管线](媒体管线.md#低延迟调度与观测)，不以降低缓冲承诺任意供给无欠载 |
| 中央动态通话球、语音记录与执行记录切换、持久通话文字 | 已有客户端与会话事件实现；阶段成果即时表达、精确播放范围持久化仍待完善 |

Voice 不硬依赖 SuperAgent 或 Harness 聚合。会话所属模块通过现有宿主接缝提供适配能力，缺少适配时明确说明；不能把模块启用、标题或模型自述当作会话归属。普通 Harness 接入复用官方会话服务，执行权限不因开启通话扩大。

视觉遵循[前端视觉规范](../02-工作台与Agent/前端视觉规范.md)，供应商与模型标识遵循[模型与供应商](../04-模型与工具/模型与供应商.md)。源码接线与真实设备、供应商和安装版验收分别确认，不由构建或定向测试推定全链路可用。
