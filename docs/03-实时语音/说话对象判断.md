# 决策配置与说话对象判断

本文维护决策配置、独立测试和说话对象判断的待研讨边界；决策当前不接入通话。板块入口见[设计](设计.md)，通话输入与插话见[实时通话](实时通话.md)，媒体配置与凭据见[媒体管线](媒体管线.md#配置凭据与取消)。

## 配置与当前范围

配置与独立测试已实现：入口收在“设置 → 媒体 → 语音 → 实时通话 → 交互模型”面板底部默认折叠的“决策（未接入通话）”区域，不再是独立子标签；沿用现有保存与加载，配置、固定样例测试和已存数据保留。`listening` 保存启用开关、完整决策接口地址、可选原始模型 ID、独立 API 密钥、唤醒词来源与自定义词。产品只呈现“决策”，不预设供应商、地址、模型或称呼；新配置默认关闭且连接字段为空，既有用户配置原样保留。模型是否必填由所选接口合同决定，不按域名猜测。区域内直接说明仅保存配置并支持固定样例测试、通话内容不发送到决策服务。测试连接只发送固定样例，草稿变化隔离旧结果，测试成功不代表判断准确率。凭据复用 Voice 的敏感字段、权限文件和脱敏快照，不回传浏览器、不宣称额外加密；经用户明确要求才将其提供的连接信息保存到个人运行配置。

**已实现范围**：当前通话统一直接交流，不提供“对话／静默”切换，也不调用决策服务筛选用户输入。决策配置及固定样例测试保留，既有地址、模型、凭据和称呼来源不清空；即使配置开关已开启，也不接入当前通话。测试沿用 SystemOne `state + questions` 协议，不绑定厂商或底层模型，不复用聊天补全接口。决策配置变更只影响测试，不结束正常通话。

当前输入链路为：本地 VAD → 续说窗口合并的 ASR 最终文字 → 现有 `deliver`。三种通话路径均沿原行为处理输入、插话与主动播报；正常通话租约仍为 30 分钟硬上限、45 秒租约与约 15 秒心跳。不会因保留的决策配置授予长监听租约。

独立测试服务保留一道 `choice`：`addressed`（对当前助手说）、`background`（对别人或环境内容）、`uncertain`（证据不足），严格校验概率、弃权和超时。已有 0.85 的接纳阈值仅用于测试结果解释，不是实际准确率，也不控制当前通话。设置测试只发送固定示例，真实通话转录不会送到决策服务。

## 待研讨的接入边界

**待研讨、未接入通话**：须先找到说话对象与“当前是否希望助手回应”的判断边界，用自然续话、突然换题、对旁人说话、广播，以及“先别说话／可以说了”等上下文验证。用户的暂不回应要求应优先探索由模型理解上下文，不新增关键词或固定静默状态。仅凭话题相关不能证明在对助手说话，换话题本身也不能证明没有对助手说话。

候选上下文设计包括：本句、近期已接纳双方对话、助手最近公开回复、播放与生成状态、交流间隔及有效称呼；未知时间为 null，不假定用户已听完回复。材料区分历史背景与当前发言，不上传内部推理、完整工作区或全量历史。自然回答、补充约束、纠正和指代应无需逐句叫称呼；时间窗口不能自动放行所有人声。具体范围和提示词须完成边界评估后再确认。

称呼配置提供自定义唤醒词或跟随 SuperAgent 正式称呼。跟随只在 SuperAgent 已启用、身份服务可用且正式称呼非空时可选，读取现有 `store.getConfig()` 从 `IDENTITY.md` 派生的称呼，不复制称呼权威、不把“未命名”占位作为唤醒词。来源失效在设置中提示并保留选择，Voice 不因此硬依赖 SuperAgent；称呼不改变助手身份、会话归属或授权。

后续若重新接入，判断须位于正式记录和执行之前，并解决背景人声误打断、上下文误接纳与漏接纳的取舍；已接受任务的结果及审批不应因输入判断而丢失。纯文本没有声纹、方向或视线证据，不能承诺全天零误触。实测接口延迟与少量人工样例不能代替真实设备和环境评估。
