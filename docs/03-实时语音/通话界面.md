# 通话界面与记录

本文维护实时通话的应用级呈现、收起胶囊、幕布、入口与语音记录投影。板块入口见[设计](设计.md)，会话分流、交接与执行生命周期见[实时通话](实时通话.md)，提示词与听觉表达见[通话表达](通话表达.md)，媒体生命周期见[媒体管线](媒体管线.md)。

## 应用级通话与收起

已实现应用级通话控制与呈现：插件级 `controller.mjs` 通过官方 `sessions.retain` 保留原会话 scope、事件订阅与发送能力，结束、启动失败或模块卸载时释放；页面只订阅和操作同一份状态。`call-presentation.mjs` 维护展开、收起和原会话导航，`call-host.jsx` 通过 `shell.overlay` 统一挂载通话界面；不靠隐藏挂载整个聊天页维持连接，不增加安装包、常驻模型或系统悬浮窗。

- 应用内切换会话、任务、设置或路由，以及窗口缩放、失焦和最小化，不主动结束实时通话。原会话视图离开时自动收起；采集、识别、交互、执行事件与播放仍使用原 session 和 callId。普通语音转文本与独立朗读保持原页面边界。
- 保留现有圆球与幕布大视图，收起后恢复当前页面的工作层记录，由 `shell.overlay` 呈现一个全局胶囊，不再将语音幕布自动嵌入并遮盖执行正文。胶囊显示所属会话、真实通话状态及麦克风状态，并提供展开、文字显隐、静音、挂断；没有通话时不占位，不允许把仍在采集的通话完全隐藏。完整语音记录仍从原幕布查看，不建立第二份通话状态。
- 收起时胶囊上方默认显示最近 3 条用户／助手发言，直接投影同一控制器的对话和临时识别行，包含 ASR 增量、续说及助手流式回复；不额外请求模型、轮询或复制历史。稳定转录标识保持临时行到正式记录的原位交接。新条目柔和进入并将旧条目向上推移，最顶部退出渐隐；同条流式追加不反复播放整行入场，减少动效时关闭非必要动画。
- 浮动文字采用无气泡的纯文本，用户靠右、助手靠左，发言之间以浅分割线区分。收起字幕采用 14px 字号；整个字幕容器共用随主题变化的磨砂底，背景以主题底色与透明各 50% 混合，柔化后方页面。透明度与磨砂只作用于背景，不降低文字清晰度，保留柔和边缘渐隐与有限高度。长发言截断预览，完整内容仍在幕布；随胶囊拖动且受视口与安全区约束，不覆盖一整页或阻断工作层操作。文字隐藏按钮只改变这层预览，同次通话内展开、收起和切页保留选择；隐藏时新发言也不弹出，恢复后显示最新 3 条。新通话默认显示，空记录不占位；静音、播报和通话生命周期独立于文字显隐。
- 桌面胶囊默认靠右下角，避开输入和通知；窄屏抬到输入区与安全区上方，限制宽度，保持触控可达。复用现有圆球、主题、Tooltip、按钮与状态色，低对比边界和轻阴影。圆球与标题区域兼作拖动区，短按展开，位移达到 6px 才拖动；静音、挂断和审批按钮不启动拖动，拖动结束不误触展开。支持鼠标、触摸及键盘方向键，Home 恢复默认位置；位置仅在当前窗口内保留，切页、展开后收起仍保持，缩放后约束在可见安全区域，不另增面板或配置项。
- 同一客户端最多一路实时通话。在其他会话点击通话入口先展示当前通话及归属；更换目标必须明确结束当前通话后再开始，不能悄悄替换。待审批时显示“处理确认”，返回原会话的真实审批区，收起或挂断不批准、不取消已接受执行。
- 收起只改变视图；静音只关闭麦克风输入，已在进行的回复仍可播放，焦点不在文本输入时可按 `M` 切换，规则见[麦克风快捷键](媒体管线.md#麦克风快捷键)；挂断释放媒体与租约。连接中可取消，错误状态保留恢复或关闭入口；重试不自动重发未知送达的任务。语音记录按原会话保存，迟到结果不能流入正在浏览的其他会话。
- 页面刷新或销毁（`pagehide`）、离线和模块卸载仍结束媒体；缩小、最小化和失焦不主动挂断。Desktop 的关闭按钮沿官方行为隐藏到后台，页面仍存活，通话继续；托盘“退出”等真正退出销毁页面并结束通话。系统睡眠、手机锁屏或浏览器强制冻结不承诺持续运行；恢复后必须按真实连接状态呈现，不能假装仍在聆听。

桌面后台调度由 `scripts/desktop/prepare-background.mjs` 在现有打包链中注入，仅为主工作台窗口关闭 `backgroundThrottling`，其余窗口和安全选项保持原行为，不修改官方子模块。此策略已进入源码与产物校验，但必须重新打包并重启桌面应用才能生效；`npm run reload:plus` 仅刷新插件产物，不能更新已运行旧包的主进程。网页切页支持不等于旧安装包已具备持续后台运行能力。

实现验收覆盖切页时连续收发、启动中切页、返回原会话、其他会话入口、静音/挂断、审批跳转、断线与迟到结果、会话资源释放，以及胶囊空/连接中/错误/通话四态的宽窄明暗渲染。控制器定向测试、浏览器渲染和桌面编译产物校验分别验证其负责边界；真实安装包最小化后的麦克风、音频播放和长通话仍待设备验收，不能用页面隐藏事件或编译测试代替。

## 通话内容与记录

界面按来源区分原 Agent 的执行记录和用户实际听到的通话发言。交互模型寒暄、交接回应和口语结果只在语音记录显示，执行聊天保留正式交接后的用户任务与执行回复；不以口语摘要覆盖执行原稿。数据仍保存于原 session，不创建一份隐藏的平行工作会话。原生语音记录只投影来源为真实用户的正式消息、助手正文与正式发布，排除模型专用上下文、宿主注入及压缩替换副本；文件和图片保留显示名称。

增强通话将用户原话、交互回复、交接和执行关联写入原 session 的 `plugin:benchgo-plugin/voice-conversation` 可忽略事件，复用官方持久化与分页。语音专用发言在执行聊天中隐藏，语音记录仍完整投影用户与交互模型对话。通话成功绑定原 session 后，持久化一次 `call-start` 并在执行聊天显示简洁的开始时间记录。仅开启通话不生成标题；增强通话完成首个有效回复后，从真实用户语音中异步生成有界摘要，使用已选交互模型的精确路由，将结果写入正式 `session/title` 并持久化，统一侧栏与官方会话顶部标题。摘要不阻塞接话或首音，不注入虚假正式用户消息、不触发执行 Agent；已有正式标题或正式用户消息时交回官方标题机制。每个 session 同时只生成一次，提交前再次保护已有及用户手改标题；失败不影响通话，可在下次有效回复后重试。直通及 SuperAgent 路径从原会话正式用户消息、助手回复与发布记录读取，不复制工具历史，也不宣称能从旧记录准确区分所有键盘与语音输入。

全局胶囊订阅正式会话列表的标题更新，摘要完成或手动改名后同步刷新，不重建或中断通话。摘要输入限前五条可用用户语音、合计 1800 字符，输出最多 64 token；失败至少冷却 30 秒后随下一次有效回复重试，每次服务生命周期内同一会话最多失败两次，避免每轮请求失败。

点击通话入口后，入口位置过渡到屏幕中央的动态圆球；球体使用采集或播放的真实音量反馈，连接、聆听、识别、回应和错误有对应文字。“幕布”、麦克风和结束通话位于同一行；展开幕布后，圆球缩为状态条，精简对话在透明无框区域显示，连接和错误仍可见，不另弹记录窗口。幕布复用官方 Markdown 渲染器，支持安全链接和代码块；ASR 临时字幕随增量更新，并按同一转录标识原位交接为正式发言，不重播每个字符动画。

直通（`direct`）通话正在等待原模型思考时，大视图在状态文字下显示一行服务端给出的降级原因；其他阶段与其他路径不显示，不常驻。只有服务端标明该降级可通过配置交互模型解决时才提供“去设置”，打开“设置 → 媒体”并收起大视图，通话继续；子会话等设置无法解决的原因只说明、不给入口，界面不按原因文字猜测。已实现于源码，实际呈现待通话验收；直通的定位见[会话接入](实时通话.md#会话接入)。

顶部不显示左侧标题与状态点，仅在右侧保留“收起”（历史查看为“关闭”）：所有通话路径均关闭大视图并露出当前页面的工作层记录，控制由全局胶囊承载，近 3 条实时文字显示在胶囊上方并可单独隐藏。收起不强制跳回原会话或切换正在浏览的页面，原执行树、草稿与滚动保留挂载。官方审批或提问未处理时，全屏与胶囊提供“处理确认”，回到原会话的审批与输入区；挂断不代表批准。完整语音幕布通过展开后查看；Windows 通话视图避开原生标题栏，移动端保留安全区。减少动效时关闭非必要动画。

幕布记录区隐藏滚动条，保留鼠标滚轮、触摸和键盘滚动；记录区可聚焦，查看旧记录时新消息不抢回底部，不用 `overflow:hidden` 裁掉内容。

增强通话的事件流在建立后立即发送不入记录、不朗读的 `ready` 握手，不能等待用户首句才响应。客户端仅对握手设置 12 秒期限，已连接的静默通话不受此期限影响；麦克风采集真正就绪后才显示聆听状态。原会话直通和独立交互模型均保留原有接入语义。

输入栏只保留同一个通话入口。桌面悬停或键盘聚焦显示入口上方的“语音记录”菜单；触屏短按启动，长按 550 ms 以圆环进度反馈后显示同一菜单，松手不再启动。移动、取消、多指和卸载均中止长按。菜单复用官方 `Menu` 的定位、指针宽限、键盘和关闭行为，挂断后可直接回看，通话配置不可用时也不影响记录入口。

已生成、已显示、已播放是不同事实，不能收到文字就标记用户已听完。当前持久记录保存回复文字与被打断标记，尚未精确持久化每段已播放及未播放范围；该能力仍待完善。重新通话读取近期文字和原执行状态，不自动重放历史语音或工具；断流明确提示重新开启，不自动重发已接收任务。
