# 通话表达与语音设置

本文维护普通会话增强通话的内置沟通提示词、听觉表达目标和自然语言语音设置。板块入口见[设计](设计.md)，交接与执行事实见[实时通话](实时通话.md)，朗读过滤的实现规则只在[媒体管线](媒体管线.md#内容与界面)维护。

## 内置沟通提示词与听觉表达

**精简沟通提示**：正文直接从理解需求、自然回应和完成工作开始，不增加“你是……”身份开场。只保留交流、行动、事实与权限三组规则，不主动解释内部角色或模型分工。完整任务整理、早期有效约束、精确名称与否定限制仍须保留，执行状态以真实回执为准。字符预算、参数、工具调用细节由现有工具定义与宿主校验承载，不在系统正文重复。需要委派时先简短接话再调用工具的要求及宿主处理见[对话与交接](实时通话.md#对话与交接)。实际模型口吻和工具选择仍需真实通话验收。

模型可见的任务工具说明也使用“当前任务、当前会话”的中性措辞，不再注入分层角色。每轮宿主状态附带准确的 `currentModel: { providerId, model }`，与本轮实际请求使用同一路由；询问模型时按该配置标识回答，不从工具差异推断底层模型或内部架构。通话恢复时，过去最多 40 条、12000 字符的公开对话以标明来源的历史参考资料提供，不把旧助手发言重标为当前所选模型的 `assistant` 自述；历史中有效的用户要求与事实仍可用于理解任务，原始界面记录不删改。当前通话新产生的双方发言继续按正常角色延续。系统提示每次回复从同一权威 Markdown 读取一次，本轮工具循环复用；更新不依赖模块首次导入时的提示词缓存。

普通会话轻量交互模型使用 `plugins/voice/prompts/conversation.md` 作为唯一提示词正文，服务端通过 `src/conversation-prompt.mjs` 的 `readVoiceConversationPrompt()` 读取。文件随 Voice 发布；缺失或空白明确报错，不让客户端传入系统提示词。`src/conversations.mjs` 将其装入所选供应商与模型的流式请求，并只开放交接、修订、停止及语音设置工具。SuperAgent 的主聊、旁聊复用其原有对话提示词，普通转录和朗读不调用这套交互模型。

表达参考 SuperAgent 的[Router 对话准则](../06-superagent/Router对话准则.md)：温暖、有判断、尊重用户、少占注意力，以认真理解和真实结果体现朋友般的交流感；不复制其身份、文档链、记忆、工单或权限，不表演亲密或虚构人类经历。默认一到两句直接回应，不固定开场、等待话术或结尾追问；长解释先讲关键结论，按用户需要展开，失败与限制仍必须保留。

| 内容 | 听觉表达 |
| --- | --- |
| Markdown 表格 | 按行说出可理解的文字与数字，不念竖线和分隔行，不插入“表格内容略过”等播报 |
| 其他 Markdown 标记、代码、命令、结构化工具参数 | 不读格式或载荷，必要时简短说用途，模型不自行宣告“略过”；精确内容保留界面，实际可见后才说明已提供。正文仍出现代码时由共用过滤兜底提示 |
| 带标题的链接 | 只说真实标题，不读 URL 或查询串；无标题时说“这个链接”，不编造标题 |
| Windows 文件路径 | 按真实盘符、目录与文件说位置，如“D 盘项目文件夹里的说明文件”；必要时保留扩展名区分，完整路径仍在界面 |
| 中间计划、普通进度、原始推理 | 不逐条播报；普通进度静默供追问，推理不进入语音 |

模型提示词与进入 TTS 前的流式文本处理共同保证朗读规范；不能只靠模型自行遵守。流式链接和路径须识别跨片段内容，不将半个协议、盘符或代码标记提前读出；口语转换不能改写原会话的链接、路径与执行原文。这里规定通话口语目标；过滤如何处理表格、代码、链接与路径（含代码的兜底提示）及其验收只在[媒体管线](媒体管线.md#内容与界面)维护。

## 自然语言语音设置

普通会话增强通话通过已注册工具读取和调整语音设置，不把设置要求委派成开发工作。`get_voice_settings` 返回实际语速与音色，`set_voice_speed` 按服务端校验修改语速。是否调用由模型按上下文判断，“讲慢一点”和追问后的“一点五倍”都应可用；宿主不按关键词判断用户原话，只校验范围、精度和参数形状。“调到一点五倍”对应 1.5，“说快一点 / 慢一点”先读取现值再小幅增减 0.1。当前范围为 0.25–4 倍、精度 0.01，越界明确说明，不静默改成另一个目标。仅保存语速字段，保留 ASR、TTS 模型、音色、凭据与交互模型等其他配置。

只有设置工具成功并回传实际值后，交互模型才确认改变；按真实回执区分已保存、当前生效或下次生效。失败保留原值、说明失败；“工作快一点”不当成语速指令，这是对模型的要求，宿主不设关键词闸门。保存成功后服务端推送配置，客户端更新后续 TTS 请求；不改变采集和执行模型，不承诺已经播放的音频变速。该独立工具路径不依赖 SuperAgent。SuperAgent 通话沿用其统一设置工具和 Voice 设置适配器的 `tts.speed` 配置，不额外加载上述轻量工具。由模型判断是否调用已实现于源码，真实模型能否正确选择并调用工具仍须通话验收。
