# SuperAgent 身份与形象

本文维护同一助手的身份、个性外观和表现方式。人格与记忆的数据权威见[记忆与技能](记忆与技能.md)，聊天布局见[对话交互](对话交互.md)。

## 身份与现有能力

BenchGo 是统一的产品、Logo 与吉祥物 IP；SuperAgent、Router、宠物是同一个助手。默认正式素材来自 assets/brand/，个人外观不替换应用、托盘与安装品牌；改形象不改名字、模型、权限、记忆或正在执行的任务。

- **档案分工**：主人档案为 USER.md，助手的姓名与身份归 IDENTITY.md，人设归 SOUL.md，外观资源留在配置与资源存储。界面可以分“主人档案 / 我的档案”，不另建宠物昵称、角色切换或独立人格；只换外观不推断新人设。
- **侧栏主聊入口**显示当前形象与姓名，保留点击、键盘访问及选中状态。窄栏省略长姓名，可查看全名。聊天顶部另有真实工作状态，见[顶部身份与活动指示](对话交互.md#顶部身份与活动指示)。
- **形象创作**：走现有聊天与图像服务。先查真实素材目录，优先复用已有组合，生成后先预览再应用，可取消和回退。上传 PNG / JPEG / WebP 须实际解码为静态 PNG 并移除元数据，限制 8 MiB、单边 8192、总像素 32×1024×1024。
- **动作**：由真实事件和受控本地配方触发，不从措辞猜任务成功，不为每次表达调用模型，不因缺素材自动生成。外观版本绑定表情，换装不混播其他外观的动作。
- **新会话装饰**：普通会话的空白页通过官方 `conversation.hero.frame` 同 ID 优先级，在输入框右上方呈现当前形象。进入时轻柔探头，待机以本地低频配方交替点头、轻跳、侧倾与小步，内置形象还会眨眼和张望；不调用模型、不表示任务结果、不遮挡输入。减少动态、离屏或页面隐藏时停止，离开空白页即卸载。配置未读到时用默认形象；自定义图片损坏时提示不可用，不改写配置。
- **身份入口**：助手看板的「身份」页保留形象、SO、目标、记忆、Identity 五个入口。SO 直达 SOUL.md，Identity 直达 IDENTITY.md，沿用档案编辑与保存；形象快捷入口直达资源 → 身份的预览区。跨入口切换保护未保存草稿；首次读取显示加载，失败可重试并保留已有形象和入口。

桌面形象的目标只是同角色轻窗口、拖动与回到现有聊天，不另造人格、记忆、输入框或任务中心，见[桌面与多端目标](#桌面与多端目标)。

## 出厂无名与全渠道一致

身份只有内置层与 SOUL.md / IDENTITY.md 文档链这一条来源，主聊天、旁聊及所有渠道共用。渠道名称、应用品牌和底层供应商 / 模型只是产品或运行信息，不构成助手的名字或自我介绍；渠道适配器、会话配置和初始化模板不附加人设、自称或自我介绍预设。

- 出厂姓名为空，初始化配置与身份文档都不带默认名字。系统提示词不附加“BenchGo 个人助手”等默认身份，也不描述未命名状态；界面占位文字不写回姓名字段，不注入模型。
- 身份名称以 IDENTITY.md 为准；仅在其缺少 name 字段时回退到 config.name，显式空名表示未命名。
- 用户明确命名后，该名字就是正式姓名，写入 IDENTITY.md 并按统一档案装配供后续会话使用，不降格为小名、昵称或渠道别名。只问姓名或提到一个名字不自动触发改名。
- 已有的用户命名与自定义正文保留；历史对话里的自称不能覆盖当前权威身份。

## 身份与形象设置

### 单页身份配置

资源 → 身份的标题行右侧以铃铛切换本机回复提示音。图标区分开启与静音，切换反馈尊重系统减少动态。开启时尝试解锁浏览器音频，失败提供可感知的反馈。页面复用已有提示音偏好。

桌面预览在左，右侧在姓名上方排列「生成」「导入」「导出」三个彩色图文按钮。窄屏沿用上下布局，按钮可换行。表单沿用 [BenchGo 前端视觉规范](../02-工作台与Agent/前端视觉规范.md)。

```text
身份                                      [提示音]
共享形象预览    [生成]  [导入]  [导出]
                姓名  [                ]

形象资产        [试播 ▾]  [应用形象]  [取消预览]
[素材库]        选中页签的内容
[工作动作]
                [恢复上一版]  [恢复默认形象]
```

「形象资产」默认打开「素材库」。桌面左侧纵排「素材库」和「工作动作」，窄屏横排并支持触控。页签使用单层选中态和清晰焦点，方向键随布局方向切换，Home 和 End 跳到首尾。

- **生成**进入已有聊天，可继续调整 AI 草稿。
- **导入**以 ZIP 为主入口，另可上传单张图片或为已应用的自定义形象上传表情。导入先进入预览。
- **导出**下载当前已应用形象的 ZIP，包含形象清单和引用素材。待应用的草稿可继续编辑。
- **素材库**保留表情、动作、配色、装饰二级分类。首次读取使用共享加载态，空库显示既有空态，失败显示原因和重试，有数据时显示当前分类的素材。可用的 AI 生成和上传入口独立于素材目录状态。
- **工作动作**直接展示待机、回应、专注、等待、完成等事件的动作映射，可试播或还原预设。

各操作共用页首预览、试播和恢复入口，有草稿时显示「应用形象」「取消预览」。切换页签保留草稿，处理进度、结果和错误在公共区域保持可见。

姓名与形象沿各自的持久化命令保存。先后或交错操作时按最新 revision 合并，保留另一处草稿及其他配置。过期轮询不得回写，冲突和保存失败时保留草稿。

- 形象动效默认开启。系统减少动态优先，隐藏的形象暂停动作。旧 `cardMotion` 偏好在读取时忽略，随正常配置写入清理。
- 旧配置中的 `cardHtml` 在读取时忽略，随正常配置写入清理。设置、API、助手上下文和提示词均已移除该能力。

## 创作、应用与恢复

创作入口在资源 → 身份 → 生成。AI 创作使用原聊天，创作引导只显示可关闭的提示，不自动填入或发送消息，不覆盖已有草稿、引用或附件。

| 用户意图 | 路径与边界 |
| --- | --- |
| 创造新角色 | 核实图像能力，默认生成一个候选；失败保留描述，能力缺失仍可上传 |
| 换装或局部修改 | 先查当前角色的兼容素材；参考图 / 局部编辑不支持时明确说明，不把重新生成冒充局部编辑 |
| 一次表情 | 优先展示已有兼容素材；缺少时走显式创作，不自动生成 |
| 改默认外观 | 预览完整图、小尺寸与明暗背景，明确应用后切换；未满足要求保持当前形象 |

新资源验证成功才更新引用；配置用 revision 合并，迟到的生成结果不覆盖新选择，应用失败保留原有效版本。保留当前、上一有效版本和一个待确认结果，未应用的结果复用聊天产物。用户资源不写回 assets/brand/，不执行上传的 SVG / HTML / 脚本或外链动画；原创角色不强行套用基准挂点和装饰。

### 形象包与素材库

形象包采用 ZIP，根目录放带版本的 `manifest.json`，素材随包携带。AI 生成和上传进入同一校验、草稿、试播与应用通路。内部复用 SuperAgent 的形象存储、`assistant_pet` 和 `PetAvatar`。旧默认装扮、原创主图和已有表情映射由读取层兼容，安装或升级后可直接使用，显式应用才写入新格式。

| 清单项 | 用途 |
| --- | --- |
| `version`、`name`、`avatar` | 格式版本、显示名和必需主图。主图可引用包内静态图片，内置形象可引用同一素材库的受支持条目 |
| `expressions`、`palettes`、`decorations` | 素材 ID 到图片路径的映射。配色和装饰可以使用整张变体，可选 `variant` 指定当前变体。内置资源的装饰沿同一素材库挂点组合 |
| `actions`、`bindings` | 动作 ID 定义短关键帧和可选表情，状态绑定把真实工作事件映射到当前包动作。用户可在当前形象里调整映射 |

动作关键帧由本地渲染器解释，仅接受有界的位移、旋转、缩放、透明度和时长，可选表情必须引用当前包内有效素材。内置表情、颜色、装饰与动作配方继续作为库，以稳定 ID 引用。包只识别清单及其引用的本地图片，限制解包总量与素材数量，复用单图大小、尺寸和实际解码校验；未知版本、越界路径、外链或无效引用在预览前反馈原因。应用原子更新当前引用，失败保留当前版本和可重试草稿。

可用 `{"version":1,"name":"小助手","avatar":"images/avatar.png"}` 创建最小形象包。动作的 `duration` 使用毫秒，范围为 120–1800。`frames` 包含 2–12 个关键帧，`at` 从 0 递增到 1，`x`、`y` 使用图片尺寸百分比，`rotate` 使用角度。工作事件键为 `idle`、`acknowledge`、`focus`、`waiting`、`completed`，`none` 表示静止。整个包的压缩前后各最多 24 MiB，最多 48 个条目。

AI 可根据用户描述生成主图、表情与装饰图，也可编排配色、动作和状态绑定。图像使用已配置的[媒体生成](../04-模型与工具/媒体生成.md)，参考图或局部修改按该能力核验。创作可按需复用已有辅助看图能力检查素材一致性。当前对话负责结构化清单，图像能力缺失时仍可用上传或内置素材库。

## 表情与动作目标

表情是角色素材，动作是本地 transform / opacity 等受控配方。实际工作时，已应用的包按下表真实事件播放绑定动作，未绑定时沿用内置动作或静态主图。对话中的一次性表达只接收当前包已有的动作或表情 ID；播放由本地处理，已有任务状态与许可流程独立运行。

| 表现 | 触发与播放规则 |
| --- | --- |
| 待机 | 低频或静止，不持续大幅浮动 |
| 回应 | 用户发送或主动轻触，短时重复合并，单次点头 / 倾身 |
| 专注 | 当前会话真实执行，开始短播后静止，不无限抖动 |
| 开心 | 普通友好回应，不能解释为任务完成 |
| 完成 | 任务进入 completed 后按结果去重只播一次；执行报错、中断或停止不播，表达或投递失败显示独立状态。completed 的含义见[任务三态](结果与交付.md#任务三态与简短摘要) |
| 等待用户 | 真实问题 / 审批，提示一次并保留对应入口；点击形象不能代替答复或授权 |

- 同位置只播一个动作，不排长期队列；异常和待确认优先，一条回复最多一次表达，不随 token 重播。普通表达以约 5 秒冷却为体验起点；隐藏或减少动态时停止运动。
- 缺表情时回退到当前角色主图，不变回品牌角色；主图损坏时提示不可用并保留配置。
- 聊天只设一处主要动态角色，预留空间不挤正文和输入；历史小头像静态。语音复用 Voice，不新增监听或虚构口型。不建设亲密度、养成、饥饿、复杂情绪或额外记忆系统。

## 桌面与多端目标

桌面能力先核实自有包装层的扩展点，不改官方子模块、不引入 runtime patches。目标是默认关闭的轻窗口：拖动、点击回到现有聊天、隐藏 / 恢复；透明空白不挡点击、不抢焦点，换屏 / DPI 后可找回，位置按设备保存。

关闭形象不停止助手或任务，退出 BenchGo 时一并退出。前台聊天与桌面不重复庆祝，只做本设备可见性判断。Link 复用静态头像和一处轻动作，不做系统悬浮窗；不增加桌面聊天面板、任务中心、独立通知体系或重型动画运行时。

## 实现与验收边界

已接入源码的能力包括身份单页、ZIP 形象包及 AI 清单草稿、预览与应用、自定义表情、短动作和工作状态绑定。看板五卡入口及新会话空白页装饰沿用已有路径。下列条目用于新版布局及兼容验收。

裁切、主图损坏自动回上一版和桌面窗口待实施。真实供应商按模型能力验收基于参考图的生成或局部编辑。

待验证：

- 全新档案姓名为空、未命名时问身份、明确命名后按正式姓名回答，保存 / 重载 / 新会话中的姓名一致；覆盖主聊天和各渠道。
- 命名 / 人设与外观互不覆盖；上传 / 生成 / 取消 / 应用 / 恢复 / 重载的完整路径；新外观不混播其他外观的表情；缺服务或资源时有明确降级。
- 载入含旧 `cardHtml` 或 `cardMotion` 的配置，核对正常写入并重载后旧字段清理、形象动效按默认生效、其他配置完整。
- 实际渲染覆盖未命名和默认形象、空素材、首次加载、错误与重试、已有素材与工作动作。验证桌面与窄屏的页签方向、无横向溢出、明暗主题、键盘焦点和触控，以及从看板直达、跨页签切换、保存姓名和应用形象时各自的草稿保留。
- 形象包验证内置套装、旧原创形象及表情的兼容，检查已应用形象导出后可重新导入。生成或上传有效包后可预览、取消、应用、重载和恢复上一版；无效或不完整的包保留当前形象。验证工作状态绑定、一次性表情、系统减少动态、缺素材及迟到草稿。
- 提示音验证点击开关、偏好跨刷新持久化、静音和浏览器解锁失败。检查触屏、键盘、减少动态和窄容器中的标题布局。

正式品牌规范见[品牌素材](../../assets/brand/README.md)；VI 仅作参考，固定版本与许可边界在[板块来源](设计.md#来源与维护规则)维护，不引入其本机服务或运行依赖。
