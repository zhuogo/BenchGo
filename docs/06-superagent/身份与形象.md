# SuperAgent 身份与形象

本文维护同一助手的名片、个性外观和表现方式。人格与记忆的数据权威见[记忆与技能](记忆与技能.md)，聊天布局见[对话交互](对话交互.md)。

## 身份与现有能力

BenchGo 是统一的产品、Logo 与吉祥物 IP；SuperAgent、Router、宠物是同一个助手。默认正式素材来自 assets/brand/，个人外观不替换应用、托盘与安装品牌；改形象不改名字、模型、权限、记忆或正在执行的任务。

- **档案分工**：主人档案为 USER.md，助手的姓名与身份归 IDENTITY.md，人设归 SOUL.md，外观资源留在配置与资源存储。界面可以分“主人档案 / 我的档案”，不另建宠物昵称、角色切换或独立人格；只换外观不推断新人设。
- **名片**：身份页和侧栏共享 160×40 名片。`cardHtml: null` 使用当前形象与姓名；自定义 HTML 最多 16000 字符，sandbox 禁止脚本和网络，无有效内容时兜底且不改写原文，清空保存即恢复默认显示。主聊与旁聊顶部不嵌入自定义名片，见[顶部身份与活动指示](对话交互.md#顶部身份与活动指示)。
- **形象创作**：走现有聊天与图像服务。先查真实素材目录，优先复用已有组合，生成后先预览再应用，可取消和回退。上传 PNG / JPEG / WebP 须实际解码为静态 PNG 并移除元数据，限制 8 MiB、单边 8192、总像素 32×1024×1024。
- **动作**：由真实事件和受控本地配方触发，不从措辞猜任务成功，不为每次表达调用模型，不因缺素材自动生成。外观版本绑定表情，换装不混播其他外观的动作。
- **新会话装饰**：普通会话的空白页通过官方 `conversation.hero.frame` 同 ID 优先级，在输入框右上方呈现当前形象。进入时轻柔探头，待机以本地低频配方交替点头、轻跳、侧倾与小步，内置形象还会眨眼和张望；不调用模型、不表示任务结果、不遮挡输入。关闭 `cardMotion`、减少动态、离屏或页面隐藏时停止，离开空白页即卸载。配置未读到时用默认形象；自定义图片损坏时提示不可用，不改写配置。
- **身份页**：助手看板的「身份」页是形象、SO、目标、记忆、Identity 五张入口卡：形象用横向主卡，SO 与目标并排，记忆与 Identity 各用横卡。SO 直达 SOUL.md，Identity 直达 IDENTITY.md，沿用档案编辑与保存；该页不重复姓名、模型和任务统计，任务从看板任务页进入。跨入口切换保护未保存草稿；首次读取显示加载，失败可重试并保留已有形象和入口。

桌面形象的目标只是同角色轻窗口、拖动与回到现有聊天，不另造人格、记忆、输入框或任务中心，见[桌面与多端目标](#桌面与多端目标)。

## 出厂无名与全渠道一致

身份只有内置层与 SOUL.md / IDENTITY.md 文档链这一条来源，主聊天、旁聊及所有渠道共用。渠道名称、应用品牌和底层供应商 / 模型只是产品或运行信息，不构成助手的名字或自我介绍；渠道适配器、会话配置和初始化模板不附加人设、自称或自我介绍预设。

- 出厂姓名为空，初始化配置与身份文档都不带默认名字。系统提示词不附加“BenchGo 个人助手”等默认身份，也不描述未命名状态；界面占位文字不写回姓名字段，不注入模型。
- 身份名称以 IDENTITY.md 为准；仅在其缺少 name 字段时回退到 config.name，显式空名表示未命名。
- 用户明确命名后，该名字就是正式姓名，写入 IDENTITY.md 并按统一档案装配供后续会话使用，不降格为小名、昵称或渠道别名。只问姓名或提到一个名字不自动触发改名。
- 已有的用户命名与自定义正文保留；历史对话里的自称不能覆盖当前权威身份。

## 名片编辑与保存

入口为资源 → 身份 → 信息，姓名与名片预览共用实际的 160×40 渲染组件。

- 编辑 HTML 只展开编辑器，预览和诊断不直接写配置，取消 / 保存沿外层表单。已有自定义 HTML 优先，应用新形象不自动清空它；空白在保存边界归 null。
- 过滤提示可定位不支持的标签、隐藏 / 零尺寸 / 越界等常见问题；任意 CSS 无法证明可见时保留实际预览和兜底，不改写保存原文。
- 保存后按服务端 revision 刷新各入口，拒绝过期轮询回写；冲突和保存失败保留草稿，不丢其他配置。
- `cardMotion` 控制名片 HTML 动画、形象预览、聊天形象及新会话装饰的本地动作，不改变聊天的真实工作状态；系统减少动态优先，页面隐藏或名片不可见时暂停。
- 名片可键盘进入身份页，窄栏姓名省略但能查看全名；HTML 只作展示，没有脚本和网络权限。

## 创作、应用与恢复

入口为资源 → 身份 → 形象，聊天承担主要创作。提供当前预览、上传、让 AI 帮我设计、应用 / 取消与上一有效版恢复；不另建创作工作室或模型选择器。创作引导只显示可关闭的提示，不自动填入或发送消息，不覆盖已有草稿、引用或附件。

| 用户意图 | 路径与边界 |
| --- | --- |
| 创造新角色 | 核实图像能力，默认生成一个候选；失败保留描述，能力缺失仍可上传 |
| 换装或局部修改 | 先查当前角色的兼容素材；参考图 / 局部编辑不支持时明确说明，不把重新生成冒充局部编辑 |
| 一次表情 | 优先展示已有兼容素材；缺少时走显式创作，不自动生成 |
| 改默认外观 | 预览完整图、小尺寸与明暗背景，明确应用后切换；未满足要求保持当前形象 |

新资源验证成功才更新引用；配置用 revision 合并，迟到的生成结果不覆盖新选择，应用失败保留原有效版本。保留当前、上一有效版本和一个待确认结果，未应用的结果复用聊天产物。用户资源不写回 assets/brand/，不执行上传的 SVG / HTML / 脚本或外链动画；原创角色不强行套用基准挂点和装饰。

## 表情与动作目标

表情是角色素材，动作是本地 transform / opacity 等受控配方，二者分开，避免为衣服、动作和场景生成全排列。状态来自真实事件；对话表达只能沿现有回复附带允许的 ID，不另起情绪模型，不允许任意脚本、URL、持续时间或窗口操作。

| 表现 | 触发与播放规则 |
| --- | --- |
| 待机 | 低频或静止，不持续大幅浮动 |
| 回应 | 用户发送或主动轻触，短时重复合并，单次点头 / 倾身 |
| 专注 | 当前会话真实执行，开始短播后静止，不无限抖动 |
| 开心 | 普通友好回应，不能解释为任务完成 |
| 完成 | 任务进入 completed 后按结果去重只播一次；执行报错、中断或停止不播，表达或投递失败显示独立状态。completed 的含义见[任务三态](结果与交付.md#任务三态与简短摘要) |
| 等待用户 | 真实问题 / 审批，提示一次并保留对应入口；点击形象不能代替答复或授权 |

- 同位置只播一个动作，不排长期队列；异常和待确认优先，一条回复最多一次表达，不随 token 重播。普通表达以约 5 秒冷却为体验起点；隐藏、关闭动态或减少动态时停止运动。
- 缺表情时回退到当前角色主图，不变回品牌角色；主图损坏时提示不可用并保留配置。
- 聊天只设一处主要动态角色，预留空间不挤正文和输入；历史小头像静态。语音复用 Voice，不新增监听或虚构口型。不建设亲密度、养成、饥饿、复杂情绪或额外记忆系统。

## 桌面与多端目标

桌面能力先核实自有包装层的扩展点，不改官方子模块、不引入 runtime patches。目标是默认关闭的轻窗口：拖动、点击回到现有聊天、隐藏 / 恢复；透明空白不挡点击、不抢焦点，换屏 / DPI 后可找回，位置按设备保存。

关闭形象不停止助手或任务，退出 BenchGo 时一并退出。前台聊天与桌面不重复庆祝，只做本设备可见性判断。Link 复用静态头像和一处轻动作，不做系统悬浮窗；不增加桌面聊天面板、任务中心、独立通知体系或重型动画运行时。

## 实现与验收边界

已实现（源码接线，安装版最终视觉由用户验收）：形象编辑、资源校验、预览应用、基准表情映射与形象页短动作预览；聊天顶部使用同一形象和真实工作状态；新会话空白页装饰；身份页五卡入口，浏览器覆盖四态、明暗主题、窄屏和键盘入口。

待实施：身份页与侧栏名片的完整动作、聊天动作与原创短表情、完整事件映射（含完成动作对任务完成事件的消费）、参考图局部编辑、裁切、主图损坏自动回上一版、桌面窗口。界面不暴露无效开关。

待验证：

- 全新档案姓名为空、未命名时问身份、明确命名后按正式姓名回答，保存 / 重载 / 新会话中的姓名一致；覆盖主聊天和各渠道。
- 命名 / 人设与外观互不覆盖；上传 / 生成 / 取消 / 应用 / 恢复 / 重载的完整路径；新外观不混播其他外观的表情；缺服务或资源时有明确降级。
- HTML 编辑、过滤、保存、清空和冲突保护使用真实渲染；形象页与聊天的尺寸、主题一致。
- 按 CPU、内存、输入响应比较动态开关，隐藏后无持续循环，动作不额外产生模型请求；四态、触屏 / 键盘。

正式品牌规范见[品牌素材](../../assets/brand/README.md)；VI 仅作参考，固定版本与许可边界在[板块来源](设计.md#来源与维护规则)维护，不引入其本机服务或运行依赖。
