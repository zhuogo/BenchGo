## 设计调整（2026-11-03）

保险库不再要求用户设置或输入口令，也不提供手动锁定、闲置自动锁定或解锁流程。凭据仍须加密持久化；应用运行期间由保险库服务管理解密状态。SuperAgent/Worker 只持有凭据句柄，执行必须经过审批并在发送前复验固定目标、方法和权限，结果只返回脱敏状态。此调整降低桌面用户操作成本，安全边界聚焦于“Agent 不得看到明文”，不承诺隔离本机用户。

### 模型自管理动作工单化（代码已完成）

模型修改配置、文档、图像及形象的受控动作进入 Trigger → Ticket → 专属 Assignment → Run/fence → 验收 → commitResult/outbox，按 callId/参数哈希幂等，并复验策略及权威 revision/hash/requestId/产物；普通 Worker 不得领取专属 Assignment。用户直接操作设置页不伪造模型工单。**2026-11-04 本次将当面记忆记账改为协调操作，直接执行，不另建工单、不逐条审批；来源、版本与纠正/遗忘规则仍由代码校验。**

实现位于 `src/model-action-ticket.mjs`，不复用 `acceptDesktop` 的 Harness Assignment。适用的真实模型调用先持久化原始用户 Trigger、callId、参数哈希、当前策略版本及专属 Assignment/Run；普通 Worker 排除 `executor=model-action`，成功后保存权威回执并按操作核实配置 revision、文档 hash 或图像 requestId/产物。中断及结果未知只核实，不重放。

模型动作工单机制已有实现；记忆直接管理复用独立 CRUD 路径，完整版本回滚界面与真实渠道/供应商全链验收仍未完成。
