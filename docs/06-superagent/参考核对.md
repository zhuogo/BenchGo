## DeepSeek 原型核对

路径均相对 reference/dsh-superagent-prototype/。

| 机制 | 证据 | BenchGo 处理 |
| --- | --- | --- |
| Trigger/订阅优先 | src/core/intake.ts、docs/002-authorization.md | 新事项 Gate 与已有订阅分开，续问无新授权 |
| Gate | src/admission.ts、src/policy.ts | 原型可允许未 @ inferred；BenchGo 人类新群请求须 @，名单内机器消息可进入 inferred，但须 auto 与有效书面规则才能开单，不因 @ 获得主人权限 |
| Eval/handback | src/core/evals.ts | 借鉴批次、超时、持有/释放，BenchGo 按作者口径实现 |
| Ticket/Assignment | src/core/model.ts、src/core/tickets.ts、docs/003-execution.md | 原型底层状态不等于 BenchGo 产品阶段，保留业务/运行分离 |
| 持久副作用/outbox | src/app/effects.ts、src/app/outbox.ts | 复用思想，单机数据库先落册再执行 |
| 原文窗口 | src/sources/admission-context.ts | 确定性卡片与引用，不误做 LLM 摘要 |
| Router 工具 | src/app/sessions.ts | 当前发布原型仍有 bash/read 等工具；“原文 Router 不带手”限定为作者引用文章，不能称此仓库工具为空 |
| Watchdog/FTS5 | src/app/runtime.ts、src/app/store-read.ts | 有定时推进/健康与 LIKE 查询基础，不等于独立 Watchdog 或 FTS5 |

作者稿中的 0/5、2323万→3177万、p50 12.4/p95 15.7、29.5 分钟等，当前仓库未找到实验原始材料。本轮未复现；保留为作者提供的文章结论，文章链接/版本仍待补，不做 BenchGo 质量或性能预测。

## Hermes / Muse 核对

路径相对 reference/hermes-agent/。

| 机制 | 证据 | 与 BenchGo 的关系 |
| --- | --- | --- |
| 冻结提示 | agent/AGENTS.md | 冻结记忆可借鉴；BenchGo 明确实时许可不受冻结影响 |
| first-match | agent/prompt_builder.py | Hermes 各类规则查找语义不同；作者候选链是 BenchGo 定案 |
| 双计数器 | agent/agent_init.py、agent/turn_context.py、agent/turn_finalizer.py | 默认阈值 10 可核；不能据此声称现有 BenchGo 已实现 |
| 后台 review | agent/background_review.py | Hermes 默认暖缓存完整回放，可被新前台 turn 抢占；BenchGo 单辅助槽+并行不看忙闲是有意选择 |
| FTS5 | tools/session_search_tool.py | 无 LLM 原文搜索，但读取存在长度上限；BenchGo 需按 ID 分页无损读取 |
| Curator | agent/curator.py、skills/AGENTS.md | 14/30 天、归档可恢复、LLM 合并默认关；限自建技能 |
| 影子 Git | tools/checkpoint_manager.py | 文件修改前快照，不撤回外部发送/付款 |
| 安全代填 | tools/browser_vault_tool.py | opaque handle、目标绑定、代填/脱敏是机制参考 |
| 审批 | tools/approval.py | 代码门落实审批；不能把红线文档误写成无需执行门 |
| 交付状态 | cron/delivery_queue.py | delivered/failed/unknown/suppressed 区分，未知发送不盲重试 |
