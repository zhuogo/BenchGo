## 第一批完成门槛

1. 有真实抓取记录的新闻任务，最终 6–10 条、领域覆盖和来源标记符合要求；无文件也能 completed，并在原聊天收到正文。
2. 首次给出 14 条或来源标记不足时，Router 告知原因，自动原单补查/修正，用户不用反复点“重新验收”。
3. 搜索失败但直抓成功：按证据与任务要求交付并说明渠道限制；全部联网失败：明确等待原因和恢复方式，不编造新闻。
4. 确需用户回答的问题有 Attention，回答绑定原单继续；内部核验故障有自动恢复状态，不让用户确认事实真伪。
5. 停止/撤权/版本变化、重启、重复回调和通知失败不导致重复执行；未知外部效果先核实。
6. 桌面真实输入和后台完成均经过持久协议；主聊天自然回复、工单状态与原来源交付一致。

新闻测试固定来源正文、报道时间、抓取时间、错误和已知结论；真实抓取另验，不要求每日新闻相同，不锁定 AI 回复句式。网页实施后执行 `npm run reload:plus`，根 `npm run check` 不替代运行验收。
