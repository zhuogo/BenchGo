# SuperAgent 记忆与技能

本文是自我迭代的唯一机制正文，维护档案记忆、增量来源、11 项职责、历史检索与技能策展。图解见[自我迭代文件与流向](架构.html#iteration-files)，上下文由[模型与上下文](模型与上下文.md#上下文装配)维护，接口和存储由[服务契约](服务契约.md)维护。

## 档案记忆与原文账本

三类数据各有真源，派生视图不另存一套对话或事实：

| 数据面 | 真源与职责 |
| --- | --- |
| 事实与档案 | 受控 Markdown：身份与工作约定、按日详细事实、精选总纲、对象视图和行为复盘；事实有稳定 ID、可信来源和版本 |
| 派生与维护 | assistant.db：文档版本、journal、检索索引、bank 分类视图、增量水位、维护队列、技能、想法候选和遗忘保护；索引与视图可重建，不取代正文 |
| 原文证据 | 官方 Session 是对话和执行过程唯一原件，Harness 是日志唯一写入者；ledger.db 保留业务原文与 Trigger / Thread / Task / Run / Result / Attention / Delivery 关联 |

运行根 R 为基础层 config.dataDir 下的 assistant/，默认 ~/.benchgo/assistant/；源码和随插件发布的任务提示词不在 R 内。

| 文件 | 职责与读取 |
| --- | --- |
| SOUL.md / IDENTITY.md / USER.md / AGENTS.md | 人格、助手身份、用户档案、工作约定；Router 自动装配。姓名以 IDENTITY 为权威 |
| MEMORY.md | 精选短总纲，保存上限 6000 字符、按上下文预算装配；不是全部事实的副本，与 USER 等常驻材料去重 |
| TOOLS.md | 本地环境工具笔记，按需读；真实能力以宿主注册表为准 |
| memory/YYYY-MM-DD.md | 详细事实与变更，保留稳定 ID、类型、来源、适用条件和版本；按日组织但保存即时发生。不建每条 entries 文件 |
| memory/people/INDEX.md、memory/groups/INDEX.md | 小量对象目录，预算内自动装配；每行名称、最多 100 字短摘要和来源引用 |
| `memory/people/<id>.md`、`memory/groups/<id>.md` | 人物与群组对象视图；涉及对象时按需读，以日记事实 ID 为引用，不把重复摘要当新证据 |
| dreams/YYYY-MM-DD.md | 当日行为复盘，写做得怎样、哪里失误、如何改善，不冒充用户事实；按需读 |
| dreams/alignment/ALIGNMENT_SYNTHESIS.md | 简短协作对齐：“如何与用户打交道”；每次 Router 启动自动装配，在安全边界更新 |
| PROACTIVE_PREFERENCES.md | 主动消息的话题、时机、紧急度与形式；每次主动投递决策前读取 |

Dreams 日期页由记忆整合与对齐复盘共用[有界追加辅助](../../plugins/superagent/src/maintenance-memory-upkeep.mjs)：同日最多保留 6 批、正文 12000 字符，同批去重，保留各批事实 ID 与来源引用；任一依赖被遗忘时整页失效，这是轻量的粗粒度清理。ALIGNMENT_SYNTHESIS 仍覆盖为最新的简短综合。

bank 的 world / experience / opinions / reflections 是同一事实集合的数据库分类视图，不生成四份正文，不增加向量库或 memory/index/ 目录。按日事实、对象视图与总纲之间以 ID 和来源引用关联；纠正保留替代关系，遗忘清理相关正文和派生，不能以审计留痕为由保留明确要求遗忘的内容。

- 文档写入保留 expectedHash、版本和 journal；并发冲突先重读，不覆盖用户修改；多文件部分成功须明确记录，不宣称文件与数据库跨介质原子事务。
- 会话快照用于复现已应用的上下文；后续回合在安全边界读取最新档案与记忆版本，纠正与总纲更新不一律等到新会话。当前在途模型请求保持原输入，明确遗忘立即限制旧召回和受影响派生快照。
- 项目规则按 .hermes.md → AGENTS.override.md → AGENTS.md → CLAUDE.md → .cursorrules first-match，同名规则沿目录链合并，深层优先；复用官方上下文能力，不叠加第二个加载器。
- 原文按 ID 返回来源、全长与分页指针，不以摘要冒充原文；记忆与历史搜索分数不混排。记忆、技能、复盘和 AGENTS.md 不能产生或扩大授权，见[权限与对外审批](任务与执行.md#权限与对外审批)。

## 历史会话检索

历史全文检索由 `history-search.mjs` 复用官方 `sessionQuery` 的增量索引，Router 工具和 HTTP 共用同一适配服务。BenchGo 只适配来源范围、公开文字和引用契约，不自建索引、分词或排序。

| 材料 | 默认范围与读取方式 |
| --- | --- |
| 提炼记忆 | 沿记忆服务查事实、偏好、决定与经验，保留来源和版本；词索引匹配，不是向量检索 |
| 历史对话 | 主聊、手动旁聊及其可信 `sessionLineage` 中仍存在且有权读取的公开对话；先返回摘录和位置，再按需读原文 |
| 任务与业务原文 | 经原任务和账本入口按权限读取；Worker、子代理、工具输出及内部通知不进入默认对话搜索面 |

- **范围**：由持久会话归属和当前调用者权限确定，不按标题、cwd 或模型自报猜测。指定会话 ID 仍核对范围；IM 和普通工作台会话不在默认面内。已删除的来源不再命中。
- **两段式**：官方 `searchSessions()` 跨会话定位，同一会话的更多命中用 `searchEvents()`；相关命中按 `sessionId / seq` 经 `readEvent()` 核对，再用 `observeSession()` 的公开投影返回有界上下文。搜索只交付限长摘录、会话 ID、seq、时间与分页指针。
- **公开文字**：真实用户发言和正式助手回复可读；内部宿主输入、中间输出、推理、工具参数与输出不返回。事件类型本身不足以判定公开，由确定性投影复核。展示缓存有界、按 revision 失效，不持久化第二份正文。
- **覆盖限制**：命中遵循官方 `unicode61` 词或短语语义，不保证连续中文句内任意子串命中；只由插件发布记录承载、未写入原生消息正文的文字不在索引内。搜索返回 `matchMode / coverage / limitations` 说明边界，不以全文扫描或自建索引补缺，也不把空结果解释为绝无相关历史。
- **分页与错误**：取消信号贯穿工具、HTTP 和官方调用；分页沿官方不透明 cursor。引用失效、索引禁用、权限不足、取消、来源损坏和游标过期须可辨，错误不触发创建、激活或重放 Agent。

官方首次构建、版本变化和增量对账仍会读取来源日志，不承诺时延不随历史增长。接口字段见[检索与定点读取契约](服务契约.md#检索与定点读取契约)。

## 自我迭代：一大组、四小组、11 项职责

Router 负责对话中的即时识别和同步记忆；**只有一个自我迭代后台执行器**负责五类维护任务，统一领取队列、串行执行、消费增量来源并记录水位。它不负责普通 Worker 执行、执行摘要、投递或 Watchdog，不因此合并这些已有服务。Watchdog 只监督，不调模型做迭代，也不代替执行器维护档案。

| 小组 | 职责 | 机制 |
| --- | --- | --- |
| A 记录与触发（2） | 即时记录 | Router 从真实用户原话主动识别耐久事实、稳定偏好、决定与关系变化；明确记住、纠正、遗忘当场办理，写入成功后才确认，不开任务 |
| A 记录与触发（2） | 静默整合 | 实质对话暂歇后，把尚未处理的合格来源交给统一执行器；与定时和显式请求共用增量范围及去重，不新增 quiet 文件或独立 Agent |
| B 记忆组织（4） | 记忆整合 | 读取增量材料、核对已有事实、处理替代与冲突，更新日记事实并精选短 MEMORY 总纲；无增益可为空 |
| B 记忆组织（4） | 日志层 | memory/日期.md 承载事实与变更，不复制聊天全文；原始对话和工具过程仍在官方 Session |
| B 记忆组织（4） | 派生数据 | 服务维护数据库 bank 分类视图和检索索引；模型不直接改索引，修正或遗忘先使旧召回失效，再清理派生 |
| B 记忆组织（4） | 关系档案 | 按稳定对象 ID 维护 people/groups 的 INDEX 和对象页，引用原事实，明确私人关系与公开资料的区别 |
| C 后台改进（3） | 对齐复盘 | 用真实反馈更新 dreams 日复盘和简短 ALIGNMENT_SYNTHESIS，回答如何与用户打交道，不从沉默推断认可 |
| C 后台改进（3） | 技能评审 | 从可复用方法形成技能候选，结合实际采用、真实使用和效果评审改进版本，不把闲置时长当作无效证据 |
| C 后台改进（3） | 想法策展 | 在数据库维护轻量候选，说明依据、适用条件与不确定性，去重和失效；通过现有聊天/投递呈现，采纳后才走既有任务路径 |
| D 行为约束（2） | 主动投递偏好 | Router 保存用户明确的主动消息反馈，每次主动投递前读取；一次拒绝不自动成为永久禁令 |
| D 行为约束（2） | 常驻配置 | 受控更新人格、身份、用户与工作约定，保留无关字段；临时任务要求不能自动改写稳定人格或授权 |

这 11 项不包含目标研学和上下文压缩。目标清单沿[任务与执行](任务与执行.md#目标清单)维护；压缩沿官方上下文能力处理。

### 增量来源与触发

定时、静默和显式整理请求使用同一来源采集、去重键与处理水位。真实用户消息和正式助手回复从官方 Session 按 sessionId / seq 引用，执行经验从有真实归属的结果与业务原文读取；不同来源保留身份、版本、权限和完成语义。后台任务不得读取工具参数、推理、凭据或内部通知凑材料，也不能把 Router 扩写和 Worker 的习惯归因给用户。

闭单完成、结果版本相符、可信来源和投递回执仍是判断**执行成功经验**的重要证据；它们不是全部记忆材料的准入条件。真实对话、纠正和明确偏好可在任务未完成时保存。失败、等待和未送达也可提供有范围的事实或教训，但不得提炼成已经做成的经验；未知效果继续标为未知，后台整理不阻塞原任务交付。

- 单次任务条件不自动升为长期偏好；用户明确的一般性表达或多个独立请求的一致证据才支持稳定偏好，同一任务重试不算多个证据。
- 五类维护共用静默窗口；新输入到来时让位或延后，即时保存与后台补记共用来源去重。各职责仍有未消费来源时下个统一 tick 续批，不必等待下个长周期。没有新增合格材料就跳过模型调用，不读取当前 Router 全上下文凑数。
- 队列、租约、水位、幂等键、处理上限和失败重试由代码管理；模型只提出有来源的变更。提交成功后推进相应水位，重试复用同批来源，部分失败不吞来源。未调用模型的空材料、无变化或停用结果退还预留额度；真实模型失败或在途取消仍计真实开销。
- Worker 和子代理只提供执行证据，不写长期记忆；Router 工具写入与后台受控写入使用不同的宿主身份，模型不能自行声明后台权限。
- 保留排除、来源版本、纠正、遗忘和回滚边界。后续整理不能恢复已遗忘内容；回滚也不能绕过遗忘和现行授权。

### 提示词与后台边界

宿主必装配的 plugins/superagent/prompts/builtin-layer.md 是 Router 内置职责的唯一真源。Muse 的 system_prompt 是其运行时副本，仅参考原则，不新增同名副本。五份后台任务说明按任务读取，不常驻灌入 Router，也不表示五个后台 Agent：

| 任务说明（plugins/superagent/prompts/self-iteration/） | 维护职责 |
| --- | --- |
| memory-upkeep.md | 定时、静默、显式请求共用的记忆整合 |
| relationships.md | 人物/群组对象视图 |
| dreaming.md | 日复盘和简短协作对齐 |
| skill-review.md | 技能候选与真实效果评审 |
| idea-curation.md | 轻量想法候选与既有投递 |

后台自我迭代不创建工作台聊天、任务、独立任务线或新过程 UI，不播报例行过程。用户仍在现有记忆、技能与档案入口查看结果；值得告诉用户的想法经现有 Router 聊天/投递，并在投递前检查 PROACTIVE_PREFERENCES。写入失败保留真实诊断，用户显式请求时如实说明未完成，不能虚构成功。

### 技能与想法的采用

技能沿用 assistant.db 的候选、正文、版本、使用与审核记录，经官方 SkillProvider 发现和按需读取，不新增一套自建技能文件目录。结构仍以 When to Use / Procedure / Pitfalls / Verification 表达可复用规则、原因与验证；不写成任务流水。

- 候选由现有“工具 → 技能”批准/拒绝；采用与恢复保留版本、证据和回退路径，官方服务不可用时明确提示。
- 实际执行中读取并采用技能才记使用；目录预览不算使用。效果评审分别记录有用、受阻、失败或证据不足，失败可成为避坑规则，不能编造成功。
- 技能只按真实反馈评审，reviewInputs.idleDays 仅提供只读闲置信号；不自动标记 stale，不按闲置时间自动归档，也不提供闲置阈值配置。现有 active / stale / archived 状态及手动归档、恢复继续支持；是否改进须结合适用性、真实效果与现行采用规则，第三方与固定技能保持保护，不自动删除。
- Ideas 是独立数据库候选，不是事实记忆、目标或任务。通过现有聊天/投递说明依据与不确定性，用户明确采纳后再调用既有执行路径；候选生成和投递均不增加授权。

## 管理路径

记忆页沿用时间线、折叠行、全文、来源与历史版本；新增和编辑共用保存，编辑与遗忘独立。对象页、复盘和投递偏好通过受控档案访问，技能沿用[统一技能管理](../04-模型与工具/统一技能管理.md)。后台过程不新增页面或工作台会话。

- 保存、取消或删除后焦点回到对应或相邻记录；切换资源页保留未保存内容和滚动位置。
- 保存失败保留草稿和真实原因；写入成功但刷新失败时只重试读取，不重复写入。
- 纠正和明确遗忘在当前会话后续的安全边界生效；原文引用失效明确报错，不拿摘要冒充原文。

## 实现与验收边界

已接线的基础能力：Router 显式记忆与档案写入、可信来源与版本保护、纠正与遗忘；历史检索适配及公开投影；自建技能数据库、候选采用和官方 SkillProvider。源码接线不代表安装版验收。

本轮已实现（源码接线与定向测试）：按日详细事实与短总纲、当前回合后续刷新、单后台执行器及五任务、定时/静默/显式共用增量来源与欠账续批、人物/群组对象视图、Dreams 日复盘与简短对齐、主动投递偏好、技能真实反馈和候选评审，以及 Ideas 数据库与现有聊天提议入口。闭单可信送达后的来源登记已接入同一增量管线。

Ideas 当前仅在 proactive 显式启用、下一真实用户回合与候选相关时，最多提供一条提议，并读取相关主动偏好；内部调度不触发外发，也不新增自主发送。提议元数据进入上下文不等于 Router 已采用或用户已收到，不自动改变候选生命周期。

真实付费模型的提炼质量、协作改善、技能增益、想法价值及安装版运行效果尚未验证；源码与受控测试不能替代这些验证。

后续独立能力：档案增量 add / patch / remove、统一档案备份、完整编辑与版本回滚界面、大语料按章蒸馏、完整业务原文关系投影。目标研学和压缩不归本轮。

待验证（含安装版）：

- 即时主动记忆及明确记住/纠正/遗忘；来源稳定 ID、版本冲突、新结构版本恢复、当前回合后续刷新、快照与遗忘同步、重启去重及保存失败。
- 定时/静默/显式共用增量来源和单执行器，新输入让位、空材料跳过、部分失败水位不前移；Worker/子代理拒绝写长期记忆，未知或失败不虚构成功。
- 对象 INDEX 与事实引用、bank 无四副本、Dreams 日复盘与简短对齐的实际装配、技能真实使用及效果、固定保护、Ideas 与投递前偏好检查；后台无工作台聊天/任务/过程 UI。
- 历史搜索中文与混合词、跨范围拒绝、内部文字排除、分页原文定位、索引禁用或损坏、来源删除、取消和重启；首次索引、重复查询和真实数据量的耗时分别实测。
