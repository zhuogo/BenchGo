# SuperAgent 记忆与技能

本文维护记忆权威、档案快照、历史会话检索、业务原文账本与学习策展。上下文如何装配见[模型与上下文](模型与上下文.md)，统一身份见[身份与形象](身份与形象.md)。

## 档案记忆与原文账本

三类材料各有真源，检索只提供引用，不另建历史对话存储：

| 材料 | 真源 |
| --- | --- |
| 身份、事实、决定和经验 | 同一助手的 Markdown 档案与结构化记忆 |
| 对话原文与执行过程 | 官方 Session（Harness 是会话日志唯一写入者） |
| 业务原文与来源关系 | 业务原文账本 `ledger.db`，连接 Trigger、Thread、Ticket、Run、Result、Attention 和 Delivery |

| 档案 | 职责 |
| --- | --- |
| SOUL.md | 性格、表达与底线 |
| IDENTITY.md | 姓名、形象与对外身份，是身份名称的权威 |
| USER.md | 主人称呼、时区与偏好 |
| AGENTS.md | 工作约定、审批红线、渠道与保险库规则 |
| MEMORY.md | 决定、关系与长期结论 |
| TOOLS.md | 本地工具笔记；真实工具能力以宿主注册表为准 |

哪些档案自动注入、哪些按需读取，由[上下文装配](模型与上下文.md#上下文装配)维护。宠物与 Router 不各建记忆；身份来源规则见[出厂无名与全渠道一致](身份与形象.md#出厂无名与全渠道一致)。

- 会话按 sessionId 持久冻结档案与 hash，恢复时复用快照；修改即时落盘，下一会话生效；明确遗忘会脱敏已派生的快照。
- 当前保存方式是完整 content 加 expectedHash、版本与 journal。add / patch / remove 增量编辑待实施。
- 并发写入冲突先重读，不覆盖用户修改；多文件部分成功须显式记录。
- 遗忘同步正文、索引与派生内容；已遗忘的内容不得被后续整理重新写回，留痕要求不能抵消明确的删除要求。
- 项目规则按 .hermes.md → AGENTS.override.md → AGENTS.md → CLAUDE.md → .cursorrules first-match，同名规则沿目录链合并，深层优先；复用官方上下文能力，不叠加第二个加载器。
- 业务原文按 ID 返回原文、来源、全长与 nextCursor，不重新总结。记忆检索与历史检索的分数不混排。
- 记忆、技能和 AGENTS.md 不能产生或扩大授权；审批规则见[权限与对外审批](任务与执行.md#权限与对外审批)。

## 历史会话检索

历史全文检索由 `history-search.mjs` 复用官方 `sessionQuery` 的增量索引，Router 工具和 HTTP 共用同一适配服务。BenchGo 只适配来源范围、公开文字和引用契约，不自建索引、分词或排序。

| 材料 | 默认范围与读取方式 |
| --- | --- |
| 提炼记忆 | 沿记忆服务查事实、偏好、决定与经验，保留来源和版本；词索引匹配，不是向量检索 |
| 历史对话 | 主聊、手动旁聊及其可信 `sessionLineage` 中仍存在且有权读取的公开对话；先返回摘录和位置，再按需读原文 |
| 工单与业务原文 | 经原工单和账本入口按权限读取；Worker、子代理、工具输出及内部通知不进入默认对话搜索面 |

- **范围**：由持久会话归属和当前调用者权限确定，不按标题、cwd 或模型自报猜测。指定会话 ID 仍核对范围；IM 和普通工作台会话不在默认面内。已删除的来源不再命中。
- **两段式**：官方 `searchSessions()` 跨会话定位，同一会话的更多命中用 `searchEvents()`；相关命中按 `sessionId / seq` 经 `readEvent()` 核对，再用 `observeSession()` 的公开投影返回有界上下文。搜索只交付限长摘录、会话 ID、seq、时间与分页指针。
- **公开文字**：真实用户发言和正式助手回复可读；内部宿主输入、中间输出、推理、工具参数与输出不返回。事件类型本身不足以判定公开，由确定性投影复核。展示缓存有界、按 revision 失效，不持久化第二份正文。
- **覆盖限制**：命中遵循官方 `unicode61` 词或短语语义，不保证连续中文句内任意子串命中；只由插件发布记录承载、未写入原生消息正文的文字不在索引内。搜索返回 `matchMode / coverage / limitations` 说明边界，不以全文扫描或自建索引补缺，也不把空结果解释为绝无相关历史。
- **分页与错误**：取消信号贯穿工具、HTTP 和官方调用；分页沿官方不透明 cursor。引用失效、索引禁用、权限不足、取消、来源损坏和游标过期须可辨，错误不触发创建、激活或重放 Agent。

官方首次构建、版本变化和增量对账仍会读取来源日志，不承诺时延不随历史增长。接口字段见[检索与定点读取契约](服务契约.md#检索与定点读取契约)。

## 后台学习与技能策展

长期记忆围绕用户的稳定事实、意图和适用条件提炼。单次任务要求不等于长期偏好：偏好应来自用户明确的一般性表达，或多个独立请求的一致证据，同一任务的重试不算多个证据。Router 扩写的工单要求和 Worker 的执行习惯不能成为用户偏好。没有值得保留的内容时返回空结果。

| 环节 | 规则 |
| --- | --- |
| 当面记忆 | 用户明确交代记住、纠正、遗忘，由 Router 当场直写，不开工单，成败如实反馈。Worker 与子代理不写长期记忆，工具执行层对写入做 Router 身份检查 |
| 触发 | `/learn`、明确的自然语言请求，或计数器：同一 Router 会话每 10 条用户输入、单回合第 10 次工具迭代。计数只触发调度，后台输出不递归计数 |
| 调度 | 学习队列只有 learning 一种类型；服务启动处理一次，此后每 30 秒领取一项，默认每日最多 20 项 |
| 取材 | 只取已完成且已送达的工单：completed、结果与指令版本一致、原来源匹配、有 accepted 投递回执。材料是可信原始指令加 Worker 最后一段话。进行中、等待、待交付或投递未知的工单不入选 |
| 批次 | 跨会话全局水位，每批最多五单；失败重试复用同一批次，全部保存后才推进水位。没有新材料时不调用模型，也不读取 Router 当前上下文凑数 |
| 提炼 | 辅助模型每批最多输出五条记忆、两个技能候选，可为空。提示词要求：结果写明没做成的，不提炼成功经验。写入使用批次内稳定槽位，模型重试改写措辞不产生第二份记录 |
| 保存 | 有可信用户来源、有效正文且符合学习规则的记忆自动保存，无逐条批准；技能保存为候选。学习排除、纠正与遗忘屏蔽优先 |

后台整理不经过 Router 的模型回合，不回灌 Router 上下文，也不是交付前置；它不对 Worker 结果评分。整理结果保留来源与版本，用户可事后纠正、遗忘或回滚，回滚不恢复已明确遗忘的内容。工单何时算完成见[结果与交付](结果与交付.md#工单三态与简短摘要)。

技能复用官方 skills，SuperAgent 只生产和策展自建内容：

- 结构为 When to Use / Procedure / Pitfalls / Verification，只写泛化规则与原因，不写任务日志。
- 候选在“工具 → 技能”由用户批准或拒绝；批准后经官方 SkillProvider 提供，正文按需读取。官方技能服务未启用时明确提示。统一管理入口见[统一技能管理](../04-模型与工具/统一技能管理.md)。
- Curator 每分钟检查一次，在 Router 与执行任务空闲时运行，只处理自建且未固定的技能：距最近实际使用满 14 天标记 stale，满 30 天归档，永不自动删除。目录预览不计使用，第三方技能和固定技能不被改写或归档，LLM 合并关闭。
- 使用水位、学习阈值和策展状态持久化，重启不重复写回或归档。

## 管理路径

记忆页以时间线展示已保存的记忆：默认紧凑折叠行，展开后阅读完整正文、来源与历史版本；新增和编辑共用保存流程，编辑与遗忘是独立操作。

- 保存、取消或删除后焦点回到对应或相邻记录；切换资源页保留未保存内容和滚动位置。
- 保存失败保留草稿并返回真实原因；写入成功但列表刷新失败时只重试读取，不重复写入。
- 原文按编号失效时明确报错，不拿摘要冒充原文。

## 实现与验收边界

已实现（源码接线，安装版未据此验收）：记忆直写、可信来源与版本保护、纠正与遗忘；计数学习、闭单取材与全局水位、辅助模型提炼；自建技能候选与策展；历史检索适配、Router 工具与 HTTP 入口、取消传递和公开投影。

待实施：档案增量 add / patch / remove、统一档案备份；技能的完整编辑、归档与版本回滚界面；整理结果回滚界面；大语料按章蒸馏；完整的业务原文关系投影。

待验证：

- 明确记住 / 纠正 / 遗忘、学习关闭与排除、并发冲突、重启去重、遗忘保护、保存失败与冻结快照。
- 当面记忆不派工；Worker 与子代理不能直写长期记忆；未完成或未送达的工单不进入学习；结果写明没做成的工单不被提炼成成功经验；整理不阻塞交付。
- 检索的中文与混合关键词匹配、跨范围拒绝、内部文字排除、分页与原文定位、索引禁用与损坏、来源删除、取消和重启；分别实测首次索引、重复查询和真实数据量下的耗时。
- 技能固定保护、使用水位、归档与恢复。
