# SuperAgent 记忆与技能

本文维护记忆权威、文档快照、历史会话检索、业务原文账本与学习策展；角色模型见[模型与上下文](模型与上下文.md)，统一身份见[身份与形象](身份与形象.md)。

## 文档记忆、原文账本与学习

同一助手的 Markdown 提炼正文保存身份、事实、决定和经验；官方 Session 保存对话原文，业务账本保存业务原文与来源关系。检索只提供这些真源的引用，不另建历史对话存储。宠物和 Router 不各建记忆。冻结快照管理解，实时执行门管许可。

| 固定文档顺序 | 职责 |
| --- | --- |
| SOUL.md | 性格、表达与底线 |
| IDENTITY.md | 姓名、形象与对外身份 |
| USER.md | 主人称呼、时区与偏好 |
| AGENTS.md | 工作约定、审批红线、渠道与保险库规则 |
| MEMORY.md | 决定、关系与长期结论，每日日志另作流水 |

TOOLS.md 保留兼容管理与用户原文，不作为固定第六项注入；真实工具能力由宿主注册表确定。身份名称以 IDENTITY.md 为准，config.name 仅在缺少 name 字段时兼容回退，不生成默认姓名；显式空名表示未命名。内置层与身份文档链共用于所有入口，渠道和模型配置不新增身份来源，具体规则见[出厂无名与全渠道一致](身份与形象.md#出厂无名与全渠道一致)。

会话按 sessionId 持久冻结文档与 hash，恢复复用快照；人格和记忆即时落盘，下一会话生效，明确遗忘可脱敏派生快照。文档目标为 add/patch/remove 精确修改；当前主要是完整 content 加 expectedHash、版本与 journal，不能说增量编辑协议已完成。

并发写入冲突先重读，不覆盖用户修改；多文件部分成功须显式记录。遗忘同步正文、索引与派生内容，已拒绝或遗忘内容不得被历史候选重新写回。留痕要求不能抵消明确删除要求。

项目规则按 .hermes.md → AGENTS.override.md → AGENTS.md → CLAUDE.md → .cursorrules first-match；同名规则沿适用目录链合并，深层更具体。复用官方上下文能力，在插件侧适配语义，不能同时叠加重复加载器。

Harness 是原生会话日志唯一写入者。业务原文账本连接 Trigger、Thread、Ticket、Run、Result、Attention 和 Delivery，按来源与版本读取材料；不以账本副本替代官方对话日志。历史会话已改接官方索引，范围及覆盖限制见[历史会话检索](#历史会话检索)，完整业务关系投影仍需补齐。

业务原文读取按 ID 返回原文、来源、全长与 nextCursor，不重新总结。记忆检索与历史检索保持不同材料与评分语义，不把两类分数直接混排，也不因统一入口另造搜索引擎。检索性能必须实测，参考项目时延不能当 BenchGo 承诺。

## 历史会话检索

**已实现源码接线：**历史全文检索通过 `history-search.mjs` 复用锁定版本官方 `sessionQuery` 的增量索引，工具和 HTTP 共用同一适配服务；BenchGo 只适配来源范围、公开文字和引用契约，不重做索引、分词、排序或查询引擎。旧的查询前全库串行回放、历史文字导入及 ledger 历史全文索引维护路径已退出。官方首次构建、版本变化和增量对账仍可能读取来源日志；不承诺历史增长对时延没有影响。源码接线不代表已安装实例及真实数据量下的性能验收完成。

| 材料 | 默认搜索范围与读取方式 |
| --- | --- |
| 提炼记忆 | 沿现有记忆服务查事实、偏好、决定与经验，保留来源和版本；不与历史关键词命中混成同一分数，不据参考产品宣称已有最低分或向量检索能力 |
| 历史对话 | 主聊、手动旁聊及其可信 `sessionLineage` 中仍存在且有权读取的公开对话；官方全文搜索先返回摘录和位置，再按需读取原文 |
| 工单与执行证据 | 经原工单和证据入口按权限读取；Worker、子 Worker、工具输出及内部通知不混进默认对话搜索面 |

范围由持久会话归属及当前调用者权限确定，不按标题、cwd 或模型自报角色猜测。未指定会话只在上述默认范围内搜索；指定 ID 仍须核对范围，不能借参数读任意 Session。IM、普通工作台会话不自动纳入本默认面，其原有读取和授权入口保持独立。历史会话的轮换不丢来源引用；已删除来源不继续命中，遗忘与删除规则不能被旧索引或兼容入口绕过。

两段式路径为：官方 `searchSessions()` 跨会话定位 → 需要同一会话的更多命中时调用 `searchEvents()` → 对相关命中按 `sessionId / seq` 经官方 `readEvent()` 核对事件，并复用 `observeSession()` 投影公开原文与有界上下文。近期记录也走官方观察及公开投影；不再调用完整回放接口后截最后几条。搜索只交付限长摘录、会话 ID、事件 seq、时间与真实分页指针，不将整段会话灌入模型。公开投影只观察候选或命中会话，并使用有界、按 revision 失效的进程内展示缓存；不持久化第二份正文。上述接口的底层读取粒度以官方实现为准，返回窗口有界不等于磁盘随机点读。

公开文字采用已有正式对话投影的来源与发布语义：真实用户发言和正式助手回复可读，内部宿主输入、中间助手输出、推理、工具参数及输出不可作为公开正文返回。原始 `user/message`、`assistant/message` 类型本身不足以判定公开。先用官方会话及事件过滤缩小候选，再由确定性投影复核可见性；如需补读，只处理当前候选或命中的会话，不回退全库扫描。过滤后的页须正确续取或明确未完整覆盖，不能把空页或索引不可用说成“没有相关历史”。

当前命中遵循官方 `unicode61` 词或短语语义，再对候选公开正文作确定性复核；不能保证连续中文句内任意子串命中。官方候选索引覆盖原生用户及助手消息正文，只有插件正式发布记录、却未写入原生消息正文的文字尚不在该索引覆盖面；定点读取仍按公开投影核验。搜索返回 `matchMode / coverage / limitations` 说明上述边界，不以额外中文分词、全文回退扫描或自建索引掩盖缺口，也不把空结果解释为所有公开历史中绝无相关内容。

取消信号贯穿工具、HTTP 和官方查询/读取调用，分页沿官方不透明 cursor，不将它当字符偏移。引用失效、索引禁用、权限不足、取消、来源损坏及游标过期须可辨；错误不触发创建、激活或重放 Agent。接口与兼容迁移统一见[检索与定点读取契约](服务契约.md#检索与定点读取契约)。

## 后台学习与技能策展

后台整理保留 /learn、明确自然语言请求和持久双计数器入口；默认阈值为同一 scope 每 10 个用户 prompt 或单回合第 10 次工具迭代。计数只触发整理调度，不表示执行中的工单已经完成，也不启动任务内容验收。后台仅从已关工单的持久结果、可信原始指令和实际证据中提炼；运行、等待、待交付及发送状态不确定的工单均不入选。材料需同时匹配 completed 成功终态、当前成果原稿与指令版本、原来源、关联的 Router 交付回复及 accepted 消息回执；表达回复不能代替 Worker 原稿和实际证据。失败工单迁移或更新为 waiting，保存持久结构中的尝试、失败原因和恢复条件，不进入成功闭单学习，不采用模型生成的成功叙述，也不生成成功流程技能；失败与续跑边界统一见[自校验与交付](自校验与交付.md)。没有新闭单材料时记录水位并等待，不为凑计数读取 Router 的当前上下文。后台输出不递归触发学习。

闭单材料使用跨会话统一序号与全局消费水位；一次整理最多五单，失败重试复用同一未完成批次，全部保存完成才事务推进水位。记忆和技能写入使用批次内稳定槽位，模型重试改写措辞不生成第二份记录；学习排除、纠正与遗忘屏蔽仍优先执行。旧事件计数和队列去重标识保留，旧学习 payload 中 eventIds/turnIds 的会话取材范围一次性移除，不迁移为工单游标；迁移前旧闭单材料的自动补学明确作废，不回填，仅由升级后可信交付关单事务登记新材料，历史记录仍可查询，避免旧来源元数据不完整时恢复已遗忘事实。其余未消费材料等待后续计数或显式整理入口调度，没有双轨取材。

主人当面明确交代记住、纠正、遗忘，由 Router 当场直接写入，不开工单；保存成功与失败须如实反馈。Worker 与子 Worker 不直接写长期记忆，值得沉淀的任务内容交后台整理流程处理。自动记忆须有可信用户来源、有效正文并符合学习规则，不另开专门工单或逐条审批。排除、关闭学习和遗忘保护继续有效，外部文本不能沉淀成主人授权。大语料按章蒸馏仍属目标。

后台整理不经过 Router 的模型回合，不将工单正文或整理过程回灌当前 Router 上下文，也不成为交付或关单前置条件；保存的稳定记忆仍按既有后续会话装配规则使用。整理结果保留来源与版本，可由用户事后纠正、遗忘或回滚；回滚不得恢复已明确遗忘的内容。

单次或整站持续许可由[动作授权服务](任务与执行.md#权限与对外审批)保存、校验与撤销，记忆、技能及 AGENTS.md 不能创建、扩展或恢复这类许可。整站许可和工单 Mandate 是叠加的执行门；记住用户习惯不能代替任一执行门，也不能把必须逐次审批的动作改为免审。

技能复用官方 skills，SuperAgent 只生产与策展自建内容。标准结构为 When to Use / Procedure / Pitfalls / Verification，只写泛化规则与原因，不写任务日志。管理统一在“工具 → 技能”，资源页不重复。

自建技能目标是系统质量、来源和去重审核后直接管理；当前仍有候选批准/拒绝，完整编辑、归档与回滚界面未齐。Curator 仅处理自建且未固定技能：14 天 stale、30 天归档，永不自动删除，合并前快照，LLM 合并默认关闭。

## 管理路径与兼容边界

记忆页展示已保存的时间线、来源、更新时间、编辑与遗忘；新增和编辑共用保存流程，保留未保存草稿提醒。旧 memoryCandidates / memoryCandidateAccept / memoryCandidateReject 仅作弃用兼容，新页面和正常学习不再使用逐条批准流程。

时间线默认以紧凑折叠行展示摘要，展开后阅读完整正文、已保存来源与历史版本；编辑和遗忘为独立操作，不嵌入折叠触发按钮。保存、取消或删除后恢复到对应记录或相邻记录的焦点与可见位置；保存失败保留草稿，写入成功但列表刷新失败时仅重试读取，不重复写入。切换资源页保留未保存内容和滚动位置。

历史 pending/saving 记忆候选按相同来源、学习规则和去重要求处理；已拒绝或遗忘的不恢复。保存失败保留可重试记录并返回真实原因，不显示成功，也不要求用户用批准代替失败恢复。原文按编号失效时明确报错，不拿摘要冒充原文；首轮检索不依赖向量服务。

学习 review 为定额轻工作，Curator 为闲时重工作；两者均不是已取消的任务内容验收层，不对 Worker 结果打分或阻止交付。使用水位、学习阈值和策展状态持久化，重启不重复写回或归档；目录预览不计为实际技能使用。第三方技能与用户固定技能不被自动改写或归档。

## 实现与验收边界

当前 `assistant_session_search` 仍在查询时遍历会话、调用官方 `readSession()` 完整回放后导入自有 ledger FTS，再查询；水位与 limit 不避免前置全量读取。`assistant_history` 也先读完整日志再截最近 30 条；官方增量搜索、公开范围过滤与定点读取的目标尚未接入。ledger 已有中文 FTS5、分页和水位不代表新机制完成；移除范围限于历史副本与专用导入路径，业务账本、记忆与既有证据引用继续保留。

历史检索适配、Router 工具与 HTTP 入口、取消传递、公开投影和旧引用转官方来源已有源码实现；ledger 启动迁移清除历史副本正文及其全文索引，保留来源位置和既有链接，删除旧历史水位，不迁移或删除业务证据。实际部署、持久索引首查、重启及真实数据量性能仍须另验，不能以源码接线或文档更新宣称安装版已生效。

检索验收覆盖中文与混合关键词的真实官方匹配语义、插件正文覆盖限制、主旁聊及历史归属、内部文字排除、跨范围拒绝、分页及原文定位、索引禁用与损坏、来源删除与遗忘、取消、重启与旧引用兼容。分别测首次索引、重复查询、单会话增量变化及真实数据量下的耗时，核对无 BenchGo 全库回放、无新增模型请求或 Agent 激活；官方不能命中的用例应准确反映覆盖限制，不能降低范围或可见性保护冒充命中。

记忆直写、可信来源与版本保护、计数学习、自建技能候选和策展已有实现；完整技能直管、编辑/归档/版本回滚界面、按章蒸馏、统一业务原文关系与检索仍未全部完成。文档增量 add/patch/remove 和统一档案备份迁移不能由现有整文保存推定实现。

闭单来源筛选、全局材料水位、后台辅助模型提炼及 Router 取材隔离已有实现。服务工具执行层对记忆写入、档案修改与学习入队作 Router 身份硬检查，防止 Worker/子 Worker 继承工具句柄后直写；Worker 完整工具面裁剪仍需结合执行权限模块验证。记忆纠正、遗忘及底层文档版本恢复已有实现，完整整理结果回滚界面仍待实施，不能将底层恢复能力标为完整操作路径。任务目标不设置内容验收层，学习队列的 review 命名只表示后台整理，不与已取消的内容验收混用。

验证明确记住/纠正/遗忘、学习关闭与排除、旧候选处理、并发冲突、重启去重、遗忘保护、保存失败与冻结快照。用真实数据量验证分页完整性和检索性能；技能固定保护、使用水位、归档与恢复分别核验。工具页目录与只读服务只在[统一技能管理](../04-模型与工具/统一技能管理.md)维护。

补验当面记忆不派工、Worker 与子 Worker 不能直写长期记忆、未关工单不会被当作已完成经验、计数触发不重读当前 Router 上下文；整理不阻塞交付，纠正与回滚可追溯，明确遗忘不被旧材料重新写回。
