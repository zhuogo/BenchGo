# SuperAgent 服务契约

本文是跨小模块公共接口与数据不变量的唯一说明。具体行为分别见[板块导航](设计.md#小模块设计)，机器字段以 OpenAPI 和已发布 schema 为准，目标设计不自动成为可调用能力。

## 领域记录与版本

| 记录 | 权威内容与不变量 |
| --- | --- |
| Trigger | 统一入口管线通过后登记的稳定来源键、渠道/来源类型/会话或话题/消息、actor、原文及时间；不可变、去重，同键异内容不能覆盖历史；来源标注以[链接与渠道](链接与渠道.md)为准 |
| Candidate / Eval | 上下文引用、准入依据、规则版本、批次、owner、attempt、deadline 与结果状态 |
| Decision / Disposition | 模型建议、代码复核、原因、规则引用与实际去向，支持审计 |
| Ticket | 标题、目标、用户要求与自校验依据、活摘要、来源、生命周期与 instructionRevision；目标不设置独立内容验收结论 |
| Mandate | 每份授权快照完整记录策略版本、范围、强度、命中规则、发起人身份五要素及可信原始指令引用；无命中书面规则时明确为空列表；授权版本不可变，不含资源预算，不新增用户必填授权表 |
| Assignment / Run | 任务包及已应用完整要求快照、执行安排、优先级，真实官方 session、父子关系、执行代际、工作区、租约、fence、检查点和效果状态 |
| 工单输入账本与修订快照（已接线） | 原始输入引用、可信来源/发起人、目标工单、幂等键、完整要求快照、后台要求编号与授权版本、已收到/待应用/已应用、应用该输入的实际 Run 和工具边界；跨入口只应用一次 |
| Subscription | Thread 与 Ticket 多对多关系、消息游标、持有/处理/释放状态，不扩权 |
| Result | 当前要求版本的成果原稿、原文证据、按目标需要的产物、原 Worker 会话轻量自校验记录与未尽事项；保存后向所属 Router 发完成信号，原稿在工单详情保留，不附独立模型评分或内容放行结论 |
| Attention | 原问题、请求人、来源、工单与要求/结果版本、回答及处理状态 |
| 外部动作与授权记录（已接线） | 可信授权人、精确 origin/服务、动作与类别、期限、注册通道、冻结目标与最终提交内容及摘要、工单/Run/调用归属、单次消费键或网站持续许可及撤销状态；授权与执行效果分开，不含凭据明文，单次批准只执行冻结此件 |
| 动作类别与通道注册（已接线） | 四类高危均有类别及默认 handoff；仅可信代码声明类别、专用操作和内容准备/提交实现，核心校验后纳入可执行通道；新增渠道不增加核心渠道特例，当前内置通道范围见[权限实现边界](任务与执行.md#实现与验收边界) |
| 用户接管点（待完善） | 当前无适配器返回 handoff、原因和动作/能力标识；完整页面或应用定位、已完成准备、最后一步及接管状态设计尚待补齐。接管不产生通道许可，不把用户点击推定为实际成功 |
| Router 表达交付（已接线） | 完成信号关联工单、来源、要求与结果版本；Router 读取保存原稿并主动自然表达，自选摘要或完整回复；保存正式稿及原稿引用后由统一 outbox 投递，不设置内容放行结论、重派或验收操作；实现边界见[自校验与交付](自校验与交付.md#实现与验收边界) |
| Delivery / Outbox | 原来源、来源适配器绑定、Router 成果回复/失败说明/问题引用、幂等键、尝试、回执、错误与下一次投递；统一 outbox 调用来源适配器，回执回同一工单；成功回复确认送达才 completed，结构性无解说明确认送达才 failed；生成或投递失败均待交付，不触发 Worker 重跑 |

instructionRevision 是普通要求修订的后台编号，用于顺序、归属和防迟到；配置 revision 或记录版本用于并发控制。原范围输入先写同单账本及完整快照，在原 Worker 下一工具提交边界整份原子切换；在途工具继续使用已固定快照，不为普通修订取消、停跑或重建分派，同一批工具不混用要求编号。暂停只收、不自动恢复。仅超 Mandate 扩权经真实用户确认后生成新授权版本；要求编号与授权版本分别保存。叫停或撤权立即拦新动作并请求取消可取消的在途执行，实际停止事实另记。行为权威见[工单、跟进与目标](任务与执行.md#工单跟进与目标)。

Mandate 的命中规则只引用用户预先授权的书面规则，默认授权不能由模型、机器消息或外部正文产生。Worker 与一层子 Worker 逐层继承并按任务及工具面裁剪，不扩权、不复制凭据，具体边界见[权限与对外审批](任务与执行.md#权限与对外审批)。

业务工单状态、执行状态、等待原因和交付状态分别记录。用户始终与 Router 对话：Worker 原稿先落库并发完成信号，Router 读取后主动自然提醒，自选摘要或完整回复再交付原来源，不重派或增加内容验收。成功回复确认送达后 completed；结构性无解的失败说明确认送达后 failed 关单，保留原稿并可由用户明确继续或调整。生成或投递失败保留待交付，只重试 Router 表达或补投已存回复；超时、临时故障与效果未知先核实或恢复，不盲目关单、重复执行。状态说明由 Router 自行判断，无固定报告、标题前缀、系统状态文案或硬兜底，真实状态留在任务列表。idle、模型停笔、HTTP 成功、播放 ACK、送达与已读分别记账。流程权威见[自校验与交付](自校验与交付.md)。

以上区分领域语义、已接线记录与待完善接管体验；当前字段和返回值以 OpenAPI 为准，不以设计文字冒充已部署行为。

## 公共接口与数据契约

人端 HTTP 统一为 POST /api/commander/assistant，机器字段以[OpenAPI](../../plugins/benchgo/openapi.json)为准；模块实现见[服务装配](../../plugins/superagent/src/service.mjs)。旧 action 适配同一领域服务，不另存状态。

| 接口族 | 关键契约 |
| --- | --- |
| state / ensure / history / send / requestState / cancel | 会话、持久收件与回执；接收、处理、任务完成分别表达 |
| assistant_delegate / assistant_tickets / assistant_ticket_control / assistant_ticket_change | 绑定宿主 Agent、可信原始指令、同单输入账本与逻辑 thread/sessionLineage；模型参数不能声明 owner。接单记录标题/活摘要查重依据，普通修订与扩权确认分流 |
| ticketAnswer | ticketId、attentionId、instructionRevision、requestId 与真实答案；校验原问题、来源、版本与状态 |
| ticketResume | 明确恢复动作才继续，先应用暂停期间最新已授权完整快照；校验原执行身份与效果，queued:false/code 不是恢复成功 |
| config / profileDocuments / memorySave / memoryDelete | revision 或 expectedHash 冲突保护，秘密不返回；当面记忆目标由 Router 直写，Worker 不写长期记忆，后台计数整理只读已关工单、不经 Router 上下文；旧记忆候选接口仅弃用兼容 |
| connectionCatalog / connectionConfigure / connectionCredential / connectionAction / connectionStatus / connectionVerify | 配置、凭据、安全操作与运行状态分离，使用真实连接结果 |
| actionPermissions / actionPermissionCreate / actionPermissionRevoke | 已接线的真实授权人管理接口；站点许可限定精确 origin、login/private-upload、期限与 actor/profile，列表和审计脱敏，撤销阻止后续提交；许可不代表当前已有对应登录/上传执行适配器 |
| assistant_external_action | 已接线的 Worker 专用 catalog/prepare/submit；仅可信注册通道，冻结动作绑定工单/Run/授权/策略，正式审批只接受 allowed-once，无通道 handoff，未知回执 uncertain 不重放 |
| ledgerRead / assistant_ledger_read / assistant_session_search | 依权限分页返回原文，不按摘要伪造来源；证据查阅不调用独立语义重审或评分 |
| 执行会话关联与定位（目标） | 项目工作区/官方「未分组」（按最近活动排序）会话、执行会话标记及工单反向定位共用真实 Ticket/Assignment/Run/session/工作区关系；定位不重派，缺记录明确不可用；具体交互见[任务列表](../02-工作台与Agent/任务列表交互.md) |
| ownedSkills 与批准、拒绝、固定、恢复 | 当前候选协议保留；未实现直管操作不能先注册为可用 |
| artifact / system-file / Voice 兼容路由 | 保留鉴权、受控目录、文件类型与大小约束，Voice 生命周期由 Voice 服务负责 |

Router 的 assistant_* 工具只注册给拥有会话的 Agent，不等于全部暴露为外部 MCP。外部 MCP 保持既有委派边界，不新增任意配置、凭据明文、历史读取或消息发布权。人端接管、凭据录入、导入等不能用模型声明代替真实用户权限。

授权行为唯一正文见[权限与对外审批](任务与执行.md#权限与对外审批)。动作服务接收能力声明、准备结构化动作、生成绑定冻结快照的审批请求、由真实用户答复、复核并单次提交、记录回执；无通道返回可恢复的接管点，不返回可由任意脚本消费的通用批准。注册类别、实际通道及许可匹配均由宿主验证，模型只可提出待审动作，不能注册可信能力、写入许可或回报用户已批准。浏览器/终端保留其他工作能力，不承诺从任意调用中识别高危提交。安全凭据录入是独立人端秘密协议，不作为 ticketAnswer 普通正文；录入与动作获批分别表达。目标记录未发布 schema/API 前不注册为可用接口。

assistant.db 保存控制面、工单及运行记录；ledger.db 保存可重建原文检索；官方会话日志保存原始执行；Markdown 保存提炼正文；state.json 保存逻辑会话映射等状态。默认数据根为 ~/.benchgo/assistant/。

渠道适配器不保存自身对话状态，不另建渠道工单或渠道专属会话存储。各渠道与桌面都是统一工单的入口，工单输入账、业务状态、投递记录与关单条件全局唯一；统一工作台会话可带来源标记呈现并直接回复，渠道归属不产生第二份记录。适配器只提供来源证据与原生概念映射，规则服务执行来源核对、聊天范围、准入和研判；渠道授权按适配器逐项绑定、可独立撤销，授权校验仍归统一服务。

副作用先持久登记，数据库事务不等待模型或网络。先一致保存 Worker 原稿、实际失败材料及绑定版本的 Router 通知，再异步生成并保存 Router 回复与唯一 outbox；实际送达回执一致记录交付状态及对应关单终态，不能在原稿落库或回复生成时提前 completed/failed。提交只做来源、已应用要求快照、有效执行身份及落库的确定性校验，不设语义 review gate；原文证据按权限查阅。生成失败只重试 Router 表达，投递失败复用已存回复，两者保留待交付，不重跑 Worker。文件与数据库用 journal/hash 恢复一致，不宣称跨介质原子事务。通知、生成与投递按稳定身份去重，发送重试与执行恢复分别处理。

错误区分参数、认证/权限、版本/幂等冲突、能力不可用和效果未知；成功响应不得同时掩盖未应用、未完成或未送达。停用 SuperAgent 释放自身监听、计时器、worker、路由和数据库，保留用户数据，停止服务不等于撤销外部效果。

## 接口演进与验收

存储、HTTP 与工具版本独立管理。旧 action 适配同一领域服务；不兼容配置明确提示升级或只读，不注册尚未部署的操作。模型工具、HTTP、渠道和桌面复用同一身份、准入、状态及版本校验。

统一输入账本、原 Assignment/Run/session 续做、工具批次快照切换、暂停只收件、扩权真实批准回执，以及动作授权存储/注册/审批和管理接口已接线。问答卡持久绑定 sessionId/callId、questions、Attention.id 与要求编号，即时/迟到答案幂等回原问题，跳过不产生许可。执行会话交互见[对话交互](对话交互.md)，渠道与送达关单边界分别见[链接与渠道](链接与渠道.md)、[自校验与交付](自校验与交付.md)。入口 Assessment、后台学习 review 与软件测试验收各保留自身职责。

Router 表达交付已接线；具体机制和实现边界见[自校验与交付](自校验与交付.md#实现与验收边界)。接口验收须覆盖完整的执行、回复生成、持久投递和可信送达路径，并分别核对正式审批卡、真实渠道及重启恢复，不能以静态渲染代替实际业务效果。

每批实现同步领域服务、HTTP/工具、OpenAPI、能力发现、客户端入口与对应验证。核对真实源身份不能由载荷或模型声明覆盖，跨会话工单控制被拒；参数、权限、版本冲突、能力缺失和未知效果分别可辨。完成结果与 outbox 的一致性、文件/数据库 journal 恢复和停用释放须独立核验，不能以 HTTP 成功代替任务完成或投递成功。

新增验证无独立内容验收模型或评分返工；Worker 原稿、完成信号、Router 自然回复及回执按版本关联，原稿在详情可查，Router 主动表达、自选摘要或完整回复且不重派或验收。成功/结构性失败说明送达后分别 completed/failed；生成失败只重试表达，投递失败只补投，两者保持待交付且不重 Worker。验证无固定报告、标题前缀、状态硬文案或兜底。验证五要素实存完整、工具范围不超原指令，普通修订在原执行边界整份切换且不打断在途工具、暂停不续跑、叫停撤权优先、扩权才生成新授权版本；统一输入跨入口去重与已应用关联可追溯，真实执行会话双向定位不重派。网站许可按类别/期限匹配，高风险逐次审批，重启不重放未知效果。
