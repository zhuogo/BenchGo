# SuperAgent 模型与上下文

本文维护角色模型与上下文装配。共享供应商和不透明 ID 的基础规则见[模型与工具](../04-模型与工具/设计.md)，文档权威和冻结规则见[记忆与技能](记忆与技能.md)。

## 上下文装配

上下文目标按三个层次装配：固定文档层、近期原文层、按需材料层。开局装配、每回合补材料、长会话整理各有触发点，压缩不删除原文引用、不偷偷刷新冻结文档。

Router 的十项开局包依次为：系统指令、运行信息、五文件全文、对齐总结、关系索引、活跃目标摘要、能力目录、保险库清单、其他对话摘要、本会话窗口。索引与目录只给名单，正文按需取。

能力目录反映当前真实可用性，保险库清单只给非秘密元数据和句柄。Main Agent 内部完整能力不代表 Worker 获得全套上下文；Worker 的上下文切片与工具面按[权限继承规则](任务与执行.md#权限与对外审批)同步裁剪，授权记录由服务读取，不以提示词或历史摘要代替。

Worker 只拿本工单任务包：目标、用户原话与必要上下文、自校验固定要求、Mandate、当前输入及原文指针。子代理只拿父 Worker 分出的任务切片与原文指针，不复制 Router 开局包或父会话完整历史，不以 fork 全量历史绕过切片。子代理最多一层，继承同工单权限门，工具面继续收窄且不提供凭据工具。辅助模型只拿本次生成、压缩、研判或整理所需材料。上下文切片不能代替执行时权限校验。

Worker 在原执行会话快速轻量自校验，优先使用可运行的测试、构建或命令输出，将成果原稿与证据保存到工单并向 Router 发完成信号。用户始终与 Router 对话；Router 读取已存成果，主动自然提醒已完成，自选摘要或完整回复，再向原来源交付。Router 只负责表达，不重派、不做内容验收，不固定报告、标题前缀或系统状态文案；原稿保留在工单详情，追问仍可按需读取直接回答。实际改成果走在办修订或关联调整单；生成或投递失败保持待交付，只重试表达或投递，不重跑 Worker。具体见[任务与执行](任务与执行.md)与[自校验与交付](自校验与交付.md)。

用户当面交代的记住、纠正、遗忘由 Router 当场直写，不开工单。Worker 与子代理不直接写长期记忆；后台整理流程按计数器从已关工单的持久材料中提炼，不经 Router 上下文，整理结果可纠正、可回滚。具体规则见[记忆与技能](记忆与技能.md)。

## 三角色模型与会话归属

### 自有会话角色装配

Agent preset、permission preset 与模型路由分别管理。`session-role-assembly.mjs` 统一配置 Router / Worker 的官方 `standard` 能力组合及 `workspace-write + ask` 权限 bundle，保留既有 Router 工具身份白名单、Worker 工单权限门和角色模型路由。装配核对真实 bundle，而非根据预设名称推测权限；官方 `danger-full-access` 默认附带 `never`，不用于本装配。宿主服务、预设或 bundle 不可用时明确受阻，不回退用户当前档位。工作区之外的操作仍受宿主沙箱与真实审批约束，业务授权本身不会使底层自动放行。

会话归属来自持久主聊 / 旁聊状态、Assignment / Run 和官方子会话 parentSession；不依赖标题、当前页面或模型声明。`sa_session_roles` 只保存身份、预期装配与最后实测配置，普通会话查询返回空；旧自有会话尚无装配记录时仍显示所属角色和“待核验”，不能视为普通会话。记录包括实际挂载与日志选择的 Agent preset、插件模块、工具面、沙箱及额外可写目录、审批策略、当前模型和正式 request/header 的模型 / 工具身份；不复制对话、工具参数或输出。

新建与首轮前自有会话通过官方 `agentPresets.mount/select` 纠正组合，执行前复检，工具派发再检查装配是否被改动。主聊档位不会传入新 Worker，Worker 的模型继续使用创建时冻结的工作路由。permission bundle 可通过官方 `permissionPresets.set` 独立纠正；该 setter 不回答、取消或替换未决审批，原审批身份与真实用户决定仍沿官方生命周期及业务账复检。更换已运行会话的 Agent preset 则没有当前官方迁移接缝：记录 `ROLE_MIGRATION_UNAVAILABLE` 并阻塞，不通过重新 mount、fork 或重放迁移，不丢历史、工单及待办关联。输入框选择器只读呈现另见[对话交互](对话交互.md)，底层校验不依赖隐藏界面。

一层子 Worker 由官方 spawn 建立独立 Session，并继承父 Worker 的确切 preset revision、沙箱和当前工作模型，再按既有工具白名单与当前工单取交集。官方委派固定将审批收窄为 `never`，实测记录明确标注 `parent-required`；需要审批的动作受阻并把真实原因交父 Worker，不声称子会话仍能独立弹批、不把拒绝当批准。凭据、再次委派及直接向用户提问不进入子工具面。独立 Session 不表示独立宿主进程。

| 模型角色 | 配置与行为 |
| --- | --- |
| Router 对话模型 | 系统 models 首选与备用队列，主聊、旁聊共用；新回合按本角色路由，回合内冻结实际请求参数 |
| Worker 工作模型 | 新执行会话取系统工作角色 workerModels 及参数，在会话创建时冻结首选、备用顺序与参数；所属项目或工作区的默认模型不参与覆盖 |
| 辅助模型 | 系统 auxiliary 槽及备用名单，按生成、看图、压缩、研判、总结与后台整理等能力使用；只处理本次工作材料，不承担工单内容验收 |

执行会话属于任务所在项目的工作区，并在工作区会话列表带工单标记；从任务列表打开工单详情可进入同一会话，聊天消息不提供该跳转入口。无项目任务落官方「未分组」；这就是本设计的“最近”，指按最近活动排序、随时可翻到的落点，不是独立工作区名称。会话的展示归属与模型归属分别确定：移动或恢复所属工作区不将其模型改成该工作区或项目默认值。执行会话输入与主聊天归入该工单的输入共用同一份记录，模型路由不因插话或普通修订重新选择；会话入口和归档规则见[任务与执行](任务与执行.md)。

已有执行会话续跑使用创建时冻结的工作角色路由与参数，不随之后的系统、项目或工作区配置改写。运行故障可在该冻结备用队列内有界切换；切换后持久记录实际选择，后续续跑沿用该选择，不每次退回首选模型。恢复时不得用最新配置重新拼接备用名单或替换旧参数。

子代理默认继承父 Worker 当前实际使用的工作模型及相应参数，包括故障切换后的选择，不取辅助模型或项目默认模型。子代理的选择仍受同一冻结工作角色路由约束，不能借工具配置或会话 allowlist 静默使用角色之外的模型；不支持的覆盖须明确拒绝或交回父 Worker 处理。模型切换不放宽工单授权和工具面。

入口研判与后台整理可使用辅助模型，不对工单结果评分或决定放行；Worker 自校验留在原执行会话，不另开验收模型会话。模型角色是配置分工，不要求三个模型或 Agent 同时常驻。未配置工作角色、辅助能力不可用等情况须给出明确状态或配置中可见的回退规则，不默默借用项目默认模型；辅助路由兜底不将后台结果注入 Router 聊天上下文。

providerId、modelId、工具名和协议值都是不透明标识，不猜别名或静默改写。选择、保存、重载、能力解析和实际请求必须一致，编辑单项保留其他配置；能力不支持要明确告知。

资源导航中的「模型」独立管理三个角色；身份页仅管理名字与形象。角色区域可折叠，折叠摘要展示首选与备用数；完整供应商和模型 ID 可展开、选择与复制。保存按完整草稿校验，缺失、重复或非法 ID 自动展开对应角色并保留草稿；目录读取失败允许重试或手填完整 ID，不将显示名称当作协议值。编辑与排序后保持键盘焦点，保存失败在原页重试，不丢失其他角色配置。

Fallback 按错误分类、有界备用顺序执行：取消、政策或权限拒绝不切换绕过，403 仅在适配器明确判定凭据故障时处理。跨供应商保留对话语义与工具结果，重新解析推理参数，不重放已生效工具。

密钥池仍是已定目标，当前旧 keyPools 已移除，后续复用基础层凭据与供应商路由落实；不能恢复旧字段冒充完成。RouterGo 管其供应商内部线路，本地备用管客户端目标不可用，避免无界叠加重试。

## 执行摘要与监督判断

执行摘要由服务端消费统一执行事实自动触发，不占用 Router 对话回合，也不由 Worker 自报进度。接单、阶段或工具组结束、子 Worker 派出与返回、受阻与等待、暂停停止与恢复、自检及终态等关键事件先展示确定性粗状态，再合并为约 30 字、最多 40 字的当前摘要；列表与详情读取同一派生投影。摘要只改变展示，不修改工单状态、验收结论或通知 outbox。

后台执行摘要与独立 Watchdog 的进展判断显式使用 `auxiliary-only` 路由，复用配置中的 `auxiliary.summary` 能力及其有序辅助队列。辅助角色可以选择与 Router 相同的模型 ID，但使用自身参数；未配置、能力未启用、超时、失败或输出无效时，不追加或跳回 Router。既有用户主动总结、入口研判等调用保留各自原有路由规则，不能把后台严格路由概括为所有辅助调用都禁止既有回退。取消及权限、政策拒绝不靠切换模型绕过。

摘要默认按 4 秒窗口合并，最长等待 12 秒，关键事件达到阈值也可提前处理；每单最多一个在途请求，全局最多 2 个，单单最小调用间隔 15 秒、全局启动间隔 1 秒，输入上限 8000 字符、单次超时 20 秒。窗口、阈值、并发、频率、输入及超时均可配置。待处理工单与消费水位持久化，重启继续合并；持续事件不会无限推迟发布。同阶段的新事件可保留已绑定旧水位的有效文字，新的运行、要求版本或状态阶段则阻止迟到结果覆盖。此类限额只约束后台开销，不构成工单执行预算或截停条件。

模型输入只取 `executionFacts.evidence()` 的白名单结构：脱敏目标和验收、受控状态、事件类别与计数、证据引用、必要的产出变化或检查事实、上一版摘要。目标与要求自由文本在发送前同样脱敏并限长，不传原始工具参数、完整输出、凭据或思维链，不把执行文本当成指令。当前工具计数明确为会话累计，不能推定为当前要求版本的新进展；尚无可核验产出变化时标记 `outputObservation: unknown`，不将空数组说成“已检查且没有产出”。证据不足只描述已知活动，不编造完成、原因或效果。

摘要绑定 Ticket、Run、要求版本、证据水位及状态阶段，更新时复核归属和水位单调性。`assistant.db` 仅增加可重建的摘要投影、待处理水位和辅助调用审计，不复制官方 transcript 或另立工单账。调用、完成、迟到丢弃、失败和降级均可查；模型失败保留仍有效的文字，并公开确定性降级及真实错误类别。纯摘要展示事件不再次触发模型，展示更新与对外通知分离。

Watchdog 判断器可在独立宿主运行，只依赖本宿主的辅助模型请求和监督审计存储，不要求目标 assistant 服务启动成功。仅有受控异常迹象且满足最小观察窗时调用；默认观察 120 秒、单单调用间隔 60 秒、全局最多 2 个在途、超时 30 秒、输入 8000 字符，连续 2 次同类判断且证据水位与证据内容均前进后才具备疑似信号资格。用户答复、审批及未到期的合法后台作业或声明长操作予以豁免；配置可调整，历史恢复保留调用间隔和连续命中记录。

判断仅返回疑似无进展、疑似偏离、正常等待或证据不足，并带理由、允许范围内的证据引用、水位及不确定性。合法等待、新运行或要求变化、迟到结果与审计失败均不能沿用旧的放行资格；模型不可用降级为机械监督，不宣布 Worker 正常或故障。判断器不改工单、不暂停重派或恢复执行、不重启宿主，也不自行发送处置信号；外部监督的信号与检查生命周期见[任务与执行](任务与执行.md)。

## 实现边界与验证

以上是目标设计，以下按仓库源码区分现状，不代表已打包运行实例已经验证：

- 新执行会话只读取统一配置层解析后的工作角色队列，再由 `worker-model-route.mjs` 冻结；未单配 `workerModels` 时沿用配置层明确的 Router 队列继承规则，没有有效模型才报错。单工单、修订及目标节点不接受 provider/model 覆盖，旧字段请求明确拒绝，项目默认值不参与路由。执行器在实际请求边界应用冻结的模型与角色参数，保持供应商 ID 原样。
- 统一角色装配已接入主聊、旁聊、Worker 和一层官方子 Worker；只影响持久归属的 SuperAgent 会话，普通会话保留官方选择路径。定向验证使用锁定版本真实 Agent / preset / permission / Session 服务与脚本化模型适配器，覆盖首轮纠正、运行后 preset 阻塞、原审批身份保留及持久角色恢复；不等于实际宿主沙箱、外部工具、安装实例或真实供应商请求已验。运行过的旧会话若组合不符仍为明确迁移阻塞，不写成已完成迁移。
- 工作队列、参数、当前选择和自检记录持久化在 BenchGo 自有 `sa_worker_execution_state`，不向官方日志追加自定义插件记录。备用切换后保存 index，恢复沿用同一队列。旧 Run 首次恢复时只读迁移旧队列并记录 `legacy-queue`；没有队列的记录只保留官方保存的选择及可恢复请求参数，记录 `legacy-selection`，不拼接当前备用模型。迁移后只读新表，旧日志保留历史证据，不改写。
- 子代理从父 Worker 当前实际工作模型和参数生成路由约束，拒绝会话选择、allowlist 或请求参数越过该路由，工具面继续收窄。官方参考版本为 `0.2.2-rc.1`、提交 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`，与当前根目录 `upstream.json` 和子模块 pin 一致。
- Worker 动态任务包仅装配原工单已应用的完整要求快照、任务上下文与来源引用，不再序列化 Router 通用上下文；普通修订在原会话下一工具批边界整份替换，窄 Assignment 保留任务切片。Router 十项开局包、旁聊动态摘要和长会话无感轮换仍需独立验证。
- 项目执行会话在官方 create/resume 后通过 `workspaceRegistry` 显式 attach 到同一项目工作区，header cwd 用于展示归属，Run 目录或 worktree 用于实际执行，两者不改变冻结模型。无项目会话保持官方未分组列表，按最近活动排序表达“最近”功能，不创建同名工作区。工单入口与列表标记复用官方 `uiWorkspace.openSession` 和 `sidebar.session.row.trailing`；终态归档复用官方 registry，并保留原 session 和成果。
- 固定轻量自检由原 Worker 的 `assistant_task_result` 工具记录摘要、检查和限制；结构性失败须包含尝试、死因和继续条件。宿主只校验记录与运行、要求编号等确定性归属，不另开自检 Agent 或内容评分会话。
- 辅助摘要与独立进展判断模块已实现，定向测试覆盖白名单脱敏、辅助队列隔离、事件合并与防饥饿、限额、重启续接、旧结果隔离、合法等待、连续命中及审计降级。服务端摘要装配和统一展示投影已接线；安装版自动更新、真实辅助供应商请求及独立宿主故障场景仍须真实验收。当前产出变化为未知，判断强制高不确定性；重复工具调用不等于已验证“无实质进展”，需受控目标的可核验产物或检查事实完成该验收。

Router 表达交付、状态事实、交付后关单和后台整理的服务边界，以[自校验与交付](自校验与交付.md#实现与验收边界)及所属模块为准。渠道、重启、完整输入路径与四态渲染应分别验收，不由模型路由接线推定完成。

验证角色选择、保存、重载、能力解析与实际请求一致；以不同系统工作模型与项目默认模型核对首次请求，再修改两处配置并续跑，确认已有会话仍用冻结路由和参数。覆盖故障切换后续跑保留实际选择、冻结备用队列不被新配置改写、子代理默认继承当前工作模型且越角色覆盖不静默放行。用真实错误分类验证取消和权限拒绝不切换、跨供应商工具结果保留且不重复副作用。

检查实际装配材料，确认 Worker 仅取任务包、子代理仅取切片与原文指针，fork 不得复制全历史，压缩保留原文引用和冻结文档。验证完成信号关联持久成果，Router 读取后主动自然表达并交付，自选摘要或完整回复、不重派、不触发内容审查；原稿仍可追溯，实际改结果进入修订或关联调整单。检查自校验留在原执行会话、没有额外内容验收模型调用；Worker 与子代理无长期记忆写入口，后台整理只取已关工单且不从 Router 上下文取材。
