# 研判调度缺口修复

2026-11-03 调度与模型路由修复记录；2026-11-05 按源码更新 Router 门禁、持久输入及聊天展示状态。依据 DSH 实验结论和 `eval/superagent-20261103/dsh-pitfalls-audit.md`；历史验证与本轮 P0 记录分开。

1. 跨线程研判独立推进，同线程保持单一在途研判、租约与批处理。后续 tick 能调度新线程，不能被旧线程的慢请求阻塞。不新增固定并发限流。停止须取消并等待在途研判；策略变更和过期租约仍禁止提交。
2. 接单研判遵守既有辅助 review 用途配置：勾选且配置有效时辅助首选及备用优先，随后主模型及备用；未勾选或未配置时仍以当前主模型优先。模型 ID 不改写。保留受限原文读取工具和现有授权复核，不改成无工具的通用文本请求。
3. Router 工具门禁已由本轮[持续主会话后端](持续主会话后端.md)方案收紧：取消每请求 8 次探索额度，所有网页、文件与 shell 调查均交给 Worker；主会话兼顾正常聊天、直接回答、协调、工单查询与必要澄清。工具定义身份校验防止同名工具替换继承权限，模型可见面同步限制，不限制 Worker 并发。

主聊天交互目标：Router 与用户自然交流，派工成功后自行组织回复；必要授权或关键歧义才追问。执行过程留在工单内，后台通知少打扰，验收后交付结果；这些规则不限制正常聊天。当前是否满足由源码核对记录说明；历史调度与模型路由验证不代表后续交互调整已完成真实验收。
