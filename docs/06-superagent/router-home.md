# Router 工作简报（已实现）

2026-11-04 源码校对。空会话展示 BenchGo 正式形象、工作简报和三项快捷起草。构图采用 Editorial greeting（seed 1211466134），沿用产品字体与主题；宽度跟随官方聊天内容轴，品牌形象保留原比例。已有会话显示 `QuietChat` 发布投影，官方内容容器和输入框继续复用，但不挂载原始执行 transcript；输入框保留额外 5px 底部留白。

- 需要你关注：waiting、blocked、uncertain、failed，最多 2 项。
- 正在推进：非终态且非暂停、停止中的任务，最多 3 项。
- 最近完成：completed，最多 2 项。阶段与摘要只取当前指令版本。
- 管理任务、记忆与档案跳转既有资源入口。关注项不等于可直接批准；授权与问答仍由原交互界面处理。
- 快捷起草通过官方 InputActions 插入可编辑文本，不发送、不覆盖已有草稿。官方输入框继续负责草稿持久化，聊天正文由 `QuietChat` 展示。

首页和实时任务面板共享 tickets / goalList 请求与缓存，每 10 秒更新；隐藏页面暂停，最后一个订阅卸载时取消请求。加载、失败和真实无任务分别显示，失败时标明保留的旧数据。

动效包括有限次数入场、品牌形象展开和悬停、快捷入口按压反馈；使用 transform/opacity，并遵从 prefers-reduced-motion。窄容器使用单列快捷入口，沿用同一套组件。
