# 身份名片设计清单

设计日期：2026-11-03；源码校对：2026-11-04。状态：名片编辑、过滤与版本同步已实现；当前界面已简化，以下现状以工作树源码为准。文末保留首版历史验证，不代表本次重新构建或视觉验收。

## 目标与界面

让身份名片成为可识别、可编辑、稳定显示的 BenchGo 伙伴。沿用 `assets/brand/benchgo-mark.svg` 的正式形象、比例和颜色。

当前入口为 SuperAgent → 资源 → 身份 → 信息，保留姓名编辑与一个简洁的名片区域：

- 名片标题旁展示与实际名片共用的 160 × 40 px 预览；没有独立宽窄或浅深主题预览开关，颜色跟随当前主题。
- 「编辑 HTML」按钮展开/收起代码编辑器；展开本身不修改配置，输入后更新预览和诊断，最多 16000 字符。
- `cardHtml` 为空时展示当前宠物形象与姓名，并显示「动态效果」开关；有自定义 HTML 时隐藏该开关，已有 `cardMotion` 配置仍生效。
- 当前没有「BenchGo / 自定义 HTML」模式切换或恢复默认按钮。恢复当前形象的路径是展开 HTML、清空内容并保存，保存边界将空白归为 `null`。
- 外层身份表单提供「取消修改」「保存更改」；未保存修改沿用离开提醒和配置冲突保护。形象素材、预览应用与恢复上一版在「身份 → 形象」管理。

侧边栏中，吉祥物与姓名构成一个整体；聊天和资源入口仍独立可用。保留单层布局，不叠加卡片边框，不常驻堆砌技术说明。窄栏优先保留图标和操作，姓名截断并通过气泡显示全名；可用高度由统一组件控制，不能继续默认把任意 HTML 塞进 30px 高度。

2026-11-04 校对时执行名片、名片编辑器、宠物状态与后端四组定向测试，共 18 项通过。没有执行浏览器四态视觉验收；这些测试不能代替下文列出的实际展示与动态接线验收。

## 实施前已确认现状

| 位置 | 代码事实 | 影响 |
| --- | --- | --- |
| `plugins/superagent/client/card.jsx` | 自定义模式根据原始 HTML 非空判定；过滤后无兜底 | 原文非空但输出为空时仍展示空 iframe |
| 同上 | 仅允许少量文本标签和 STYLE；不支持的元素连同子树被移除 | 图片、SVG 或不支持的外层容器可造成整个名片消失 |
| 同上 | iframe 使用 sandbox 与禁止网络的 CSP | 外部图片、脚本驱动的宠物不能直接运行；这是应保留的隔离边界 |
| `plugins/superagent/client/style.css` | 高度固定 30px，溢出隐藏；身份页预览宽度与侧栏不同 | 超高、偏移内容会被裁切，预览效果不能代表实际侧栏 |
| `plugins/superagent/client/index.jsx` | 侧栏轮询与事件更新并存，配置快照刷新未按 revision 拒绝旧响应 | 存在新旧结果覆盖风险，尚未复现用户具体触发过程 |
| 同上 | 身份页有名片预览和恢复默认，没有 HTML 编辑入口 | 修改、校验、保存、确认侧栏生效缺少完整路径 |
| `plugins/superagent/src/store.mjs` | 已有 cardHtml、长度校验及配置 revision | 应复用已有配置保存机制 |
| `assets/brand/benchgo-mark.svg` | 有身体、双眼、编辑器条等 data-part 标记 | 可复用原素材；首版不需要生成新形象或新素材 |

以上是源码事实与风险分析，并非对用户具体故障的运行时复现结论。

## P0：修复显示与保存链路

- [x] 统一预览和侧栏的渲染组件、过滤规则、尺寸约束及默认主题，避免两套显示逻辑。
- [x] 对过滤掉的标签和属性给出可定位的编辑提示；不支持的普通容器考虑保留安全子节点，危险元素仍删除完整子树。
- [x] 过滤后无有效内容时展示默认 BenchGo 名片，并提示原因；不能将空白当作成功预览。
- [x] 区分「有节点」与「能看见」：检查常见隐藏、透明、零尺寸及越界规则。无法可靠判断的任意 CSS 保留预览确认与恢复入口，不宣称能自动识别所有空白。
- [x] 约束自定义内容的布局范围，明确可用高度；超出时在编辑区提示，不静默裁切到完全不可见。
- [x] 保存成功后用服务端返回的配置及 revision 同步侧栏；拒绝旧响应回写。轮询、事件、页面刷新走同一版本判断。
- [x] 配置冲突时保留草稿并提示重新载入，不静默覆盖；保存失败不显示成功，不提前替换侧栏。
- [x] 外部工具修改名片也通过统一刷新链路生效；关闭再打开身份页、重新加载应用后保持一致。
- [x] 保留 iframe sandbox、禁止脚本和网络资源的边界；不以开放同源权限解决显示问题。

## P1：形象展示与动态边界

- [x] 默认名片使用当前宠物形象加姓名；没有个人形象时使用官方吉祥物，已有自定义 HTML 不被自动替换。
- [x] 名片保持素材比例。当前 `AssistantCard` 内的 `PetAvatar` 使用 `motion={false}`，默认名片为静态，旧版浮动、悬停抬起和点击短动作不再是当前能力。
- [x] 点击吉祥物进入身份设置；键盘可聚焦、可操作，有明确的可访问名称。HTML 仍是展示内容，不承载脚本交互。
- [x] 动态开关随配置保存；自定义 HTML 动画会在开关关闭、页面隐藏或名片不可见时暂停，系统减少动态效果优先。该配置也供形象页动作预览等位置复用，不意味着静态名片已播放动作。
- 聊天顶部已根据运行/待确认状态切换基准角色表情；动作参数和原创角色短表情尚未完整接入名片渲染，见[宠物现状](宠物.md)。
- [x] 名片操作提供全名提示和可访问名称；HTML 问题以文字提示，不只依赖颜色。

名片内的伙伴感是本期范围。独立悬浮桌宠、声音、养成系统和复杂动作素材属于后续独立设计，不纳入本期实现。

## 配置与实现边界

- 继续以 `cardHtml: null` 表示当前形象加姓名，非空字符串表示自定义 HTML，避免新增与旧字段冲突的模式字段；空字符串在保存边界统一归为默认。过滤后无可见内容时也以当前形象兜底，不改写保存的原文。
- 新增动态开关字段 `cardMotion`，由统一配置校验、默认值和版本合并管理；缺省值兼容旧配置，系统减少动态偏好优先。
- 姓名与身份档案沿用现有权威来源，不将外观写入 IDENTITY.md；只保存变化字段，不丢失模型等其他设置。
- 同步更新 `assistant_config` 工具 schema、提示与运行上下文，不能仍引导模型生成仅限旧 30px 布局的内容。
- 品牌素材从唯一母版经现有构建方式引入；跨页面公共组件放 `plugins/shared/client/`，不从 Link 业务包建立反向依赖。
- 业务改动限制在自有 `plugins/`，不修改官方子模块；不引入新的安装插件包。

## 验收清单

- [ ] 默认名片：首次进入、修改姓名、保存、关闭页面、重载后，身份页与侧栏一致。
- [ ] 自定义 HTML：展开编辑、预览、保存、重载、清空恢复当前形象路径完整；清空后未保存也支持取消修改。
- [ ] 用图片名片、不支持的包裹标签、空 STYLE、隐藏内容、超高内容验证提示与兜底；安全子节点不被误删，危险内容不能执行。
- [ ] 用延迟与乱序响应验证旧轮询不能覆盖新保存；并发编辑冲突不丢草稿或其他配置。
- [ ] 通过工具修改 cardHtml 后，侧栏能同步，无需重新启动应用。
- [ ] 常规/窄侧栏及浅深主题无整卡空白，入口不被挤出；预览能代表实际布局。
- [ ] 动态关闭、系统减少动态、后台暂停均有效；键盘操作与气泡说明可用。
- [ ] 验证旧配置迁移、HTML 过滤安全性和版本同步的定向测试；完成前端实现后执行 `npm run reload:plus`。视觉效果由用户验收。

实施顺序：先 P0 显示及同步修复，再补身份页编辑路径，最后接入动态默认名片与定向验证。


## 2026-11-03 首版实施记录（历史）

本节保留当时交付与验证记录。当前编辑器没有下述模式切换、宽度/主题预览或独立恢复按钮，名片动画也已调整；现行路径见文首。首版通过数量不作为当前工作树回归结果。

- 渲染：`card.jsx` / `card.css` 统一默认与 HTML 名片，使用正式吉祥物，默认名片支持轻浮动、悬停和按压反馈；页面隐藏、离屏、减少动态偏好均有处理。统一 40px 名片区域，窄栏收起操作文字保留图标。
- 编辑：`identity-card-editor.jsx/css` 提供模式切换、HTML 草稿、诊断、宽度/主题预览、恢复默认及动画开关。外层身份表单负责差异保存和取消，资源切换、助手导航与浏览器关闭提供未保存提醒。
- 同步：`config-sync.mjs` 为侧栏与配置请求维护统一版本快照；保存成功直接通知订阅者，较旧 revision 和同版本旧请求不能覆盖新配置。删除原先 `benchgo:assistant-name` 事件与重复的名片状态。
- 契约：旧配置补齐 cardMotion，空白 cardHtml 归为 null；工具 schema、系统提示和运行上下文同步更新，配置合并及 revision 冲突保护沿用原存储能力。
- 清理：删除旧手写名牌、30px 名片、旧预览容器的样式和工具说明；没有修改官方子模块或引入新依赖。
- 本次同时优化工具页分段切换器与紧凑顶部布局，复用共享分段控件，保持键盘和减少动态支持。
