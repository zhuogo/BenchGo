# 消息工具栏与回应

2026-11-04，实施契约。主聊和旁聊使用相同消息展示，不恢复工具过程。

- 删除消息正文上方常驻的发送者与日期行；通过左右布局和无障碍名称区分用户/助手。
- 运行时只显示三点轻动效，不显示“加载中”文字或正在执行哪个工具；工作记录仍从既有入口查看。为屏幕阅读器保留等待标签，尊重 reduced-motion。
- 工具栏在鼠标悬停、键盘聚焦或弹层打开时显示；固定在用户消息左侧、助手消息右侧，与消息正文垂直居中，离正文 8px，消息间距为 16px。正文与工具栏共用一行网格，正文按剩余空间限宽，工具栏不可压缩；隐藏时保留侧边宽度、不额外占用底部操作行，悬停只改变透明度，不改变消息位置或滚动高度。取消净空测量和底部回退。触屏仍在侧边常显，控件命中区至少 44px；已有表情作为正文下方的紧凑徽章常显，不参与工具栏的垂直居中定位。
- 交付正文按普通助手消息呈现，与正式回复使用相同正文及侧边工具栏；不显示“交付通知”标题、通知卡外框或“标记已读”。需要回答的选项保留；后台来源、去重与交付账本协议不变。
- 用户气泡独立收缩，背景与文字成对复用宿主 `--dsw-specific-bubble` / `--dsw-alias-label-primary`；工具栏和弹层复用宿主浮层、辅助文字与边线主题变量，随亮暗主题切换。
- 表情/用量面板通过 portal 与宿主 `useAnchoredPosition` 定位，避开滚动容器裁剪并限制在窗口内；点击外部关闭，Escape 返回实际触发按钮。仅隐藏工具栏视觉，不移除键盘 Tab 入口。
- 复制消息纯文本；失败明确提示。时间按消息实际时间展示；聊天容器较窄时以时钟图标替代日期文字，完整时间仍可通过悬停或键盘聚焦读取。没有用量的消息显示“未记录用量”，不编造 Token。
- 工具栏使用宿主公开 Tooltip 气泡（上方、portal），替代浏览器 title；复制、回应、用量及完整时间支持悬停/键盘聚焦提示。
- 图标统一 18px 显示、16px 画布与 1.3px 圆端线条：复制/成功/用量复用宿主 Medium，笑脸补齐同规格描边。悬停、弹层展开及复制成功有稳定底色反馈；时间与操作轻分隔。表情面板使用整齐的六格选择、语义提示和选中态，不改变已保存回应值。
- 表情是当前用户对消息的本地产品回应（👍 ❤️ 😂 🎉 🤔 👎），一次选一个，可取消。按来源线程与稳定消息键持久化，不发送外部渠道，不构成审批或 Agent 指令，不宣称多用户聚合。
- 后端 `history` 增 reactions 映射；消息用量只投影宿主已记录数字。`messageReaction` 使用 threadId/messageKey/emoji（null 清除），必须验证目标消息归属；同步 OpenAPI。
- 消息键为 `message:<id>` 或 `notification:<eventId>`。回应记录按线程与当前宿主会话隔离，重置主聊不会继承旧会话回应；旧历史翻页仍可回应。`usage` 仅表示最终回复对应的那次模型请求（包括显式发布回复的请求），不是整个工单或回合累计；仅保留宿主记录的非负有限数字，缺失不补零。

设计沿用 BenchGo 的字体、色彩与居中对话宽度；消息工具栏低对比，浮动表情面板轻阴影，动画只反馈悬停/点击/加载。2026-11-03 原轮次按当时用户要求由用户检查视觉；后续网页修改仍遵循仓库的四态实际渲染自查要求，用户做最终验收。
# 实施验证

## 即时显示修正（2026-11-03）

重复回显修正：history 必须保留已公开消息的 seq 与用户来源 rpcId；过去 engine 分页返回时删除 seq，导致客户端无法关联实时用户节点和持久消息。以 rpcId/seq 做身份合并，不按文字内容删除重复发送。测试必须消费真实 engine.history 输出而非人工补齐字段。完整历史分页继续由服务端控制，实时投影只补历史末尾新用户消息。

输入区停靠：自有消息视图使用独立可滚动区域，官方 composer seat 作为同级不收缩的底部区域，完整保留工具栏、状态栏与审批接管。不能依赖官方 main 根类的 sticky 选择器，因为自有面板没有该私有根类；通过公开 data-conversation-scroll / data-composer-seat 标记限定自有页面样式，不使用全窗口 fixed 定位。

宽度修正：主聊/旁聊使用官方 conversation.content 的 main 变体。宿主客户端模块表不支持直接导入官方 src 子路径，即使 package exports 允许也不能作为插件运行时依赖。自有轻量 ConversationWidth 仅测量容器并投影原生宽度偏好到 CSS 变量，正文及输入框仍使用官方布局规则；当前不提供拖动手柄。不得引用官方内部组件，不修改上游源码。

启动衔接：后端 ensure 返回不代表客户端 Session 目录已收到增量。retain 遇到 unknown session 时仅刷新官方目录并重试一次，保留原会话与历史，不重建或清空；失败提供可重试的简明提示。侧栏会话高亮需同时满足官方会话身份与当前无业务面板。正文宽度及横向间距复用官方 --dsh-chat-content-width 与 --dsh-composer-side-clearance。

客户端使用官方 uiConversation 服务必须在统一入口声明注入；可选链不能绕过 Cordis 服务依赖校验。SuperAgent 主面板注册完成后首次进入主聊天，不以官方最近工作区作为默认产品落点；后续模块状态刷新与面板重挂载不覆盖用户主动导航。最近工作区保留为普通会话功能，不删除用户历史。

用户气泡按正文独立收缩并靠右，不能被下方工具栏撑宽。等待状态只保留三点动效，“加载中”只作为屏幕阅读器标签。即时用户消息复用官方 Session 的 pendingSubmissions，并衔接官方 chat view 中已接收的用户消息；按请求身份或事件序号与服务端历史去重，不按文本去重，不另外包装发送方法。失败回声由官方状态撤回，排队消息仍留官方队列，不伪装为已接收消息。

已接通主聊与旁聊共用的消息工具栏、持久表情回应、真实回复用量和加载动效。沿用现有配色与字体，操作层视觉遵循《前端视觉规范》。时间与操作在悬停或键盘聚焦时显示，触屏常显；减少动态效果偏好下关闭动画。

本轮定向回归 19/19 通过，记录见 `eval/message-actions-tests.tap`；`npm run reload:plus` 成功，记录见 `eval/message-actions-build.log`。按用户要求未做视觉验收。用量仅表示最终回复对应的模型请求，不代表整轮工具执行或工单累计。
