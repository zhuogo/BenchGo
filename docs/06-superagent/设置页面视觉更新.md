# SuperAgent 设置页面视觉更新

更新：2026-11-04。状态：已实现，待用户最终视觉验收。

入口仍为侧栏「资源」。本轮覆盖身份（信息、形象、模型）、档案、任务（工单、持续目标、待处置评估）、记忆、产物、多平台、保险库与系统文件。

## 已实现

- 统一资源框架、页面标题与说明、内容边缘、卡片层次和保存反馈；窄面板与手机使用折叠导航。
- 保留 BenchGo 品牌素材、现有字体与主题变量，深浅主题共用组件。
- 身份名片提供预览；模型突出首选、备用及辅助用途；形象区分预览与应用。
- 档案直接展示正文，空正文不再插入“开始编写”引导；长正文随页面展开，保存栏位于正文下方，不悬浮。保留加载占位与错误重试。
- 文件与凭据保留空态引导；记忆保留时间线与来源，MEMORY.md 使用同一档案编辑方式。
- 工单、目标与评估用状态标记、摘要、更新时间表达进展；并发设置解释容量含义。
- 新增轻量 `ResourceState` 复用初始加载、空态与恢复操作；其他已有页面继续复用原组件。

配置行为保持原契约：模型 ID 原样传递、只提交变更字段、revision/hash 冲突保护、跨资源页保留未保存草稿。官方引擎与参考仓库未修改。

## 设计与验证

设计参考 design-taste-frontend 的 Framed sheet，seed `752066408`；沿用品牌字体与配色，无重抽。浅色框架承载内容页，BenchGo 吉祥物在导航与身份预览中保持一致。图标容器、状态色等以项目《前端视觉规范》为准。

使用真实 React 页面、共享组件及官方 UI 原语，在隔离的模拟 API 环境检查 12 个主要视图：浅色四态 × 1440/768/390 三种宽度，暗色数据态 × 桌面/手机；另复看长页底部。未发现运行异常与页面横向溢出。身份信息的初始加载/失败由顶层页面负责，已加载信息在子请求失败时保留。

定向测试通过，包含 61 项集成回归，以及模型、形象、档案、保险库与预算等子页测试。`npm run reload:plus` 已成功重建 modules、统一客户端及 Link Web，没有重启 Web 或打包服务端种子。

视觉技能检查为 0 FAIL；保留提示：短设置页保有自然留白，透明边线的测量提示以实际截图复核，模型顺序数字承载真实优先级，阴影仅用于已有浮层。
