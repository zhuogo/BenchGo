从哪里下载

官方下载页实时读取 zhuogo/BenchGo GitHub 正式发布，只显示该版本真实存在的文件。没有完成发布的平台会明确显示不可下载。网络受限时可直接查看GitHub Releases。

核对文件

核对仓库、版本、架构与文件名。若附带 .sha256 或 SHA256SUMS，计算 SHA-256，与同次发布值逐字比较。不匹配时不要安装。

Windows PowerShell（使用实际文件名）：

Get-FileHash .\benchgo-setup.exe -Algorithm SHA256

macOS：

shasum -a 256 benchgo-<版本>-mac-arm64.dmg

Linux：

sha256sum -c benchgo-<版本>-linux-server.tar.gz.sha256

替换示例中的版本、架构与文件名。macOS 包当前未通过 Apple 公证，文件校验不等同于 Apple 公证。

更新应用与插件

先备份重要工作目录、配置与数据。工作台「更新」入口按实际可用能力提供应用或插件更新；若没有可用的自动更新，退出应用，从官网获取对应平台新版安装。Android 使用相同正式签名 APK 覆盖更新；签名不匹配时，先确认来源并备份，不要先卸载来强行绕过。Linux 按服务端指南操作。

不要用旧版覆盖新版，不要混用开发包与正式包。升级后确认模型选择、配置保存、工作目录与设备连接仍符合预期。

反馈问题

在GitHub Issues提供系统与架构、BenchGo 版本、复现步骤、期望结果和实际错误。发送截图与日志前，删除 API Key、配对码、设备令牌、私有路径及 connection.json 等连接凭据。
