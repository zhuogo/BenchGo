官方下载页实时读取 zhuogo/BenchGo GitHub 正式发布，只显示该版本真实存在的文件。没有完成发布的平台会明确显示不可下载。网络受限时可直接查看GitHub Releases。

核对文件

核对仓库、版本、架构与文件名。若附带 .sha256 或 SHA256SUMS，计算 SHA-256，与同次发布值逐字比较。不匹配时不要安装。

Windows PowerShell（使用实际文件名）：

Get-FileHash .\benchgo-setup.exe -Algorithm SHA256

macOS：

shasum -a 256 benchgo-<版本>-mac-arm64.dmg

Linux：

sha256sum -c benchgo-<版本>-linux-server.tar.gz.sha256

替换示例中的版本、架构与文件名。macOS 包当前未通过 Apple 公证，文件校验不等同于 Apple 公证。

更新应用与插件

先备份重要工作目录、配置与数据，再按当前平台更新：

  • Windows：已有统一「更新」入口的版本，可在工作台安装可用的功能包，完成后重启 BenchGo 生效。若旧版没有此入口，先退出应用，从官网下载新版 Windows 安装器，做一次覆盖升级，无需先卸载。
  • Android：下载与现有正式包签名一致的 APK，按 Android 系统弹窗确认覆盖安装，无需先卸载；下载完成不代表已更新。签名不匹配时，先核对来源并备份，不要通过卸载来强行绕过。
  • Linux：按服务端指南操作。

Windows 旧版更新被阻塞：若旧版因无法识别引擎而不能安装功能包，先在「更新」弹窗点击「重试应用更新」，或在「版本详情」中点击「检查安装器更新」，按原生窗口提示升级 Windows 主机应用并重启。此前修复该问题的 Windows 主机应用为 v0.1.3，内置功能包 v0.1.4；若没有上述入口，从官网下载当前正式 Windows 安装器覆盖升级。

「更新」入口按实际可用能力显示应用或插件更新；若没有可用的自动更新，从官网获取对应平台的新版安装包。不要用旧版覆盖新版，不要混用开发包与正式包。升级后确认模型选择、配置保存、工作目录与设备连接仍符合预期。

v0.1.5 与组件版本

BenchGo 对外发行版本为 v0.1.5，桌面主机应用为 v0.1.4，功能包为 v0.1.5，Android 为 v0.1.4；工作台 CLI 与独立 Relay 命令包为 v0.1.1。组件版本各自递增，请按更新入口和当前平台选择安装，不要求所有组件显示同一个数字。

本次统一了命令行安装与兼容实例复用，并提供部署资源提前准备、进度、资源阶段取消和失败重试。具体命令、平台验收限制及已有环境处理见安装指南与服务端指南。旧安装器中的原生能力仍需通过对应应用升级获得，仅更新功能包不等于已替换桌面客户端。

仅对曾全局安装旧版 benchgo-plugin 的用户：如遇同名命令占用，或曾用 --force 覆盖后升级插件导致 benchgo 入口消失，请按安装指南先升级旧插件、再安装 CLI 的顺序恢复。固定版本 npx 仍是推荐入口，其他用户无需先安装插件。

默认桌面安装包保留完整资源，首次下载安装器或首次通过 CLI 准备当前平台资源仍需完整下载；资源通过校验后才会复用。请以下载页显示的实际文件大小和发布说明为准，不以命令包大小推断完整安装所需流量。
