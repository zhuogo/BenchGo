完成初始化

打开 BenchGo，按启动页的实际提示准备环境、安装插件并进入工作台。首次启动需要联网。若失败，先检查网络和提示原因，再使用重试入口。

安装版统一包含 BenchGo 基础层、Harness 聚合、SuperAgent、Voice 和 Link，无需逐个寻找或安装源码包。各能力在设置中独立管理。

连接你的模型

  1. 在模型或供应商设置中添加实际使用的供应商，填写其提供的 API 地址与 API Key。
  2. 选择供应商返回或你明确填写的模型 ID。模型 ID 是供应商标识，请保持原样，不要替换成看起来相近的别名。
  3. 保存后重新打开确认配置保留，再用一次真实对话确认请求可用。保存成功不等于认证成功。
  4. 在 SuperAgent 模型设置中为 Router 与 Worker 选择可用模型；需要时再配置备用模型。

不支持的能力以界面实际提示为准。请勿把 API Key 放到公开反馈、截图或共享文档中。

完成第一件事

选择或建立项目，确认工作目录。向 SuperAgent 说明目标、背景与交付形式，例如「帮我整理这个目录的说明文档，先列出修改方案」。在任务列表查看进展、补充要求与最终文件。涉及需授权操作时，阅读具体内容后再决定。

本地运行与联网

工作台、项目与会话保存在你的机器上，但使用云端模型、在线工具或外部服务仍会发送对应请求。本地工作台不意味着所有任务完全离线。Voice 等能力还取决于配置的服务与模型。
