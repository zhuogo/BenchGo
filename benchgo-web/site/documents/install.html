BenchGo 在电脑或服务器上运行，手机和平板连接已有工作台。请从官方下载页选择当前实际可用的安装包，支持平台以该次发布为准。

Windows x64

  1. 下载 EXE 安装器，核对文件来源为 github.com/zhuogo/BenchGo。
  2. 退出正在运行的 BenchGo，运行安装器并按步骤安装。
  3. 打开 BenchGo，按启动引导准备工作台和插件。首次启动需要联网下载必要依赖，请等待实际阶段提示。

macOS

在「关于本机」确认芯片：Apple 芯片选择 arm64，Intel 处理器选择 x64。打开相应 DMG，将 BenchGo 移入「应用程序」；ZIP 包解压后同样移入「应用程序」。

当前 macOS 包未通过 Apple 公证，首次打开可能出现系统提示。请核对官方来源与校验值，按系统针对该应用提供的提示处理；不要关闭系统的全局安全保护。DMG / ZIP 是否已经提供，以下载页显示为准。

Linux 服务端

当前面向 Ubuntu / Debian x64 与 systemd，提供浏览器工作台，不是 Linux 桌面安装器，也不支持 ARM64。请阅读Linux 服务端安装。

Android 与 iPhone

Android 从下载页获取正式 APK，按系统提示允许本次来源安装。手机端需要已有工作台保持运行。iPhone / iPad 使用工作台提供的 HTTPS 手机网页，当前没有 iOS 原生包。

安装后继续阅读首次使用或手机连接。
