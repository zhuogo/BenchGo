此包是浏览器工作台的服务端，不是 Linux 桌面安装器。当前仅支持 Ubuntu / Debian x64 与 systemd，不支持 ARM64。首次安装需联网准备固定版本的官方 Harness，必要时准备 Node.js 24.9+，插件依赖随包提供。

推荐：添加 SSH 服务器

在已有 BenchGo 的「设备」中点击「添加」，选择 SSH 服务器，按引导完成连接。日常使用优先采用此入口；以下独立压缩包适用于维护者。

使用服务端压缩包

从下载页获取压缩包与同名 .sha256，核对校验值，解压并进入版本目录。将命令中的「版本」替换成实际版本号。

sha256sum -c benchgo-<版本>-linux-server.tar.gz.sha256
tar -xzf benchgo-<版本>-linux-server.tar.gz
cd benchgo-<版本>-linux-server
(umask 077; bash install.sh github connect > connection.json)

github 可按脚本支持改为 mirror。以日常用户运行，需系统权限时按提示处理。connection.json 含私有连接凭据，不要公开、提交 Git 或随反馈发送。服务默认仅监听 loopback，请通过可信 SSH 隧道连接，不应把内部端口直接暴露到公网。

更新

备份配置与工作数据，核对新包来源，解压进入新版本目录执行：

(umask 077; bash install.sh github update > update-result.json)

检查命令结果与实际服务状态后继续使用。失败时检查网络、系统架构、systemd 与磁盘空间，不要公开敏感连接结果。

工作台与 Relay

Linux 工作台提供完整工作环境；BenchGo Relay 只转发已授权设备的流量。两者是不同产品与安装流程，不要把 Relay 当作工作台安装包。
