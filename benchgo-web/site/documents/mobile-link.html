Link 让手机和平板接入同一台工作台，继续对话、查看任务与文件。Link 随模块常驻，无需单独开启连接开关；电脑或服务端需要保持运行、网络可达。

Android：扫码连接

  1. 从官方下载页安装当前可用的正式 APK，手机与电脑连接同一 Wi-Fi。
  2. 在电脑工作台点击侧栏顶部的设备连接图标，打开「设备中心」，在「连接」区域点击「生成连接信息」。
  3. 在手机 BenchGo 的设备中心点击「添加设备」→「连接已有设备」→「扫码连接」，扫描电脑「连接此设备」窗口中的二维码。
  4. 回到电脑的配对窗口，在「允许设备连接？」提示中核对设备名称，点击「允许」。若已暂时关闭提示，可点击「查看连接请求」重新打开；手机连接成功后即可打开工作台。

无法扫码时，在电脑点击「复制连接信息」，粘贴到手机「连接已有设备」的「连接信息」中，再点击「连接设备」并在电脑确认。二维码包含一次性配对信息，请勿公开分享。请求已发出后等待电脑确认，无需重复扫码。若被拒绝或已过期，在电脑重新点击「生成连接信息」后再配对。

iPhone / iPad：手机网页

先确保工作台有手机可访问、证书有效的 HTTPS 地址，再在电脑「设备中心」的「连接」区域点击「生成连接信息」。打开该工作台提供的 HTTPS 手机配对页面，使用同源页面的一次性配对码或完整配对地址，再到电脑核对设备名称并允许连接。不要把其他主机的配对码粘贴到不相关网站。当前没有 iOS 原生安装包。

不同网络

局域网中 Android 可直接连接，通常不需要 Relay，默认 Link 端口为 48721。外网访问需要设备可达的 HTTPS 地址，或由你部署并配置独立的 BenchGo Relay。Relay 只转发已授权设备的流量，不含完整工作台，不会随桌面应用自动部署。

无法连接时

  • 确认工作台与 Link 正在运行，手机和电脑网络互通。
  • 检查防火墙是否允许实际使用的连接，不要关闭整个防火墙。
  • 等待电脑端授权；配对码过期后生成新配对信息。
  • 跨网络检查 HTTPS 地址、证书与 Relay 配置。

在设备管理中撤销不再使用的设备。配对码、设备令牌与服务器连接文件均应保密。
