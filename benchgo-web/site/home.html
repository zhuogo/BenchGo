A FEW GOOD QUESTIONS

你可能还想知道。

“本地工作台”，意味着完全离线吗？

BenchGo 工作台运行在自己的电脑上。是否需要联网，取决于你连接的模型、工具和任务；使用云端模型时，相关请求仍会发送给模型服务商。本地运行不等于所有任务都离线。

手机也能独立运行 BenchGo 吗？

手机和平板连接的是已有的工作台。局域网内可通过 Link 配对；外网访问需要配置可达地址或独立的 Relay。Android 有安装包，iPhone 可通过手机网页访问。

它和 DeepSeek Harness 是什么关系？

BenchGo 基于官方 DeepSeek Harness，在其上构建本地工作台与 SuperAgent 协作体验。项目采用开源路线，具体实现、许可和安装说明都可以在 GitHub 仓库中查看。
