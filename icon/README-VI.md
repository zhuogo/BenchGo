## 造型（家族骨架，与母版共锁）
- 身体 600×380、圆角 R95；右下切角为家族共同特征：45° 斜切（410,380 → 600,190），
  切角块保留身体的 R95 圆角——右下角是圆的，不是尖点（母版 geometry.json 原构造）
- 左眼：实心豆眼 90×130 R45；右眼：「<」造型，88% 缩放（2026-10-26 定）
- 右上徽章：橙色终端符 `>_`
- 身体印花：极淡小窗口轮廓（平铺）
- 右下角纹章：奶白小窗口，完整落在切角块内、避开斜边与 R95 弧线（2026-10-26 改版定规，原耳机纹已废）
